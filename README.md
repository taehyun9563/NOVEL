## 폴더 규칙

```
ai/                         ← Claude·ChatGPT 공동 설계 운영 규칙·지침·프롬프트
stories/
  NN_장르_핵심키워드/        ← 작품 하나 = 폴더 하나
    README.md               ← 작품 개요, 진행 현황, 변경 기록
    DECISIONS.md            ← 결정 이력 (D-번호, 공동 설계 시 사용)
    settings/
      01_콘셉트.md          ← 단계별 설정 확정판
      02_세계관.md
      ...
    scenes/
      01_장면이름.md        ← 핵심 장면 초안 (확정 전)
    progress/
      진행_기록.md          ← RP 진행 기록 (`저장` 시 생성·갱신)
```

- 작품 폴더 이름은 `번호_장르_핵심키워드`. 가제가 확정되면 이름을 바꿀 수 있다.
- 작품끼리 설정을 공유하지 않는다. 같은 인물 이름을 쓰더라도 작품마다 별개의 인물이다.
- 각 설정 파일은 **확정 / 추천 / 미정**을 구분해 표시한다. 추천·미정은 확정으로 취급하지 않는다.
- `DECISIONS.md`는 결정 이력만 담는다. 설정 내용의 원본은 언제나 `settings/`다. 운영 규칙은 [`ai/README.md`](ai/README.md).
- `progress/`는 RP 진행 기록이다. 설정이 아니며, RP를 이어갈 때 `settings/` 다음에 읽는다.
