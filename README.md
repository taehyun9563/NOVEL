## 폴더 규칙

```
stories/
  NN_장르_핵심키워드/        ← 작품 하나 = 폴더 하나
    README.md               ← 작품 개요, 진행 현황, 변경 기록
    settings/
      01_콘셉트.md          ← 단계별 설정 확정판
      02_세계관.md
      ...
    scenes/
      01_장면이름.md        ← 핵심 장면 초안 (확정 전)
```

- 작품 폴더 이름은 `번호_장르_핵심키워드`. 가제가 확정되면 이름을 바꿀 수 있다.
- 작품끼리 설정을 공유하지 않는다. 같은 인물 이름을 쓰더라도 작품마다 별개의 인물이다.
- 각 설정 파일은 **확정 / 추천 / 미정**을 구분해 표시한다. 추천·미정은 확정으로 취급하지 않는다.
