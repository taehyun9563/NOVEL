## 5. 김선호 — 집착·소유욕 상세 (⑦ 이후 기준)

| 분류 | 요소 | 강도 | 행동 특징 |
| --- | --- | --- | --- |
| 붙잡음 | 극단적 집착 | 매우 높음 | 떨어지는 것을 싫어하고 계속 함께 있으려 함 |
| | 소유욕 | 매우 높음 | 태현에게 가장 특별하고 가까운 사람이기를 원함 |
| | 독점욕 | 매우 높음 | 태현의 관심과 애정을 자신에게 집중시키려 함 |
| | 질투 | 높음 | 다른 여성이 접근하면 예민해짐 |
| 불안 | 상실 공포 | 극단적 | 태현이 다시 사라지거나 죽을 가능성을 두려워함 |
| | 분리 불안 | 매우 높음 | 연락이 끊기면 극심하게 불안해함 |
| | 애정 확인 욕구 | 높음 | 사랑받고 있다는 확신을 얻으려 함 |
| | 스킨십 욕구 | 높음 | 손잡기, 포옹 등으로 친밀감을 확인하려 함 |
| 돌봄 | 헌신 | 매우 높음 | 직접 행동하고 돌보려 함 |
| | 과보호 | 매우 높음 | 태현이 위험을 감수하면 직접 개입하려 함 |
| 그림자 | 죄책감 | 높음 | 과거 거절을 후회하지만 자신의 책임 범위도 마주함 |
| | 통제 충동 | 상황에 따라 높음 | 상실 공포가 심해지면 태현의 선택에 과도하게 개입 |

> 집착과 소유욕은 선호의 결점이기도 하며, 지나친 통제나 경계 침해는 실제 관계 갈등으로 이어진다.

## 6. 박태현 — 경계형 상세

| 분류 | 요소 | 강도 | 행동 특징 |
| --- | --- | --- | --- |
| 무너짐 | 자기파괴 성향 | 위기 시 극단적 | 삶의 의지를 잃으면 자신을 해치는 위험한 행동으로 이어짐 |
| 의심 | 불신 | 높음 | 선호의 사랑을 쉽게 믿지 못함 |
| | 동정에 대한 거부감 | 매우 높음 | 선호의 사랑이 동정이나 죄책감에서 나온 것이라 의심 |
| 방어 | 경계심 | 매우 높음 | 선호가 갑자기 가까워지는 것을 부담스러워함 |
| | 재거절 공포 | 높음 | 다시 상처받을 가능성을 두려워함 |
| | 자기보호 | 높음 | 감정적으로 거리를 두려 함 |
| | 감정 억제 | 높음 | 진심을 쉽게 표현하지 않음 |
| 잔여 | 미련 | 높음 | 선호를 향한 감정을 완전히 정리하지 못함 |
| 변화 | 사랑의 수용 | 초기 낮음 | 신뢰가 쌓여야 애정을 받아들일 수 있음 |
| | 회복 가능성 | 유동적 | 선호와 주변 인물의 도움, 자신의 선택에 따라 변화 |

## 7. 관계 갈등 축

선호는 죄책감과 상실 공포 때문에 더 다가가고, 태현은 그 사랑이 동정이나 죄책감일까 봐 더 물러난다. 선호의 다가감이 태현의 의심을 키우고, 태현의 물러남이 선호의 불안을 키운다. 이 갈등은 ⑦ 이후 본격적으로 작동한다.
