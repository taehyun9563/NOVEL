# 3단계 — 능력 체계 v3.2

> 상태: 확정. 참고 작품은 분위기와 전투 방식의 기준으로만 쓰며, 능력 이름과 세부 연출은 이 작품 고유의 것으로 설계한다.

## 1. 세계 공통 규칙

| 항목 | 확정 내용 |
| --- | --- |
| 능력 획득 | 혼합형 — 각성으로 자질을 얻고, 아카데미에서 훈련으로 발전 |
| 등급 체계 | F~S급(7단계) + 그 위 비공식 등급 SSS급 · EX급 · 초월급 — 총 10단계 |
| 등급과 랭킹 | 등급은 잠재력, 랭킹은 실적 — 같은 S급 안에서도 순위가 갈림 |
| 능력의 대가 | 없음 — 마력 소모만 있음 |
| 능력·기술 명칭 | 웹소설·애니메이션풍 한자어 — 기술 목록은 `09_기술.md` |

## 2. 박태현

| 항목 | 확정 내용 |
| --- | --- |
| 등급 | **초월급** (비공식 최상위) |
| 랭킹 | 국내 1위 · 세계 1위 |
| 주 능력 | 검술 기반 + 마력 검 생성 |
| 능력 콘셉트 참고 | 공간에서 무수한 검을 꺼내 쏘아냄(게이트 오브 바빌론), 마력으로 검을 원격 조종(이기어검), 하늘을 메우듯 검을 흩뿌리는 광역 공격(만천화우) |
| 전투 방식 | 직접 검술 위주, 생성 검은 보조와 필살기. 단 1:1이든 다수전이든 **본인의 기분이나 상황에 따라** 생성 검을 자유롭게 섞어 씀 |
| 재생 | 극단적 자가 재생 — 의식이 없어도 몸이 스스로 회복 |

## 3. 김선호

| 항목 | 확정 내용 |
| --- | --- |
| 등급 | S급 |
| 랭킹 | 국내 2위 |
| 이명 | 무희 |
| 주 능력 | 검술 기반 — 춤추듯 빠르고 정교한 검술 |
| 콘셉트 참고 | 나 혼자만 레벨업 차해인의 검술 이미지 |
| 검술 구성 | 검술 + 검기(검에 마력을 실어 범위·위력 확장) + 고유 특성 |
| 고유 특성 | **잔상** — 움직임에 실체 있는 잔상이 남아 여러 명처럼 싸움 |

### '무희' 이명의 경위

| 항목 | 내용 |
| --- | --- |
| 시기 | 백야 길드 입단 첫해 (2024년) |
| 계기 | 야간 대형 게이트 공략 중, 달빛 아래 머리를 풀어헤친 채 잔상과 함께 싸우는 모습이 현장 촬영 영상으로 퍼짐 |
| 이름이 붙은 과정 | 검이 아니라 춤을 추는 것 같다는 반응이 이어지며 대중이 '무희'라고 부르기 시작, 그대로 공식 이명이 됨 |
| 선호의 반응 | 처음엔 쑥스러워했지만 지금은 마음에 들어 함 |
