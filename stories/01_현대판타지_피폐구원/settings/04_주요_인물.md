## 3. 김선호

### 외형

| 항목 | 확정 내용 |
| --- | --- |
| 키·체형 | 165cm, 가늘고 유연한 체형 |
| 머리 | 허리까지 오는 흑발 긴 생머리. 전투 시에도 묶지 않음 |
| 눈 | 끝이 살짝 올라간 눈매 |
| 피부 | 흰 편 |
| 인상 | 가만히 있으면 도도하고 차가워 보임, 웃으면 확 환해짐 |
| 평상복 | 단정한 캐주얼 |
| 전투 복장 | 움직임이 큰 흰 계열 전투복 |

긴 생머리를 묶지 않고 싸우기 때문에, 춤추듯 움직일 때 머리카락이 흩날리며 잔상과 겹쳐 보인다. '무희' 이명의 시각적 근거.

### 성격과 배경

| 항목 | 확정 내용 |
| --- | --- |
| 평소 성격 (⑦ 이전) | 밝고 사교적 — 누구에게나 다정해서 태현에게도 특별하지 않았음 |
| 첫인상과 실제 | 도도한 첫인상 ↔ 밝고 사교적인 실제 성격의 차이 |
| 가족 | 평범한 가정 |
| 소속 | 국내 최대 길드 **백야 길드**의 에이스 |

| 구분 | 박태현 | 김선호 |
