# 5단계 — 관계 v5.2

> 상태: 확정. 재회 이후의 대화가 RP 안에서 진행될 경우, 이 문서의 태현 행동은 소설 모드 기준이며 RP에서는 유저가 결정한다.

## 1. 전반부 — 아카데미 시절과 각자의 길 (①②)

| 항목 | 확정 내용 |
| --- | --- |
| 친분 | 훈련 파트너로 자주 붙고, 따로 밥 먹고 연락도 하는 꽤 친한 사이 |
| 서로를 보는 시선 | 선호에게 태현은 친한 친구. **태현은 선호를 단 한 번도 친구로 생각한 적 없음 — 처음부터 여자로만 봤음** |
| 태현이 좋아하게 된 계기 | 첫눈에 반함 |
| 고백 시기 | 2학년 중반 (태현 22세 · 선호 21세 무렵) |
| 선호의 인식 | 어렴풋이 눈치는 챘음 |
| 1차 거절 이유 | 연애 감정이 없었음 — 친구로만 봤음 |
| 거절 후 태현 | 남은 기간 동안 선호를 없는 사람 취급 |
| 태현의 이명 | **패왕** |
| 무소속 이유 | 누구와도 엮이지 않으려고 모든 길드 스카우트를 거절. 누구의 명령도 듣지 않고, 한 곳에 갇히는 걸 싫어함 |

### 같은 시간, 다른 기억

| 구분 | 태현이 겪은 일 | 선호가 겪은 일 |
| --- | --- | --- |
| 아카데미 시절 | 첫눈에 반한 여자 곁에 있었던 시간 | 친한 친구와 함께한 시간 |
| 고백 | 오래 품은 마음을 꺼냄 | 눈치는 챘지만, 친구로 남고 싶었음 |
| 거절 이후 | 잊기 위해 그녀를 지움 | 친한 친구를 하루아침에 잃음 |

## 2. 후반부 — 재회와 2차 거절 (③④)

| 항목 | 확정 내용 |
| --- | --- |
| 재회 계기 | 아카데미 동기 모임·행사 |
| 가까워지는 방식 | 공동 작전·임무가 이어지는 가운데, 선호가 먼저 다가감 |
| ③~④ 선호의 감정 | 미묘한 호감이 있지만 스스로 자각하지 못함 |
| 2차 고백 시기 | 재회 후 수개월 |
| 2차 거절 이유 | 감정은 모르겠지만, 연애하다 깨지면 친구를 또 잃을까 봐 두려움 |
| 거절에서 잠적까지 | 거절 직후 곧바로 잠적 (⑤) |

### 2년 전 응어리 — 일부만 풀림

| 구분 | 털어놓은 것 | 숨긴 것 |
| --- | --- | --- |
| 선호 | 전부 — 태현이 자신을 지웠을 때 친구를 잃은 것 같았던 상처 | 없음 |
| 태현 | 일부 — "그땐 미안했다" 수준의 사과 | 진짜 이유 — 잊으려고 지웠다는 것, 그 뒤로도 계속 좋아했다는 것 |

선호는 "이제 풀렸다"고 생각하고, 태현은 아직 하나도 풀리지 않았다는 걸 안다.

## 3. 관계의 핵심 구조

1. 선호는 1차 거절 뒤 태현에게 지워지며 친구를 잃었다.
2. 그래서 2차 고백에서는 **태현을 잃지 않으려고 거절**한다.
3. 그 거절이 태현을 곧바로 사라지게 만든다.
4. 지키려던 선택이 가장 크게 잃는 결과가 된다 — ⑤ 이후 선호의 후회와 상실 공포의 뿌리.
5. 선호가 태현의 숨긴 진실(처음부터 친구가 아니었다는 것)을 알게 되는 순간, 후회가 완성된다.
