# 6단계 — 조연·주변 인물 v6.1

> 상태: 확정. 조연 프로필은 추천안을 사용자가 승인한 것이다. 태현이 각 인물을 어떻게 대할지는 RP에서 유저가 결정한다.

## 1. 공식 호칭과 기관

| 항목 | 확정 이름 |
| --- | --- |
| 능력자의 공식 호칭 | **각성자** |
| 국가 인증 기관 (작중 '협회') | **대한각성자협회** |
| 국제 연합 | **세계게이트대응연합 (WGA)** |
| 아카데미 | **국립 각성자 아카데미** |
| 선호의 길드 (국내 최대) | **백야 길드** |

## 2. 구성 원칙

| 항목 | 확정 내용 |
| --- | --- |
| 규모 | 중간 — 6명 |
| 태현의 인간관계 | 단 한 명 — 태현이 유일하게 곁을 허락한 사람 (서강민) |
| 연적 | 태현에게 다가오는 여자 한 명. 선호에게 다가오는 남자 연적은 두지 않음 |
| 보류 | 라이벌, 가족 관련 인물 — 플롯에서 필요하면 추가 |

### 연적 설계 원칙

| 항목 | 확정 내용 |
| --- | --- |
| 등장 시점 | 큰 줄기 ③ 재회 이후 |
| ③~④ 사이 | 아직 사랑을 자각하지 못한 선호가 이유 모를 불편함을 느끼게 함 |
| ⑦ 이후 | 선호의 질투·소유욕이 폭발하는 대상 |
| 성격 | 악역이 아님. 자기 삶과 이유를 가진 인물 |
| 태현과의 관계 | 태현이 어떻게 대할지는 유저가 결정 |

## 3. 조연 6명

### 한지호 — 아카데미 동기

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 남, 재회 시점 25세 |
| 소속 | 중견 길드, B급 |
| 성격 | 동기 중 가장 넉살 좋은 분위기 메이커 |
| 역할 | 동기 모임을 주최해 재회를 만듦. 아카데미 시절 두 사람이 붙어 다니던 것도, 고백 이후 태현이 선호를 지운 것도 다 봤음 |

### 서강민 — 협회 담당자 · 태현의 조력자

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 남, 30대 중반 |
| 소속 | 대한각성자협회 특별 의뢰 담당관 |
| 과거 | 부상으로 은퇴한 전직 A급 |
| 성격 | 늘 피곤해 보이고 말투는 무심하지만, 태현을 사람으로 대하는 유일한 어른 |
| 그림자 | 2년 동안 태현에게 가장 위험한 의뢰만 넘겨야 했던 것에 대한 죄책감 |
| 역할 | 무소속 태현에게 의뢰를 맡겨온 유일한 창구. ⑤ 수색 중 선호에게 2년 동안 태현이 어떻게 지냈는지 알려줌. ⑥ 구출 이후 선호 외에 태현 곁에 남는 단 한 사람 |

### 최명진 — 백야 길드장

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 남, 40대 후반 |
| 성격 | 국내 최대 길드를 키워낸 카리스마 |
| 선호와의 관계 | 선호를 후계자로 보고 아낌 |
| 태현과의 관계 | 태현을 영입하려다 거절당한 적 있음 |

### 한유리 — 백야 길드 동료

| 항목 | 내용 |
| --- | --- |
