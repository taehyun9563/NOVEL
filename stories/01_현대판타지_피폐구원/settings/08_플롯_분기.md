# 8단계 — 플롯·분기 v8.2

> 상태: 확정. 이 문서는 **최초 세계선의 기본 흐름**이다. 최초 세계선은 유동적이며, 유저 행동과 세계선 선택에 따라 언제든 벗어날 수 있다. 태현의 대사·행동은 RP에서 유저가 결정한다. 시기는 대략의 위치이며, RP 진행 속도는 `10_RP_운용.md`를 따른다.

## 1. 이야기 시작과 분기 구조

| 항목 | 확정 내용 |
| --- | --- |
| RP 시작 시점 | **한지호의 약혼 축하 자리에서의 재회 직전** (2026년) |
| 시작 이전 | 아카데미 시절, 1차 고백·거절, 수료 후 2년은 배경으로 고정 |
| 분기 방식 | 직접 선택 — 유저가 `분기`를 입력할 때 세계선이 갈림 (`10_RP_운용.md`) |
| 분기 지점 | 미리 정하지 않음. RP 중 **중요한 선택의 순간**(고백, 거절, 잠적 등)에 유저가 원하면 분기 |
| 최초 세계선 | 유동 — 유저 행동에 따라 언제든 벗어날 수 있음 |
| 세계선끼리의 연결 | 완전히 독립 — 누구도 다른 세계선을 기억하지 않음 |
| 결말 | 세계선 분기에 따라 다름 |

## 2. 최초 세계선의 기본 흐름

### 배경 — RP 시작 이전 (고정)

| 시기 | 태현 | 선호 |
| --- | --- | --- |
| 아카데미 | 첫눈에 반함. 2학년 중반 고백 → 거절 → 선호를 지움 | 친한 친구를 잃음 |
| 수료 후 2년 | 단독으로 다니며 최강이 됨. **선호를 한 번도 잊지 못함** | 백야 길드와 활동 |

### ③ 재회 ~ ④ 2차 거절

| 항목 | 내용 |
| --- | --- |
| 재회 | 한지호의 약혼 축하 자리 (평범한 식당·술집) |
| 이후 | 선호가 먼저 다가감. 공동 작전 속에서 가까워짐 |
| 태현의 행동 | 선호가 위험해질 때마다 나타나 구함 — **아직도 좋아하니까** |
| 응어리 | 선호는 전부 털어놓음, 태현은 사과만 하고 진짜 이유는 숨김 |
| 2차 고백 | 재회 약 3개월 후 → 거절 (친구를 또 잃을까 두려워서) → 곧바로 잠적 |

### ⑤ 잠적 (약 2개월)

| 항목 | 내용 |
| --- | --- |
| 세계의 대응 | 처음엔 협회가 실종을 은폐 → WGA가 알아채며 국제 문제로 커짐 |
| 선호의 수색 | 선호가 직접 찾음. 서강민과 공조, 백야 길드(최명진)의 지원 |
| 선호가 알게 되는 것 | 서강민에게서 2년 동안 태현이 어떻게 지냈는지 들음 → 사랑을 자각하기 시작 |

### ⑥ 구출

| 항목 | 내용 |
| --- | --- |
| 단서 | 아카데미 시절 태현이 **선호에게만 말해줬던 장소** — 선호는 잊었지만 태현은 기억하고 있던 곳 |
| 장소 | **아무도 없는 동굴** — 태현이 혼자 마음을 달랬던 곳. 마음을 달래던 곳에서 마음을 끝내려 함 |
| 진실 | 태현이 그곳을 골랐다는 것 자체가 진실. 선호는 발견하는 순간 "처음부터 친구가 아니었다"는 걸 깨달음 |

### ⑦ 구출 이후 — 기억상실 구간 (약 수주)

| 항목 | 내용 |
| --- | --- |
| 기억상실 | 깨어난 태현은 **선호에 대한 기억만 잃음**. 선호를 보면 이유 모를 불쾌감 |
| 기억상실의 원인 | **태현 자신의 마지막 의지** — 스스로를 꿰뚫기 직전 마지막으로 바란 것이 "그녀를 잊는 것". 검이 의지로 만들어지듯, 그 의지도 이루어짐 |
| 태현의 혼란 | 선호에 대한 기억이 없어서, 자신이 왜 자기파괴를 했는지 이해하지 못함 |
| 치료 시설 | 몸은 극단적 재생으로 바로 정상. 며칠 만에 퇴원 |
| 선호의 명분 | 치료 시설에 있는 동안 **협회 지정 담당 보호관** — 구출 당사자이자 재생 폭주·재잠적 시 대응 가능한 S급. 태현이 싫어해도 쫓아낼 수 없음 |
| 퇴원 이후 | 태현은 다시 단독 활동, 선호는 길드 활동. 선호의 집착은 태현을 멀리서 붙잡으려는 형태로 이어짐 |
| 몸이 기억함 | 선호가 위험해질 때마다 태현이 **자신도 모르게** 나타나 구함. 한두 번 반복 |

### 기억 회복

| 항목 | 내용 |
| --- | --- |
| 방식 | 몸이 먼저 기억함 → 결정적 순간에 전부 |
| 계기 | 선호가 죽을 위기에 처한 순간, 모든 기억이 한꺼번에 돌아옴 |
| 이후 | 콘셉트 설정의 갈등 축(선호의 다가감 ↔ 태현의 동정 의심)이 본격적으로 작동 |
| 태현 본인의 고백 | "처음부터 친구가 아니었다, 계속 좋아했다" — 말할지, 언제 말할지는 유저가 결정 |

## 3. 구조 — 반복되는 행동, 달라지는 이유

| 시기 | 태현이 선호를 구하는 이유 |
| --- | --- |
| 재회 이후 | 아직도 좋아해서 |
| 기억상실 중 | 이유를 모름 — 몸이 기억해서 |
| 기억 회복 순간 | 그 이유를 다시 알게 됨 |

| 시기 | 밀어내는 쪽 | 밀려나는 쪽 |
| --- | --- | --- |
| 아카데미 거절 이후 | 태현 (선호를 지움) | 선호 (친구를 잃음) |
| 기억상실 중 | 태현 (이유 모를 불쾌감) | 선호 (사랑을 자각한 채 밀려남) |
