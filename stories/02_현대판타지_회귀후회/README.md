## 진행 원칙

- 한 번에 한 단계씩 진행하고, 사용자가 고른 것만 **확정**한다.
- 제안은 **추천**, 정하지 않은 것은 **미정**으로 표시한다.
- 선택지를 낼 때는 항상 추천과 이유를 함께 적는다.
- 1~10단계 설계 완료. RP는 유저가 시작을 요청할 때 `settings/09_RP_운용.md`의 첫 장면부터 진행한다.
- RP를 이어갈 때는 `progress/진행_기록.md`를 읽고 마지막 장의 끝에서 시작한다.
