## 2. 회귀 구조

| 항목 | 확정 내용 |
| --- | --- |
| 1회차 | 태현이 선호에게 고백 → **선호가 거절** |
| 거절 횟수 | 1회차에서 **딱 한 번**. 이후 회차에서 태현은 다시 고백하지 않음 |
| 회귀 지점 | 2회차부터 매번 **거절 직후 그 자리** |
| 회귀의 결과 | 모든 회차에서 선호는 늘 **방금 태현을 찬 사람**으로 시작함. 태현은 매번 거절의 말이 귀에 남은 채 눈을 뜸 |
| 태현의 회차 | 매 회차 선호가 죽는 운명을 막고, 그 대가로 자신이 죽음. 선호는 이를 모름 |
| 회차 수 | **37회차** — 이번이 38번째 시작 |
| 태현이 강한 이유 | 37번의 죽음과 회차의 누적 — 그 강함은 전부 선호를 위해 죽은 횟수 |

## 3. 이번 회차 — 특이점

| 항목 | 확정 내용 |
| --- | --- |
| 누가 회귀하나 | **둘 다** — 태현과 선호 모두 회귀 |
| 선호가 얻는 것 | 태현이 지나온 회차들의 기억 |
| 기억을 얻는 방식 | **조각조각** — 꿈, 낯선 장소, 태현의 표정 등을 계기로 하나씩 |
| 서로의 인지 | 태현은 선호가 기억을 갖고 있다는 걸 **모름** |
| 특이점의 이유 | **미정** — 후반 미스터리로 남겨둠 |

## 4. 첫 장면

| 항목 | 확정 내용 |
| --- | --- |
| 순간 | 선호가 거절의 말을 막 내뱉은 직후, 등 돌린 태현을 보는 순간 |
| 기억의 양 | **조각 하나만** — 태현이 자기 대신 죽는 모습 하나 |
| 의미 | 방금 자기가 찬 남자가, 자기를 위해 서른일곱 번 죽은 사람이라는 걸 아는 순간 |

## 5. 이야기를 굴리는 장치 *(추천)*

| 장치 | 내용 |
| --- | --- |
| 기억 조각 | 선호가 기억 하나를 볼 때마다 새 후회와 새 사건이 생김 |
| 사망 플래그 | 이번 회차에도 선호의 죽음 운명이 다가오고, 태현은 또 대신 죽으려 함 |
| 들킬까 말까 | 선호가 기억을 갖고 있다는 걸 태현이 언제 알게 되는지 — 유저가 선택하는 큰 분기 |
