# 2단계 — 세계관 v1.0

> 상태: 확정. 이 문서의 추천안은 사용자가 승인한 것이다.

## 1. 세계의 기본 규칙

| 항목 | 확정 내용 |
| --- | --- |
| 세계 이변 | 게이트 — 게이트가 열리고 몬스터가 나옴 |
| 게이트 최초 발생 | 약 20년 전 — 이야기 시점엔 세계가 이미 적응한 상태 |
| 일반인의 인식 | 게이트는 공개. 사람들은 재난처럼 받아들임 |
| 시대 | 2026년 |

## 2. 헌터 사회의 구조

| 항목 | 확정 내용 |
| --- | --- |
| 구조 | **국가 직속** — 헌터는 국가 기관 소속, 팀 단위로 배치 |
| 기관 | **국가게이트대응청** (작중 '대응청') |
| 두 사람의 팀 | 대응청 직속 **특무 1팀** — 최고 난도 게이트 전담 |
| 팀 규모 | 5~6명 |

## 3. 회귀와 맞물리는 시간 구조

| 항목 | 확정 내용 |
| --- | --- |
| 거절·회귀 시기 | **현역 시절** — 태현과 선호 모두 이미 헌터로 활동 중 |
| 거절의 의미 | 선호가 찬 것은 같은 팀에서 믿고 지내던 동료 |
| 운명의 날 | 첫 장면(거절 직후)으로부터 **6개월 뒤** |

## 4. 운명의 날 — 대재앙 게이트

| 항목 | 확정 내용 |
| --- | --- |
| 정체 | 매 회차 **같은 날, 같은 곳**에 열리는 초대형 게이트 |
| 장소 | 서울 도심 |
| 선호의 운명 | 그 게이트 안에서 죽음 |
| 태현 | 37번 그 게이트를 겪은 유일한 사람 |
