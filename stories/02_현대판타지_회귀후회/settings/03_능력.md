# 3단계 — 능력 v1.0

> 상태: 확정. 이 문서의 추천안은 사용자가 승인한 것이다. 태현의 대사·대답은 RP에서 유저가 결정한다.

## 1. 등급 체계

| 항목 | 확정 내용 |
| --- | --- |
| 등급 | F~S급 — S급이 공식 최상위 |

## 2. 두 사람의 공식 위치

| 항목 | 박태현 | 김선호 |
| --- | --- | --- |
| 공식 등급 | **B급** | **S급** |
| 특무 1팀에서의 위치 | 눈에 띄지 않는 B급 검사 | 팀의 에이스이자 얼굴 |
| 실제 | **측정 불가** — 37회차의 누적. 아무도 모름 | 공식 등급 그대로 |
| 능력 계열 | 검 | 검술 |

| 항목 | 확정 내용 |
| --- | --- |
| 태현의 강함 | **숨김** — 공식적으론 평범한 팀원 |
| 거절의 무게 | S급 에이스 선호가 B급 동료 태현을 찬 것. 주변 눈엔 당연해 보이는 거절 |

## 3. 태현의 두 자루 검

| 항목 | 확정 내용 |
| --- | --- |
| 차는 방식 | 허리 한쪽에 두 자루를 몰아서 참 |
| 숨기는 검 | 대응청 지급 표준 장검. 바깥쪽, 늘 이것만 뽑음 |
| 진심의 검 | 안쪽에 붙어 있는 검. 팀원들은 예비검쯤으로 앎 |
| 진심의 검을 뽑는 때 | **선호가 위험할 때만** — 37회차 동안 전부 선호를 지키려고 뽑혔음 |
| 진심의 검과 회귀 | **연결 없음** — 회귀 능력이 깃든 검이 아님 |
| 첫 공개 | 이번 회차 중 팀 앞에서 처음 안쪽 검에 손이 가는 순간 = 큰 전환점 |

### 단골 농담

| 항목 | 확정 내용 |
| --- | --- |
| 농담 | "하나만 쓰면서 왜 두 자루나 들고 다니냐" — 팀의 단골 장난 |
| 가장 많이 놀리던 사람 | 선호 — 거절 전까지 가장 편하게 장난치던 사이 |
| 이번 회차 선호 | 그 농담을 하려다 말이 목에 걸림. 남들이 장난칠 때 혼자 웃지 못함 |
| 첫 공개 이후 | 농담이 팀에서 사라짐 — 장난이 미안함으로 바뀜 |
| 태현의 대답 | RP에서 유저가 결정 |

## 4. 회귀 능력

| 항목 | 확정 내용 |
| --- | --- |
| 원리 | 태현의 **숨은 고유 능력** — 1회차에서 선호를 잃은 순간 처음 발현 |
| 발동 조건 | **선호를 지키다 죽을 때만** — 다른 이유로 죽으면 진짜 끝 |
| 대가 | **감정이 조금씩 닳음** — 초반 회차의 태현은 잘 웃었지만, 지금은 거의 웃지 않음 |
| 선호가 보는 것 | 기억 조각 속 웃던 태현과 지금의 태현의 차이 — 그게 전부 자기 때문이라는 것 |
