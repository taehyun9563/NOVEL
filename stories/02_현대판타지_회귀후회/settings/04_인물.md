## 2. 김선호

### 외형

| 항목 | 확정 내용 |
| --- | --- |
| 나이 (첫 장면) | 25세 |
| 키·체형 | 167cm, 날렵하고 탄탄한 체형 |
| 머리 | 흑발 긴 생머리. 평소엔 풀고, 전투 때만 하나로 묶음 |
| 눈 | 크고 또렷한 눈. 표정이 다 드러남 |
| 인상 | 늘 웃고 있음. 자신감 있는 표정 |
| 복장 | 특무 1팀 에이스 전투복. 몸에 맞게 손본 흔적 |

### 성격과 배경

| 항목 | 확정 내용 |
| --- | --- |
| 평소 성격 (기억이 돌아오기 전) | **밝고 털털한 분위기 메이커 + 실력에 자부심 강한 에이스** — 누구에게나 친근하지만, 그 밑에 S급의 자존심이 깔려 있음 |
| 가족 | 평범한 가정. 가족과 사이 좋음 |
| 헌터가 된 계기 | 19세 각성, 처음부터 S급 판정 → 대응청 스카우트 |
| 특무 1팀 합류 | 첫 장면 기준 3년 전 — 팀 경력은 태현보다 1년 위 |
| 태현과의 관계 (거절 전) | 팀에 먼저 자리 잡은 쪽으로서 태현을 챙기던 쪽. 가장 편하게 장난치던 사이 |

### 태현을 부르는 호칭

| 항목 | 확정 내용 |
| --- | --- |
| 나이·경력 | 나이는 태현이 1살 위, 팀 경력은 선호가 1년 위 |
| 호칭 | **반말 + "태현아"** — 서로 말을 튼 사이 |
| 주의 | 선호는 자신을 "선배"라고 칭하지 않음 |
| 거절 이후 | 편하게 부르던 그 반말과 이름이 어색해지는 것이 변화의 신호 |

### 거절의 이유

| 구분 | 내용 |
| --- | --- |
| 선호가 믿는 이유 | 동료로만 봐서 |
| 실제로 섞여 있던 것 | B급 동료는 남자로 안 보였음 |
| 깨닫는 시점 | 기억 조각을 보며 스스로 깨달음 — 후회가 태현에 대한 미안함을 넘어 자기 자신에 대한 수치로 감 |
