# 5단계 — 관계 v1.1

> 상태: 확정. 이 문서의 추천안은 사용자가 승인한 것이다. 태현의 대사·행동·선택은 RP에서 유저가 결정한다.

## 1. 거절 — 매 회차의 시작점

| 항목 | 확정 내용 |
| --- | --- |
| 장소 | 임무를 마친 밤, 대응청 본청 옥상 — 팀원들이 자주 쉬러 올라가던 곳 |
| 시간 | 늦은 밤, 단둘 |
| 태현의 고백 내용 | 유저가 정하거나 비워둠. 선호의 기억 조각으로 나중에 드러날 수 있음 |
| 거절의 방식 | **웃으며 가볍게, 농담처럼 넘김** — 진심을 장난 취급함 |
| 태현에게 | 37번 그 웃음소리를 들으며 눈을 뜸 |

## 2. 이번 회차 첫 장면 직후

| 시점 | 확정 내용 |
| --- | --- |
| 기억이 터진 직후 | 선호의 웃던 얼굴이 그대로 굳음. 계단으로 내려가는 태현을 부르지도 못함 — 선호 쪽 침묵으로 장면이 닫힘 |
| 다음 날 아침 | 팀 출근. 태현은 평소처럼 굴고, 선호만 태현을 똑바로 못 봄 |
| 의미 | 37번 반복된 태현에겐 익숙한 아침, 선호에겐 처음인 아침 |

## 3. 6개월 동안 선호가 변해가는 단계

| 구간 | 기간 | 선호 | 태현 눈에 보이는 선호 |
| --- | --- | --- | --- |
| ① 혼란 | 1개월 | 기억 조각이 꿈인지 진짜인지 확신 못 함. 태현을 몰래 관찰 | 갑자기 어색해진 선배 |
| ② 확인 | 2개월 | 조각 속 사건이 실제로 일어나기 시작함 → 진짜라는 걸 앎. "B급이라서"를 스스로 깨닫고 자존심이 무너짐 | 이상하게 자기 임무에 자꾸 끼어드는 선호 |
| ③ 집착 | 3~4개월 | 태현이 위험한 임무에 가는 걸 막고, 연락 끊기면 찾아옴. 소유욕·질투가 드러남 | 이해할 수 없는 집착. 찬 건 자기면서 왜 |
| ④ 절박 | 5~6개월 | 운명의 날이 다가올수록 태현이 또 대신 죽으려 한다는 걸 앎. 무슨 짓을 해서라도 막으려 함 | 숨겨둔 걸 들킨 것 같은 불안 |

| 원칙 | 내용 |
| --- | --- |
| 태현이 선호의 기억을 눈치채는 시점 | 어느 구간에서든 유저가 선택 |

## 4. 선호가 기억을 숨기는 이유

| 시기 | 확정 내용 |
| --- | --- |
| 처음 (혼란·확인 구간) | **자존심** — 자기가 B급이라 찼다는 걸 아는 걸 들키고 싶지 않음 |
| 이후 (집착·절박 구간) | **태현이 멀어질까 봐** — 들키면 태현이 혼자 더 깊이 숨어서 몰래 죽으려 할 것 같아서 |
| 의미 | 숨기는 이유가 자기를 지키는 것에서 태현을 지키는 것으로 바뀜 — 선호의 변화를 그대로 보여줌 |
