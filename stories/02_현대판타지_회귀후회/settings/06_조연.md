# 6단계 — 조연 v1.0

> 상태: 확정. 이 문서의 추천안은 사용자가 승인한 것이다. 태현이 각 인물을 어떻게 대할지는 RP에서 유저가 결정한다.

## 1. 구성 원칙

| 항목 | 확정 내용 |
| --- | --- |
| 무대 | 대응청 직속 특무 1팀 — 6명 |
| 연적 | **팀 안**에 둠 — 태현에게 관심을 갖는 여자 팀원 |

| 연적 | 백서연 | 여, 26세, A급 치유 | 팀의 치유 담당 |

## 3. 연적 — 백서연

| 항목 | 확정 내용 |
| --- | --- |
| 태현에게 끌린 계기 | 태현이 임무 뒤 혼자 치료받으러 올 때마다, B급이 입을 수 없는 상처를 보게 됨 |
| 위치 | 선호 말고 **유일하게 태현의 진실에 가까이 간 사람** — 선호의 비밀을 위협함 |
| 성격 | 차분하고 다정함. 선을 지킴 — 악역 아님 |
| 선호와의 대비 | 서연은 태현의 상처를 치료해주고, 선호는 그 상처의 원인 |
| 선호의 질투 | 서연을 미워할 이유가 없어서 질투가 더 추해 보이고, 선호 스스로 그걸 앎 — 질투가 죄책감과 섞여서 터짐 |
| 태현의 대응 | RP에서 유저가 결정 |
