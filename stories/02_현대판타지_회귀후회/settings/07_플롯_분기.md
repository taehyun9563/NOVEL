# 7단계 — 플롯·분기 v1.0

> 상태: 확정. 이 문서는 이번 회차(38번째)의 기본 흐름이다. 태현의 대사·행동·선택은 RP에서 유저가 결정하며, 유저 행동에 따라 흐름은 언제든 달라질 수 있다.

## 1. 6개월의 주요 사건

| 시기 | 구간 | 주요 사건 |
| --- | --- | --- |
| 1개월 | 혼란 | 첫 기억 조각(태현이 대신 죽는 모습). 선호가 그 조각 속 게이트와 같은 이름의 임무 공지를 봄 |
| 2개월 | 확인 | 조각에서 본 사고가 그대로 일어남. 선호가 처음으로 미래를 바꾸려 개입하고, 태현이 "어떻게 알았지?" 하는 눈으로 선호를 봄 |
| 3개월 | 집착 | 서연이 태현의 상처에 의문을 품기 시작함. 선호의 질투가 처음 터짐 |
| 4개월 | 집착 | **진심의 검이 팀 앞에서 처음 뽑힘** — 선호가 위험한 순간. 두 자루 농담이 팀에서 사라짐 |
| 5개월 | 절박 | 선호가 기억 조각으로 운명의 날에 태현이 할 행동을 앎. 이번 회차가 지난 37번과 어긋나기 시작해 태현의 회귀 지식도 흔들림 |
| 6개월 | 절박 | **운명의 날 — 서울 도심 대재앙 게이트**. 태현의 선택에 따라 분기 |

| 구조 | 내용 |
| --- | --- |
| 전반 / 후반 | 진심의 검 공개(4개월)를 기준으로 전반은 비밀, 후반은 폭로 이후 |
| 태현이 선호의 기억을 눈치채는 시점 | 어느 시기든 유저가 끼울 수 있음 |

## 2. 운명의 날 이후 — 분기

| 결과 | 이어지는 이야기 |
| --- | --- |
| 태현이 살아남음 | **회귀 없는 첫 미래** — 갈등 축(닳은 감정)이 본격적으로 작동 |
| 태현이 또 대신 죽음 | **39회차** — 이번엔 둘 다 기억을 가진 채 시작 |
| 결정 | 운명의 날 태현의 선택은 유저가 결정 |

## 3. 갈등 축

| 항목 | 확정 내용 |
| --- | --- |
| 태현의 경계 | 쓰지 않음 |
| 닳은 감정 | 회귀의 대가로 태현의 감정이 닳아 있어서, 선호가 아무리 다가가도 태현이 그걸 제대로 느끼지 못함. **밀어내는 게 아니라 닿지 않는 것** |
| 선호의 과제 | 태현을 살리는 것에서, 닳아버린 태현이 다시 웃게 만드는 것으로 넘어감 |
| 태현 쪽 | 이 상태를 어떻게 연기할지, 회복할지는 유저가 결정 |
