# 8단계 — 기술 v1.0

> 상태: 확정. 기술 이름 중 태현의 필살기·비기 이름은 사용자가 직접 정했고, 한자·장면과 선호의 기술은 추천안을 사용자가 승인한 것이다.

## 1. 기본 규칙

| 항목 | 확정 내용 |
| --- | --- |
| 명칭 방식 | 웹소설·애니메이션풍 한자어 — 「한글(한자)」 표기 |
| 구성 | **필살기 5개 + 비기 1개**만 이름이 있음. 나머지는 이름 없는 검술로, 서술로만 표현 |
| 외침 | 이름 있는 기술(필살기·비기)만 외침 |
| 태현의 테마 | **새벽** |
| 선호의 테마 | **햇살** |
| 태현의 검 구분 | 숨기는 검 기술과 진심의 검 기술을 **나눔** |

## 2. 박태현

### 숨기는 검

| 항목 | 내용 |
| --- | --- |
| 기술 | 대응청 표준검술 — 이름 없음. 교본 그대로의 평범한 베기. 누가 봐도 B급 |

### 진심의 검 — 「미명(未明)」

| 항목 | 내용 |
| --- | --- |
| 이름의 뜻 | "아직 밝지 않은 때" — 37번 동안 끝내 새벽을 보지 못한 사람의 검 |
| 평소 검술 | 새벽빛처럼 소리 없이 빠른 검. 이름 없이 서술 |

| 단계 | 기술명 | 장면 |
| --- | --- | --- |
| 필살기 | 「초광(初光)」 | 밤의 끝에 맺히는 첫 빛 한 점 — 가장 빠른 찌르기 |
| 필살기 | 「효광(曉光)」 | 새벽빛이 번지듯 검기가 사방으로 퍼지는 광역 베기 |
| 필살기 | 「여명(黎明)」 | 어둠 전체를 한 줄로 가르는 일섬 |
| 필살기 | 「개명(開明)」 | 닫힌 어둠이 열리며 밝아짐 — 막힌 것을 통째로 베어 여는 참격 |
| 필살기 | 「광명(光明)」 | 온 하늘이 밝아진 듯, 시야를 빛으로 채우는 연격 |
| 비기 | 「여명개벽(黎明開闢)」 | 새벽이 오고 세상이 열림. 밤 자체가 갈라지고, 그 너머로 새 하늘이 펼쳐짐 |

흐름: 초광 → 효광 → 여명 → 개명 → 광명 → 여명개벽. 첫 빛 한 점에서 시작해 세상이 열리기까지.

## 3. 김선호

| 항목 | 내용 |
| --- | --- |
| 평소 검술 | 햇살처럼 곧고 밝은 검. 이름 없이 서술 |

| 단계 | 기술명 | 장면 |
| --- | --- | --- |
| 필살기 | 「조양(朝陽)」 | 아침 해가 뜨듯 아래에서 위로 크게 올려 베기 |
| 필살기 | 「난양(暖陽)」 | 따뜻한 햇살이 감싸듯, 검기가 둥글게 퍼지며 동료를 지키는 방어 베기 |
| 필살기 | 「일휘(日輝)」 | 햇빛이 반짝이듯 순식간에 수십 번 찌르는 연격 |
| 필살기 | 「백일(白日)」 | 눈부신 흰 해 — 시야를 하얗게 지우고 들어가는 일격 |
| 필살기 | 「정오(正午)」 | 해가 가장 높은 순간, 그림자 하나 남기지 않는 사방 베기 |
| 비기 | 「천양(天陽)」 | 하늘에 또 하나의 해가 떠오르며 모든 것을 비춤 |

흐름: 조양 → 난양 → 일휘 → 백일 → 정오 → 천양. 아침에서 한낮까지. 「난양」은 남을 챙기던 에이스의 성격을 담은 유일한 방어 기술.

## 4. 두 사람의 대비

| 구분 | 박태현 | 김선호 |
| --- | --- | --- |
| 테마 | 새벽 — 밤의 끝 | 햇살 — 새벽 다음에 오는 것 |
| 비기 | 「여명개벽」 — 밤이 갈라지고 세상이 열림 | 「천양」 — 하늘에 해가 뜸 |

태현의 기술이 새벽에서 끝나는 자리에서, 선호의 기술이 시작된다.
