## 1. 작품 기본 정보

| 항목 | 확정 내용 |
| --- | --- |
| 가제 느낌 | 공기 같은 사람 |
| 형식 | 소설·RP 공용 설정 |
| RP 시 유저 | 남자 주인공 박태현 |
| 남자 주인공 | 박태현 |

## 2. 큰 줄기

| 순서 | 사건 |
| --- | --- |
| ① | 20년 소꿉친구. 선호에게 태현은 늘 옆에 있는 공기 같은 사람 |
| ② | 태현이 해외로 떠남 |
| ③ | 3년 동안 선호는 빈자리 속에서 그게 사랑이었다는 걸 깨달음 |
| ④ | 태현 귀국 — **RP 시작** |
| ⑤ | 선호의 직진. 태현은 당황하고 쉽게 믿지 않음 |
| ⑥ | 연애 시작 |
| ⑦ | 연애 중 — 달달함 + 선호의 집착·질투·애정 확인 |
| ⑧ | 결말 |

## 3. 핵심 설정

| 항목 | 확정 내용 |
| --- | --- |
| 태현이 떠난 이유 | 명분은 유학·발령. **진짜 이유는 선호를 향한 오래된 짝사랑을 정리하려고** |
| 3년 동안의 연락 | 완전히 끊지는 않음 — 가끔 형식적인 연락만 |
| 선호의 직업·상황 | 태현과 **같은 업계·회사** — 귀국 후 일로 자주 마주침 |

### 같은 3년, 다른 마음

| 구분 | 태현 | 선호 |
| --- | --- | --- |
| 떠날 때 | 마음을 정리하러 감 | 잠깐 다녀오는 줄 앎 |
| 3년 동안 | 짧은 답장으로 거리를 둠 | 짧은 답장에 서운해하다 빈자리를 실감 |
| 귀국할 때 | 정리했다고 믿음 | 이번엔 절대 안 놓친다고 결심 |
