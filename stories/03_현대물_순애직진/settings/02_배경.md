# 배경 v1.0

> 상태: 확정. 사용자가 추천안 전체를 승인했다.

## 1. 업계와 회사

| 항목 | 확정 내용 |
| --- | --- |
| 업계 | **게임 회사** |
| 태현의 3년 | 회사의 해외 스튜디오에서 근무 (떠날 때의 명분 = 해외 발령) |
| 귀국 형태 | 한국 본사로 돌아오며 **선호가 속한 팀의 새 팀장**으로 부임 |
| 회사에서의 관계 | 태현 = 팀장, 선호 = 팀원 |
| 호칭 | 회사에선 "팀장님" · 존댓말 / 회사 밖에선 이름 · 반말 |

공과 사의 갭이 핵심 장치. 회사에서는 선을 지켜야 하고, 선호는 그 선 위에서 직진한다.

## 2. 사는 곳

| 항목 | 확정 내용 |
| --- | --- |
| 도시 | 서울 |
| 거주 | **어릴 때부터 옆집** — 태현이 귀국해 다시 옆집으로 |
| 양가 | 서로의 부모님과도 가족처럼 지낸 사이 |

선호가 직진할 판이 회사와 집, 두 군데로 깔린다.
