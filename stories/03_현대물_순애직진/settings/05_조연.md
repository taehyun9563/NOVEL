# 조연 v1.0

> 상태: 확정. 조연 프로필은 추천안을 사용자가 승인한 것이다. 태현이 각 인물을 어떻게 대할지는 RP에서 유저가 결정한다.

## 1. 구성 원칙

| 항목 | 확정 내용 |
| --- | --- |
| 규모 | 5명 |
| 태현 쪽 여자 | 사진 속 동료 — 함께 한국으로 파견 옴. 악역 아님 |
| 선호 쪽 남자 연적 | **두지 않음** — 선호의 직진·소유욕에 집중 |
| 조력자 | 선호 편 1명(회사 단짝) + 태현 편 1명(고향 친구) |
| 부모님 | 엄마 둘만 비중 있게. 아빠 두 분은 이름 없이 배경 |

## 2. 조연 5명

### 엘리 정 (정은서) — 사진 속 동료

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 여, 30세, 캐나다 교포 |
| 소속 | 해외 스튜디오(캐나다 몬트리올) 리드 게임 디자이너 → 태현과 함께 한국 본사로 1년 파견 |
| 성격 | 쾌활하고 쿨함, 선을 확실히 지킴 |
| 비밀 | 3년 동안 술자리에서 태현의 짝사랑 얘기를 다 들어서, 태현이 누굴 좋아하는지 알고 있음 |
| 역할 | 선호의 질투 대상. 동시에 선호가 진심이라는 걸 알아채고 몰래 재미있어하는 관찰자 |

### 오다은 — 선호의 회사 단짝

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 여, 28세 |
| 직무 | 같은 팀 배경 원화가 |
| 성격 | 직설적, 연애 고수인 척하지만 실전 경험은 별로 없음 |
| 역할 | 선호 편. 직진을 부추기고 작전을 짜줌. 회사에서 둘 사이를 가장 먼저 눈치챔 |

### 이도윤 — 고향 친구

| 항목 | 내용 |
| --- | --- |
| 성별·나이 | 남, 29세 |
| 직업 | 셋이 자란 동네에서 작은 카페 운영 |
| 성격 | 느긋하고 눈치 빠름 |
| 역할 | 태현 편. 고백 그날 밤의 사정을 아는 유일한 친구. "이번엔 진짜일걸?"이라며 태현을 흔듦. 카페가 셋의 아지트 |

### 한영숙 — 태현의 엄마

| 항목 | 내용 |
| --- | --- |
| 나이 | 58세 |
| 성격 | 수다스럽고 추진력 강함 |
| 역할 | 20년 전부터 선호를 며느리로 점찍음. 아들 마음을 다 알고 있음 |

### 이정희 — 선호의 엄마

| 항목 | 내용 |
| --- | --- |
| 나이 | 57세 |
| 성격 | 느긋해 보이지만 계획적 |
| 역할 | 태현을 아들처럼 아끼고, 딸보다 태현 편. 영숙과 콤비로 가족 모임을 핑계 삼아 판을 깔아줌 |
