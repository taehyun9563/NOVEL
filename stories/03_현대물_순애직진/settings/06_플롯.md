# 플롯 v1.0

> 상태: 확정. 이 문서는 **기본 흐름**이다. 태현의 대사·행동·선택은 RP에서 유저가 결정하며, 어떤 선택을 해도 결말은 선호와의 달달한 연애(단일 해피엔딩)로 도착한다.

## 1. 이름

| 항목 | 확정 이름 |
| --- | --- |
| 회사 | **루미나 게임즈** |
| 신작 프로젝트 | **〈프로젝트 아스테라〉** |

## 2. 배경 — RP 시작 이전 (고정)

| 시기 | 사건 |
| --- | --- |
| 9살 | 옆집으로 만남 |
| 중학생 | 선호가 처음으로 태현의 그림을 그려줌 → **태현이 좋아하게 된 계기**. 선호는 잊었고, 태현은 아직 간직 중 |
| 출국 전날 밤 (2023년 말) | 태현 고백 → 선호가 장난으로 웃어넘김 → 다음 날 출국 |
| 3년 | 태현은 몬트리올 스튜디오. 선호는 SNS 사진(엘리)을 보고 질투로 사랑을 자각 |

## 3. 기본 흐름

| 순서 | 시기 | 사건 |
| --- | --- | --- |
| 1 | 2026년 12월 초 | 태현 귀국, 선호 팀의 새 팀장으로 부임. 엘리도 함께 파견 옴. 다시 옆집 |
| 2 | 12월 초~중순 | 선호의 직진 시작 — "그 여자 누구야". 태현은 장난으로 받아들임 |
| 3 | 12월 셋째 주 연말 회식 | **엘리가 선호에게 진실을 흘림** — 태현이 3년 내내 누구 얘기를 했는지. 선호가 "나 때문에 떠난 거였어?"를 깨달음 → 가벼운 후회, 직진에 진심이 실림 |
| 4 | 크리스마스 | 엄마들이 판을 깐 양가 모임. 직진의 정점 |
| 5 | **2027년 1월 1일 해돋이** | 연애 시작 (기본 흐름 기준 — 태현의 대답은 유저) |
| 6 | 2027년 상반기 | **사내 비밀 연애** — 비밀로 하자는 쪽 vs 티 내고 싶은 선호 |
| 7 | 연애 중 | 선호가 태현 방에서 **중학생 때 자기가 그린 그림**을 발견 — 15년 짝사랑의 증거 |
| 8 | 2027년 가을, 엘리 파견 종료 무렵 | **태현에게 해외 스튜디오 복귀 제안** → "또 떠날까 봐" 선호의 집착이 크게 터지는 클라이맥스. 받을지는 유저가 결정 |
| 9 | 결말 | **프러포즈** — 누가 먼저 할지는 RP에서 |
