## 2. 장별 요약

| 장 | 요약 |
| --- | --- |
| 제1장 공고 | 지명 결투 공고. 레온이 도발하다 웅덩이에 미끄러짐. 그레이가 결투 전날 따로 시험함. 밤에 학원장실에서 "귀찮은 건 질색"이라고만 답하고 창문으로 나감(관측대의 누군가가 봄). 결투는 10초 3에 패배. 선호의 "일부러 맞았지"에 "글쎄" |
| 제2장 후폭풍 | 갈비뼈 무손상, 실기 7일 면제. 레온이 내기 조작이라 몰아붙임. 그레이가 연습검을 주고 새벽 6시 보충 수업을 명함. 도서관에서 선호의 재대결 요구에 "지금 질래", "변태". 식당에서 리안 벨을 괴롭히는 레온에게 "화풀이 상대 잘못 골랐다", "쪼잔하네". 선호가 학칙으로 레온을 물림 |
| 제3장 해 질 녘 | 별관 재대결(판돈: 태현이 지면 질문 하나, 선호가 지면 다시 안 찾음 — 태현의 요구 "평온한 일상"). 「은월참」에 패배. "왜 꼴찌인 척해?" → "졸업장 필요해서. 무적자라. 눈에 띄면 안 되고, 퇴학당해도 안 되고". 보충 수업에서 일부러 원 밖으로. 레온의 숨긴 오러를 엉덩방아로 피함, 레온 벌점 8. 토벌 실습 공고 |
| 제4장 편성표 | 1조 = 선호·태현·세라 윈·노엘 크레인. 노엘과 친구. 작전 회의에서 북쪽 경계 밖 긁힌 흔적. 선호의 질문에 "몰라" |
| 제5장 북쪽 숲 | 첫날 밤 혼자 바위등 곰(중급 상위)을 맨손과 칼집 끝으로 기절시킴. 세라는 "광폭 룬 과부하, 운"으로 결론, 선호는 칼집 자국을 봄, 그레이는 멍을 엄지로 잼. 실습 중단. 학원장이 쇠고리·가짜 무명·카이렌 소식을 전함. 다음 날 새벽 그레이가 "서부 전선에서 내 옆을 지나간 게 너냐" → "아뇨" → "아니라고 해두지". 태현이 나가며 "열한 분 감사 인사는 받았다고 전해달래요" → 그레이가 말없이 앎. 보충 수업이 "꼴찌 지키는 법"으로 바뀜 |
| 제6장 결함 | 그레이는 학원장에게 보고서대로만 말함. 세라가 룬 과부하는 외부 충격(마스터급)이라며 조사단 결성(세라·도윤, 노엘은 대답만), 태현은 "귀찮아". 교대 시간 질문에 "나도 졸아서 몰라" — 세라가 개울가의 "조용했다"와 어긋남을 짚음. 선호가 카이렌의 편지(아카데미 내 조건 해당자 이름 요청)와 7명 명단을 받고 보내지 않기로 함. 별관에서 태현에게 명단 얘기를 털어놓음 → "몰라요. 왜 저한테. 나머지 여섯 명한테도 말해줘야죠" |
| 제7장 넘어지는 법 | 조사단이 공고 전 편성을 물은 3명 추적: 카스파(레온 추종자) 해당 없음, 리안 벨 찜찜, 후드 쓴 마법과 학생 미상. 리안이 넘어지는 법을 배우러 옴 → "귀찮아". 학기말 순위전 공지(최소 1승 못 하면 퇴학 심사). 레온의 추첨 조작 소문 → 선호가 학원장에게 공개 추첨 건의("꼴찌하고는 상관없습니다" 세 번) |
| 제8장 순위전 | 공개 추첨인데 1회전 레온, 2회전 도윤. 레온의 「사자후」에 짐. 도윤에게 짐(어깨 부상이 실제로 영향) — "봐준 거 아니지?" → "몰라, 귀찮아". 3회전 마르텐(집안 빚)에게 짐. 선호가 그레이를 찾아가고, 그레이는 "숨는 쪽에 서겠다". 4회전 선호에게 「황익」·「은월참」으로 짐, 그레이의 연습검이 부러짐 — 선호 "그 검, 미안". 0승 4패. 5회전 카스파전 직전 「새」 습격: 발카스 룬 반구, 카스파 기절, 그레이 사슬에 묶임, 선호 튕겨 나감, 도윤이 사슬에 매달림 — "218호. 룸메이트지. 무명이 여기 있다면 지금 뽑아라". 태현이 손을 하늘로 뻗어 학원장실 책장 뒤의 진짜 검을 부름 → **첫 발도**, 「적섬」으로 사슬 전부를 끊고 가면 왼쪽을 깸. 「새」는 쇠 원반으로 도주. 검을 하늘로 던져 학원장실로 돌려보내고 쓰러짐. 관중은 반구를 뚫은 검붉은 빛을 봤지만 안은 못 봄 → 그레이나 선호를 의심, 꼴찌는 웃음거리. 근위대 질문에 그레이 "아니다", 선호 "못 봤다"(처음으로 거짓말). 학원장이 순위전 중단 선언. 도윤이 "……너지?" |

## 8. 태현 메모 (유저가 보여준 말투·태도)

- 대답은 짧고 늘어짐: "글쎄", "몰라", "귀찮아", "응", "…에휴"
- 툭 던지는 한마디로 상대를 무너뜨림: "넥타이 매줄래?", "쪼잔하네", "변태"
- 교관·학원장에게는 존댓말. 선호에게는 존댓말이 기본이고 가끔 반말. 노엘·도윤에게는 반말
- 정체는 끝까지 부정하거나 얼버무리지만, 그레이에게는 "그 사람이 받았다고 전해달래요"처럼 돌려서 건넴
- 진심으로 나설 때는 말이 짧아짐: "귀찮게 하네…" → 「적섬」
- 큰 선택은 "알아서"로 맡기는 일이 많음
