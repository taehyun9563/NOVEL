# 콘셉트 v1.0

> 상태: 확정. 로그라인을 바탕으로 사용자가 승인했다.

## 로그라인

> 제국 최고의 아카데미에서 최하위 성적을 유지하는 태현.
> 누구도 모르지만 그는 이미 대륙 최강의 검사다. 평범한 졸업을 원하던 그의 계획은 황녀가 공개 결투에서 그를 지목하면서 무너지기 시작한다.

## 1. 기본 정보

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 가제 | 낙제생은 검을 뽑지 않는다 | 확정 |
| 형식 | 소설·RP 공용 — RP 시 유저 = 박태현 | 확정 |
| 장르 | 제국 정통 판타지 · 아카데미 · 숨은 최강 | 확정 |
| 키워드 | 숨은 최강, 아카데미, 성장, 통쾌 | 확정 |
| 톤 | 가볍고 통쾌하게 | 확정 |
| 연애·히로인 | 정하지 않음. 유저가 말할 때 정함 | 미정 |
| 결말 | 정하지 않음. RP에서 흘러가는 대로 | 미정 |

## 2. 핵심 설정

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 태현 | 제국 최고 아카데미의 최하위생. 실은 대륙 최강의 검사 | 확정 |
| 정체 | 3년 전 대륙 전쟁을 끝내고 사라진 정체불명의 검사. 제국은 아직 그를 찾고 있음 | 확정 |
| 사라진 이유 | 영웅으로 불려 다니는 게 싫어서. 그냥 평범하게 살고 싶음 | 확정 |
| 아카데미에 온 이유 | 전쟁고아라 신분이 없음. 졸업하면 제국 정식 신분이 나옴 | 확정 |
| 최하위인 이유 | 눈에 띄면 안 되고, 퇴학당해도 안 됨. 딱 졸업할 수 있는 선에 맞춤 | 확정 |
| 검을 뽑지 않는 이유 | 그 검술은 전쟁에서 대륙 전체가 본 것이라, 뽑는 순간 정체가 드러남 | 확정 |
| 황녀 | 제국 황녀. 이름과 성격은 주요 인물 문서에서 | 미정 |
| 결투 지목 | 황위 경쟁 때문에 힘을 보여줘야 하는 황녀가, 본보기로 낙제생을 지목함 | 확정 |

## 3. 큰 줄기

| 순서 | 사건 |
| --- | --- |
| ① | 공개 결투. 태현은 검을 뽑지 않고 짐 — **RP 시작** |
| ② | 황녀가 뭔가 이상하다는 걸 느끼고 태현을 눈여겨봄. 평범한 졸업 계획이 흔들림 |
| ③ | 아카데미 사건들이 이어지면서 숨기기가 점점 어려워짐 |
| ④ | 태현이 처음으로 검을 뽑음 |
| ⑤ | 소문이 퍼지고 제국과 여러 세력이 움직임 |
| ⑥ | 그 뒤는 RP에서 |
