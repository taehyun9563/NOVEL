## 2. 3년 전 대륙 전쟁

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 이름 | 대륙 전쟁 | 확정 |

| 톤 | 국가끼리 얽힌 정치는 배경으로만 깔고, 앞에는 아카데미의 통쾌함을 둠 | 확정 |

## 3. 힘의 체계

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 근원 | 마나. 기사는 몸과 검에 두르는 **오러**, 마법사는 **마법** | 확정 |
| 기사 등급 | 소드 비기너 → 익스퍼트 → 마스터 → 그랜드 마스터 | 확정 |
| 대륙 최강 | 그랜드 마스터가 대륙에 손꼽힐 만큼 드묾 | 확정 |
| 태현 | **등급 밖** — 그랜드 마스터들이 다 같이 덤벼도 안 되는 수준. 평소엔 오러를 완전히 감춤 | 확정 |
| 검술의 흔적 | 무명의 검은 오러 빛깔과 검로가 독특해서, 본 사람은 한눈에 알아봄 → 그래서 못 뽑음 | 확정 |

## 4. 아카데미

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 이름 | 아르덴 황립 아카데미 — 제국 최고 | 확정 |
| 학제 | 4년제. 기사과·마법과 | 확정 |
| 태현의 학년 | **2학년** — 졸업까지 2년 | 확정 |
| 성적 | 학기마다 **전체 순위 공개**. 태현은 늘 꼴찌, 근데 퇴학선은 절대 안 넘음 | 확정 |
| 공개 결투 | **지명 결투** — 재학생 누구나 상대를 지명할 수 있고, 거절하면 큰 벌점 | 확정 |
| 태현과의 연결 | 벌점이 쌓이면 퇴학 → 졸업 못 함. 그래서 황녀의 지명을 **거절할 수 없음** | 확정 |
