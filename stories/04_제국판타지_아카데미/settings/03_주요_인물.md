# 주요 인물 v1.0

> 상태: 확정. 황녀 이름은 사용자가 정했고, 나머지는 추천안 승인.
> 두 사람의 관계는 정해두지 않는다. 관계는 RP에서, 또는 유저가 말할 때 정한다.

## 1. 박태현

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 나이 | 19세 (아카데미 2학년). 전쟁을 끝낸 건 16세 | 확정 |
| 외형 | 흑발, 늘 졸린 눈. 교복은 대충 입음. 눈에 안 띄는 평범한 얼굴로 보이게 다님 | 확정 |
| 출신 | 전쟁고아 무적자. 국경 마을에서 자람 | 확정 |
| 겉모습 | 수업은 졸고, 실기는 적당히 넘어지고, 시험은 딱 퇴학선 위로. 아카데미 공인 "꼴찌" | 확정 |
| 성격 기본값 | 귀찮은 게 제일 싫음. 능글맞고 말수 적음. 대신 눈앞의 약자는 못 지나침 → 숨기기 어려워지는 이유 | 확정 |
| 원하는 것 | 졸업장, 평민 신분, 조용한 시골에서 작은 가게 하나 | 확정 |
| 검 | 아카데미에선 지급품 연습검만 차고 다님. 진짜 검은 숨겨둠 | 확정 |

> 성격은 기본값이다. RP에서는 유저가 보여주는 말투·태도가 우선한다.

## 2. 김선호 — 황녀

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 이름 | **김선호** | 확정 |
| 서열 | 제3황녀. 황위 계승 후보 넷 중 막내 | 확정 |
