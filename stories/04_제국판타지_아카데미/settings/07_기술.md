# 기술 v1.0

> 상태: 확정. 무명의 오러 빛깔은 사용자가 정했고(검붉은색), 나머지는 추천안 승인.

## 1. 경지 등급 — 기사

| 등급 | 오러 표현 | 어느 정도인가 |
| --- | --- | --- |
| 소드 비기너 | 몸 안에서 오러를 느끼고 돌림 | 신입생 대부분 |
| 소드 익스퍼트 (하·중·상급) | 검에 오러를 두름 — **검기** | 아카데미 졸업 기준이 익스퍼트 하급 |
| 소드 마스터 | 오러가 검 밖으로 뻗어 나감 — **오러 블레이드** | 제국 기사단장급 |
| 그랜드 마스터 | 오러가 의지대로 모양을 바꾸고, 주변 공간을 장악함 | 대륙에 손꼽힘. 대륙 전쟁 때 발카스 총사령관이 그랜드 마스터였음 |
| 등급 밖 | 공식 이름 없음 — 대륙 사람들은 이 단계가 있는 줄도 모름 | 태현 하나 |

## 3. 마법사 등급

1~9서클. 아카데미 졸업 기준 3서클, 대마법사 8서클 이상.

## 4. 무명의 오러

| 항목 | 내용 |
| --- | --- |
| 빛깔 | **검붉은색** |
| 알아보는 이유 | 검붉은 오러를 쓰는 사람은 대륙에 무명 하나뿐. 전쟁터에서 그 색을 본 사람은 한눈에 알아봄 |
| 숨길 때 | 오러를 아예 안 쓰고 몸놀림과 검로만으로 처리. 그래서 그레이 같은 숙련자 눈에 걸림 |

## 5. 무명의 기술

태현은 원래 기술에 이름을 붙이지 않는다. 지금 이름들은 대륙 전쟁 때 **병사들이 보고 붙인 것**이고, 태현은 그 이름들을 민망해한다. RP에서 태현이 기술명을 외칠지는 유저가 정한다.

| 구분 | 이름 | 내용 |
| --- | --- | --- |
| 필살기 | 「적섬」 | 검붉은 섬광 한 줄기. 거리를 무시하고 베는 한 수 |
| 필살기 | 「흑뢰」 | 검붉은 번개처럼 꺾이며 들어가는 연격. 소리보다 먼저 닿음 |
| 필살기 | 「잔홍」 | 벤 자리에 붉은 잔상이 남고, 그 안에 닿은 오러와 마법이 지워짐 |
| 필살기 | 「단천」 | 하늘을 가르는 광역기. 대륙 전쟁 때 발카스 군 진형을 둘로 가름 |
| 필살기 | 「낙홍」 | 검붉은 오러를 위에서 내리꽂는 일격. 성벽째 무너뜨림 |
| 비기 | 「종막」 | 발카스 총사령관을 벤 한 수, 곧 전쟁을 끝낸 한 수. 제대로 본 사람이 아무도 없음 |

| 그레이 | 「철벽」 | 전장에서 익힌 방어 검술 |
