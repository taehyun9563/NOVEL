| 제5장 첫 아침 | 입소 둘째 날 | 6시 반 기상 전 이미 일어나 있음. 마사가 세면도구·수건·속옷 없는 걸 보고 피오와 연대 책임으로 잡화점 심부름(이는 버드나무 가지로 닦아 왔음). 피오의 흥정 솜씨. 초록색 입 헹굼 물약을 "처음 봐서" 사서 창가 화분 옆에 둠. 광장에서 아리엔이 "형 없이 걷기" 연습 중 → 태현이 인파를 아무와도 안 부딪치고 걸어 보임 → "사람 보지 말고 틈 봐. 피하려고 하지 마. 같이 흘러" → 아리엔 20걸음 성공, "고마워요(예의상)". **하나 첫 등장**(3학년, 소매 은줄 셋). | 제6장 입학식 | 입소 사흘 뒤 · 대강당 → 1반 교실 | 학장 연설 세 문장("…그리고 졸업하십시오"). 리제가 신입생 대표 선서에 "우리는 서로를 넘어설 것" 추가. **1반(담임 가렛)**: 리제·아리엔·줄리안·미아·피오·태현. 자기소개 무기 → **"다. 저거 다 써"**(거치대 가리킴) → 줄리안 "웨폰 마스터라도 되시나" 비웃음(농담), 리제·아리엔은 허세 아님을 느낌. 가렛이 혼자 남겨 "누구한테 배웠냐" → **"혼자서"**. 가렛: 무기술 수업에서 거치대 무기 아무거나 허락, 이론은 졸지 말 것. 미아가 웨폰 마스터=천존을 떠올렸다가 "천존은 늙은 할아버지, 오빠는 열여덟·벨루나"로 스스로 부정 |

"지금 이론 시간이잖아. 졸지 말라며"** (실연 없음). 리제 공책에 증거 정리(쉰셋/열여덟, "반드시 본다"). 과제(교범 1장 요약)를 피오 문답으로 작성: "등으로도 들어와", "멈추면 늦어", 약한 단계는 "모름, 찾으면 쓰겠음" |
| 제8장 둘째 날 | 정규 수업 둘째 날 | 가렛 과제 코멘트 "찾으면 꼭 써라. 기다린다". 리제 형 2회. **공통 과목 Ⅰ 「대륙의 힘 개론」**(이자벨 노르, 교수 돌아가며 담당, 다음 주부터 학과별 시범) — 태현은 신성력·정령·룬 "어떻게?"를 공책에 적음. **클로에 옆자리** → "너가…노인네가 말하던 딸" → 클로에 "손녀인데, 노인네 누구? 할아버지 알아?" → 수업 후 막아섬, **루카 등장** → "노인네랑 닮았네. 시끄러워" 하고 빠져나감(루카: 마력 반응 없음, 흥미롭네). 미아에게 "시끄러운 노인네뿐이야". 밤 307호, 피오 결론 "대단한 사람의 숨겨진 아들이나 비밀 제자" → "아무렇게나 생각해. 딱히 말할 이유는 없고" → 피오는 캐묻지 않고 비밀 유지, 미아에겐 "몰라, 화분 물 줬어"로 말 맞춤. 클로에가 염제에게 편지 작성(이름·특징·"노인네" 발언 기재, 할아버지 술주정 "국경에서 같이 싸운 어린 녀석"을 떠올렸다 부정) |
| 제9장 셋째 날 | 정규 수업 셋째 날 오전 | 아침 미아 vs 피오 "화분" 콩트(아리엔 첫 웃음). 리제 형 1회(어깨 교정 진행). 수업 후 하나가 정식 대련 신청(목검·규정·가렛 입회) → "귀찮은데, 하나" → 조건: 태현 승 = 한스네 튀김 한 달, 하나 승 = 졸업까지 "선배", 불응도 패. 태현이 **손을 대지 않고 거치대 목검을 끌어당김**(영창·숨소리 없음, 가렛은 격공섭물/염동 구분 불가) → "말 무르지 마" → **일합: 하나의 오러 실린 목검을 목검으로 세로로 가르고 이마 앞 한 치에서 멈춤**(부상 없음). 리제는 처음으로 검을 눈으로 따라갔고 "봐도 못 막는다"를 깨달음. 하나 패배 인정, 튀김 한 달·"하나라고 불러도 돼", 내일 점심 분점. 가렛이 갈라진 목검 조각을 챙김. 리제 "그게 형을 버린다는 거야? 내일도 때려" → 태현 "변태 맞는 거 같애" → 리제 "근신 열하루 남았어, 기다려" |
| 제9장 (계속) 학장실 | 셋째 날 저녁~밤 | 가렛이 갈라진 목검을 들고 학장에게 보고 → 학장 "다치게 한 적 없다, 결과를 정확히 알고 하는 학생, 나머지는 학장실 문서" / 가렛 "학장님이 붙으면 몇 합?" → 학장 대답 안 함(가렛은 그게 대답이라 짐작). 권왕이 학장에게 안부 편지. **학장이 "서류 보충" 핑계로 비서관 통해 사적 호출(밤 8시, 소등 전)** — 셔츠 차림·반말·녹차. "숨길 생각은 있니?" → 태현 "내기에 그런 조건 없었잖아. 숨길 생각도 밝힐 이유도 없고" → 학장: 정체가 알려지면 학생으로 못 지냄·이사회 문제(명령 아님). 염제 특강은 매년 1학기 중. "학교는 어때?" → "아직은 잘 모르겠네" → "사 년 동안 천천히 알아 가". 리제 결투 신청은 규정대로. "변태 소리 자제" → "뇌제라…붙으면 재밌겠네" → 학장: 아카데미 안 학생으로는 불가, 밖에서 천존으로는 너희 일. "너가 고통스러워하는 거 보면 재밌을 수도?" 하고 소리 없이 사라짐 → 학장 혼자 웃음, 무진 답장 추신 "학장을 놀리는 건 사흘에 두 번꼴" |
| 제10장 튀김 | 넷째 날 | 리제 형 1회. 하나가 한스네 분점에서 첫날 분 튀김. **하나의 제안: 매주 넷째 날 방과 후 연무장 정규 대련(가르치기 아님, 붙어만)** → "나 비싼데(오물오물)" → 조건 상향: 기본 한 봉지·대련 날 두 봉지·비밀 소스 원액 → **"콜"** 성립. 미아·피오·아리엔 동행(아리엔 "대련 구경은 해도 되려나"). 하나 "3학년들이 붙자고 줄 설 것, 넌 내 전속" |
| 제11장 새벽 | 다섯째 날 새벽 · 기숙사 언덕 정자 | 새벽 습관(국경 시절). 아리엔이 오솔길에서 틈 보기 연습. 황궁 형 이야기, 아버지(황제) 편지 "차석이라니 실망했다" → "왜 알려 줬어요?" → **"그냥, 못해서"** → 아리엔 처음 소리 내어 웃음, "무례해요". "내일도 새벽에 여기서 걸을 거예요" |
| 제12장 합동 실습 | 다섯째 날 오후 · 북쪽 공터 | **합동 실습 Ⅰ(남궁청)**: 진 걸린 통나무 기둥, 서로 다른 힘 둘 이상 동시. 조: 태현·**황보연**(내공 결 못 읽음)·**엘린**(쇠·불·얼음·오래된 피 냄새, "정령들이 무서워하는데 싫어하진 않아")·**브리다**(목검 손잡이 반 푼 깎은 것 알아봄). "어떤 걸 원해?" "원한다면?" → 황보연 "마법" → **지팡이 없이 서너 마디 영창, 빛 없이 마나 결계를 매듭 풀듯 해제 → 1등**. 루카(술식 구조를 다 알아야 하는 해제), 클로에(이상하게 정교), 남궁청(오러·마법·내공 결 → 셋, 모른 척). 황보연 아래에서 위로 하는 예. 브리다가 손 굳은살로 창·활·철퇴 판독, "검이랑 지팡이 둘 다 쥐는 손" → "응" → 진짜 무기 보여 달라 → "지금은 없어. 가까이. 봐서" → **씨족 대장간 표식(쇳조각) 받음, 특수과 공방 본관 지하 2층 작업대, 무료 정비**. 다른 조에서 세실리아(날카로운 질문)·설유나(말없이 관찰)·사도린("나랑 같은 냄새") 첫 등장. 클로에 조는 기둥을 태워서 실격 |
| 제13장 여섯째 날 | 새벽~밤 | 전날 밤 리제 공책 "오러+마법+(내공?) 셋 하면 괴물", 아버지의 "얼굴 모르는 세 체계 괴물"을 떠올렸다 "그건 늙은이"로 부정. 새벽 정자에서 리제·아리엔 마주침(궁정 시절부터 비교당한 라이벌, 열한 살 연회 드레스 일화) → 리제에게 "뛸 때도 어깨에 힘 들어가" → 아리엔 "바이스한테도 알려 주는군요" "못하길래". 아리엔 "태현 씨" 호칭. **오전 리제 형 0회 — 6일 만에 교정 완료**("고맙다는 말은 안 해. 네가 변태라서 때린 거니까"), 리제가 태현 형에서 '들어가면 맞는 자리'를 미리 알아채기 시작. 오후 공통 과목 서클 강의(1~9서클, 현역 9서클 확인된 바 없음) — 태현 "원으로 세는구나". **이자벨 연구실 호출** → "안 가면?" → "그럼 내가 매일 찾아간다 / 서부 꿀과자" → 감. 질문 11개(독학 영창, 지팡이 비의존, 결계 구조 즉시 판독, 오러·마나 따로 감) → "몇 서클?" → **"굳이 원을 세야 되나"** → "넘어감" 기록 + "서클 체계를 모르고 마법을 완성". 측정기 제안(거부하면 안 잼). 학장실 보고 안 함. 귀갓길 회랑 안뜰에서 **남궁청과 바둑**(처음 두는데 돌이 안 죽음, 한 수로 판을 이어 남궁청 기권) → "화경을 넘었냐" → **"하다 보니"** → 남궁청 "묻는 건 끝", 가렛·학장에게 말 안 함, 저녁 안뜰 바둑·무학과 청강 허락. 꿀과자 피오와 나눔 |
| 제14장 휴일 | 일곱째 날(첫 휴일) · 〈늙은 닻〉 | 입구에 손바닥 자국 탁자 상판이 "명물(만지면 술값 두 배)"로 걸림. 무진은 동부 사절단 일로 세르카 체류, 다음 주 출발. 학장 답장(추신 포함)을 읽어 줌. "친구는 사귀었냐?" → "이상한 꼬마들이 있긴 해" → 무진 "그게 친구야". 태현이 피오·미아(새끼손가락 약속을 무진에게 시연)·아리엔·리제("변태인 것 같아" → 무진 술 뿜음)·하나·클로에·남궁·이자벨·브리다·엘린을 차례로 이야기 → 무진 "열 명이 넘네". 무진이 처음 결투한 건 태현 열다섯 살 무렵. **다음 휴일 정오 〈늙은 닻〉 친구 초대(오리 열 마리), 변장 핑계 "먼 친척 아저씨, 동부 장사"** → "오고 싶어 하면 데리고 올게". 무진: 하나와의 계약 지켜라, 리제와 결투하면 다치게 하지 마라. 광장에서 미아·아리엔 초대(둘 다 수락, 아리엔 "오고 싶어요"), 밤에 피오 초대(수락, 편지 추신 "그 애가 친구라고 했어") |
| 제15장 무기술 | 여덟째 날(둘째 주 첫날) | 리제 초대 → "생각해 볼게". **무기술 첫 수업**(형 연습은 셋째·다섯째 날로 축소): 장검→곡도(거치대 끝)→창(허수아비 관통)→활(돌면서 서른 걸음 이마)→철퇴(기둥 반 뼘 박힘), 이음새 없이 열 번. 1반에 "진짜 웨폰 마스터 아냐?" 농담 → "천존은 노인"으로 넘김. 가렛 명부 "확인함". **특수과 시범**(미르 교수, 세실리아 신성력·엘린 물고기 정령·브리다 부유 룬). 태현이 세실리아에게 신성력 원천을 연달아 질문 → "다른 건 보면 되던데 신성력은 안 돼서" → 세실리아 "문은 안에" → **매일 새벽 예배당 기도 약속**("그래"). 클로에가 염제가 편지 받고 하루 종일 웃었다고 전함 → "이상한 노친네" → 불꽃 나비·술 노래를 아냐 → "아 맞다 그런 거 하긴 했어" → "국경의 그 애야?" → **"노친네한테 물어봐"**. 클로에가 염제에게 직접 묻는 편지(두 통), 특강 때 강당에서 묻겠다고 함. 루카는 "보고 따라 할 수 없는 걸" 마탑과 시범에서 보여 주겠다고 결심 |
| 제16장 예배당 | 아홉째~열하루째 날 | 예배당 첫날: 아무것도 안 옴, "손을 어디로 뻗어야 될지 몰랐어. 처음이야" → 세실리아 "빈손". 아리엔이 걷는 시간을 기도 뒤로 옮김. 남궁청 두 번째 바둑(천원 첫 수), 소문 전달(웨폰 마스터 농담, 클로에 편지 두 통, 루카 도서관 국경 기록 조사) → "아줌마가 힘들겠네" → 남궁청이 학장임을 알아채고 권왕을 떠올림. 열째 날: 기도 둘째 날 "사냥꾼 숨 → 그냥 숨", **리제 휴일 수락**("몇 시야" → 정오). 열하루째 날(넷째 날): **하나 초대 수락**, 첫 정기 대련 — 서른다섯 합 동안 빈자리를 느리게 보여 주며 받아 줌 → 하나가 스스로 새 수(발로 비키며 아래에서 쳐올림) → 가렛 "이름 붙여 둬라, 네 거다"(이름 미정). 3학년 **바르토**가 같은 조건 요청 → "전속이래" 거절, 하나 계약 끝나면 줄 선다. 저녁 남궁청 바둑 이어서 → **백 반 집, 태현의 첫 패배**("처음이야, 이런 거로 지는 거") → "다음 판은 네가 이틀 들여다보고 와라" |
| 제17장 둘째 합동 실습 | 열이틀째 날(다섯째 날) | 리제의 목검이 처음으로 태현의 목검에 닿음. **합동 실습 Ⅱ: 숲 진법 미로(다섯 겹)**, 조 = 태현·루카·세실리아·**사도린**. 사도린 "냄새나는 녀석이랑 같은 조네". 실습 전 **클로에(아저씨에게 할아버지 물어보겠다며 수락)·엘린(수락)·브리다("무기 가져오면 간다")** 초대. 루카 "넌 보기만 해" → 태현이 뒤에서 보고 수정(한 박자 늦음, 두 번째 줄 먼저) → 루카 "다음 것도 봐", 마지막 겹은 혼자 → 1등, 남궁청 칭찬. 사도린 "너도 사파야?" → "사파 아니야. 여기저기" → "서로 안 묻는 게 예의. **이 학교에 기척 알아보는 놈이 나 말고도 있을 거야, 조심해**" |
| 제18장 공방 | 열사흘째 날(여섯째 날) 저녁 · 특수과 공방 | 지하 계단참에서 아무도 없을 때 **아공간에서 진짜 검을 꺼냄**(D-028). 검: 검은 가죽 칼집, 회흑색 칼날에 지층 같은 접쇠 무늬, 무게가 고르게 퍼짐, 슴베에 **단왕 각인(망치·산 세 봉우리·룬)**. 브리다 "단왕님이랑 무슨 사이야?" → "줬어. 만들어서" → 브리다: 3년 전 단왕이 한 사람에게 검과 지팡이를 동시에 만듦(사흘 밤낮 화로), 산맥은 그를 천존이라 부름 → **"너야? 천존."** → 어깨 으쓱 **"글쎄"** → 브리다 확신, 드워프 대장장이 법으로 비밀 유지. 정비 허락 → 슴베 녹 제거, 녹 방지 작은 룬, 손잡이 가죽끈을 태현 손(엄지 반 푼 안쪽)에 맞춰 반대 방향으로 감음 → "좋네". 브리다 휴일 확정, "지팡이도 언젠가, 봐서 말고" |
| 제19장 오리 열 마리 | 열나흘째 날(둘째 휴일) 정오 · 〈늙은 닻〉 2층 | 새벽 예배당에서 **세실리아 초대**("기도 같이 하잖아" → 늦게 수락). 참석: 피오·미아·아리엔·리제·하나·클로에·엘린·브리다 + 세실리아. 무진은 상인 차림 변장, 팔뚝·손마디는 못 숨김. **하나(동부 초상화)·아리엔(일곱 살 종전 기념 연회)·리제(아버지 서재 동서대전 기록화)가 알아봄** → 하나 "……권왕?" → 태현 **"아, 그렇게 불렸나"** → 무진 인정, "친척은 거짓말, 국경에서 만난 술친구, 옛날에 이 꼬마한테 신세 진 게 있다", 오늘은 그냥 아저씨. 리제 "권왕이 너한테 신세를?" → 태현 **"몇 번?"** → 무진이 술값·길 안내로 둘러댐(비공개 결투 D-013 언급 없음). 무진-뇌제 대전 때 함께 싸움, 아리엔 일곱 살 때 "왜 아버지한테 인사 안 해요?" 일화, 하나와 무진 동부 같은 마을 근처. 세실리아 도착 "새벽에 기도를……" → 무진 "이 녀석이 기도를?" → "응. 안 와. 그래서 계속 가" → 무진 눈물 "잘했다, 안 되는 걸 해 봐야 사람이 되지". 무진 "권왕이 아니라 아저씨로서 잘 부탁한다" → 전원 응답. 떠날 때 입 모양 "다음 주 떠난다. 졸업 때 보자. 소원 생각해 둬라" |
