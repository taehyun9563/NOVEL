## 2. 장별 요약

| 장 | 시점 · 장소 | 사건 |

| 프롤로그 | 입학 시험 전날 밤 · 세르카 술집 〈늙은 닻〉 2층 별실 | 권왕이 "그때 내가 한 말 기억하냐?"를 꺼냄. 태현이 잔소리를 그대로 기억. "꼬마들 다니는 곳에 뭐하러" → 권왕의 "무섭냐?" 도발에 걸려 탁자에 손바닥 자국을 남기고 내기 수락. 태현이 "소원 하나"라고 답해 권왕이 이미 건 것과 겹침 → 학장(증인)이 정리: **졸업하면 권왕이 소원 하나. 태현 측 추가 조건 없음.** 권왕 몫은 "도망치면 평생 놀림". 탁자값은 태현이 냄 |
| 제1장 줄 · 일합 | 시험 당일 · 정문 → 필기 → 실기장 | 줄에서 미아를 만남(벨루나 동향). 줄리안의 새치기를 태현이 버티고 서서 막음, 가렛이 정리. 필기는 교범 명칭·예법 문제를 비움(반쯤 빈 답안). 실기 기본기 형은 남들 것을 보고 그대로, 가렛이 직접 대련을 받음 → **오러·이름 있는 기술 없이 순수 검술 일합**. 가렛 명부: 〈최상〉〈출신 수련 이력 확인 요망〉. 미아의 오른발 반 뼘 지적. 출구에서 리제가 "그거 뭐야" → 정식 결투 신청 → 태현 "대충 휘두른 것도 못 알아보는데" 하고 지나감 → 리제가 칼집째 오러를 실어 등 뒤 공격 → 태현이 이름 없는 보법으로 뒤를 잡고 손가락 두 개로 목을 겨눔(접촉·부상 없음, 목격자 다수). 가렛이 학장실 보고. 저녁 광장에서 호출장을 받고 "귀찮은 아줌마" (조교·미아가 들음) |
| 제2장 학장실 · 만두집 | 시험 다음 날 | 학장이 목격자 7명 진술 확보. 태현 "없어……습니다". 처분 — **리제: 성적 반영 없음, 입학 후 2주 근신(정규 수업 외 대련·결투 신청 금지) + 방과 후 연무장 정비 봉사(가렛 감독)** / **태현: 방어로 판단, 처분 없음. 기록 없는 구두 주의(상대가 멈추면 바로 거둘 것)**. 학장은 가렛의 이력 확인 요청에 "학장실 직접 접수, 추가 조사 불요"로 규정대로 정리. 계단에서 리제 "근신 끝나면 다시 신청" → 태현 "타인의 실력을 눈으로 판단하는 것도 실력이야". 오후 만두집에서 미아와 새끼손가락 약속(결과 발표 날 8시 분수대) |
| 제3장 게시판 | 결과 발표 날 아침 · 정문 게시판 | 태현(1379)·미아(1380) 합격, **미아는 기사과 장학생**. 수석 리제, 차석 아리엔(게시판엔 수석·차석만 이름. 태현 종합 순위 미정). 리제 "수석은 나야, 뺏어 봐" → 태현 "축하해" → 리제 당황, "두 주 뒤야" |
| 제4장 기숙사 | 입소 날 | 307호, 룸메이트 피오 마렌. 사감 마사(규칙: 밤 10시 소등, 6시 반 기상, 방 더럽히면 직접 들어감). 피오에게 소문의 주인공이 자기라고 밝힘 → "무서운 사람이야?" "글쎄". 육포·신 과일 교환. 식당 맨 안쪽 구석(벽 등지고 출입문 보는 자리)에 앉음. 미아가 아리엔을 데려옴(**둘은 같은 방**). 아리엔이 "형 밖에서 어떻게 하냐" → 태현 "형 말고 상대를 봐. 형을 너무 잘 외워서 못 버려" "아무 데나 걸어 봐, 형 없이. 사람 많은 데, 부딪치지 말고". 밤에 피오에게 입학 이유를 "어떤 아저씨랑 내기"라고만 말함(내용 비공개). 피오가 코를 곪 |
| 제5장 첫 아침 | 입소 둘째 날 | 6시 반 기상 전 이미 일어나 있음. 마사가 세면도구·수건·속옷 없는 걸 보고 피오와 연대 책임으로 잡화점 심부름(이는 버드나무 가지로 닦아 왔음). 피오의 흥정 솜씨. 초록색 입 헹굼 물약을 "처음 봐서" 사서 창가 화분 옆에 둠. 광장에서 아리엔이 "형 없이 걷기" 연습 중 → 태현이 인파를 아무와도 안 부딪치고 걸어 보임 → "사람 보지 말고 틈 봐. 피하려고 하지 마. 같이 흘러" → 아리엔 20걸음 성공, "고마워요(예의상)". **하나 첫 등장**(3학년, 소매 은줄 셋). "선배라고 불러" → "그래, 하나" → "교내에선 선배, 아니면 연무장" → "할 수 있으면, 하나" → 하나가 튀김 하나 뺏고 "입학하고 나서 보자" |
| 제6장 입학식 | 입소 사흘 뒤 · 대강당 → 1반 교실 | 학장 연설 세 문장("…그리고 졸업하십시오"). 리제가 신입생 대표 선서에 "우리는 서로를 넘어설 것" 추가. **1반(담임 가렛)**: 리제·아리엔·줄리안·미아·피오·태현. 자기소개 무기 → **"다. 저거 다 써"**(거치대 가리킴) → 줄리안 "웨폰 마스터라도 되시나" 비웃음(농담), 리제·아리엔은 허세 아님을 느낌. 가렛이 혼자 남겨 "누구한테 배웠냐" → **"혼자서"**. 가렛: 무기술 수업에서 거치대 무기 아무거나 허락, 이론은 졸지 말 것. 미아가 웨폰 마스터=천존을 떠올렸다가 "천존은 늙은 할아버지, 오빠는 열여덟·벨루나"로 스스로 부정 |
| 제7장 첫 수업 | 정규 수업 첫날 | 20바퀴, 리제 전력·태현 반 걸음 뒤(리제 주법 관찰). 형 짝 = 리제(정규 수업이라 근신 대상 아님). 틀린 데를 목검으로 때림: 6곳 → 2회차 4곳(발목 교정). "변태?" "특이한 취향이네". 태현의 형은 대충 → 리제가 다섯 번 노렸으나 때릴 데 없음 → "나는 맞는 취향이 아니라서". 가렛 속생각: 형을 버린 경지(기사단 시절 쉰셋 기사단장 한 명). 오후 이론: 교범 호흡 **흡·정·단·발** → "왜 끊어?" → 리제 교범 답 → "그걸 왜 못하냐는 거" → 가렛이 반 전체 앞 "할 수 있냐" → **"돼." "지금 이론 시간이잖아. 졸지 말라며"** (실연 없음). 리제 공책에 증거 정리(쉰셋/열여덟, "반드시 본다"). 과제(교범 1장 요약)를 피오 문답으로 작성: "등으로도 들어와", "멈추면 늦어", 약한 단계는 "모름, 찾으면 쓰겠음" |
| 제8장 둘째 날 | 정규 수업 둘째 날 | 가렛 과제 코멘트 "찾으면 꼭 써라. 기다린다". 리제 형 2회. **공통 과목 Ⅰ 「대륙의 힘 개론」**(이자벨 노르, 교수 돌아가며 담당, 다음 주부터 학과별 시범) — 태현은 신성력·정령·룬 "어떻게?"를 공책에 적음. **클로에 옆자리** → "너가…노인네가 말하던 딸" → 클로에 "손녀인데, 노인네 누구? 할아버지 알아?" → 수업 후 막아섬, **루카 등장** → "노인네랑 닮았네. 시끄러워" 하고 빠져나감(루카: 마력 반응 없음, 흥미롭네). 미아에게 "시끄러운 노인네뿐이야". 밤 307호, 피오 결론 "대단한 사람의 숨겨진 아들이나 비밀 제자" → "아무렇게나 생각해. 딱히 말할 이유는 없고" → 피오는 캐묻지 않고 비밀 유지, 미아에겐 "몰라, 화분 물 줬어"로 말 맞춤. 클로에가 염제에게 편지 작성(이름·특징·"노인네" 발언 기재, 할아버지 술주정 "국경에서 같이 싸운 어린 녀석"을 떠올렸다 부정) |
| 제9장 셋째 날 | 정규 수업 셋째 날 오전 | 아침 미아 vs 피오 "화분" 콩트(아리엔 첫 웃음). 리제 형 1회(어깨 교정 진행). 수업 후 하나가 정식 대련 신청(목검·규정·가렛 입회) → "귀찮은데, 하나" → 조건: 태현 승 = 한스네 튀김 한 달, 하나 승 = 졸업까지 "선배", 불응도 패. 태현이 **손을 대지 않고 거치대 목검을 끌어당김**(영창·숨소리 없음, 가렛은 격공섭물/염동 구분 불가) → "말 무르지 마" → **일합: 하나의 오러 실린 목검을 목검으로 세로로 가르고 이마 앞 한 치에서 멈춤**(부상 없음). 리제는 처음으로 검을 눈으로 따라갔고 "봐도 못 막는다"를 깨달음. 하나 패배 인정, 튀김 한 달·"하나라고 불러도 돼", 내일 점심 분점. 가렛이 갈라진 목검 조각을 챙김. 리제 "그게 형을 버린다는 거야? 내일도 때려" → 태현 "변태 맞는 거 같애" → 리제 "근신 열하루 남았어, 기다려" |

## 5. [임시] 기술

없음. 이름 있는 기술은 쓰지 않았다. 일합 검술, 이름 없는 보법, 인파 사이 걷기, 목검 끌어당기기(체계 미표시).
