# 콘셉트 v1.0

> 상태: 확정. 핵심 설정·구조·입학 동기는 사용자가 확정했다. 이명 이름·가제·톤·로그라인은 추천 상태이며 승인 시 확정으로 바꾼다.

## 로그라인 (추천)

> 뇌제, 염제, 빙제, 검제, 권왕. 대륙의 정점에 선 이명들 가운데서도 「무제」의 얼굴을 아는 자는 손에 꼽는다.
> 싸움밖에 모르고 살아온 그가, 오랜 벗과의 술자리 내기 하나로 동서의 인재가 모이는 대륙 통합 아카데미에 평범한 학생으로 입학한다.

## 5. 입학 동기 (1+2+3+4)

| 구분 | 내용 | 상태 |
| --- | --- | --- |
| ① 평범한 삶 | 한 번쯤 평범한 학생으로 살아 보고 싶음 — 수업, 식사, 축제, 친구와의 여행 | 확정 |
| ② 무예 호기심 | 새 힘을 얻으려는 게 아니라, 다른 문명과 새 세대가 무예를 어떻게 발전시키는지 직접 보고 싶음 | 확정 |
| ③ 절대강자와의 내기 | 다른 절대강자와 술자리에서 "한 학기도 못 버틸걸?" — 가벼운 내기로 입학을 결정. 내기 결과보다 학생 생활이 중심 | 확정 |
| ④ 과거의 약속 | 인연이 있던 인물이 생전에 아카데미 시절 이야기를 하며 평범한 학창 생활을 해 보라고 권했음. 시간이 흐른 뒤 그 말을 떠올림 | 확정 |
| 내기 상대·약속의 인물 | 누구인지 | 미정 — 주요 인물 |

## 7. 큰 구조

| 요소 | 적용 방식 |
| --- | --- |
| A. 아카데미 | 일상과 인간관계를 만드는 주요 무대 |
| B. 대륙 유랑 | 방학·실습·개인 여행으로 동서부 탐험 |
| C. 절대강자 군상극 | 이명 보유자들의 우정·경쟁·갈등 |
| D. 대륙 무투제 | 기사·마법사·무림 고수가 참가하는 대규모 행사 |

| 부 | 내용 |
| --- | --- |
| 1부 아카데미 입학 | 신분을 숨기고 일반 학생으로 입학. 친구, 라이벌, 귀족, 무림 세가 후계자와 관계 형성 — **RP 시작** |
| 2부 동서부 교류와 여행 | 교환 수련과 방학 여행으로 활동 범위 확장. 여러 문명과 절대강자들의 흔적을 접함 |
| 3부 절대강자들의 재회 | 뇌제·염제·빙제·검제·권왕 등과 직접 만나며 과거 인연과 최강자들 사이의 관계가 드러남 |
| 4부 대륙 무투제 | 여러 국가와 문파가 참여. 태현의 참가 여부와 정체 공개 여부는 RP에서 결정 |
| 5부 자유로운 대륙 서사 | 아카데미 이후 여행·전쟁·모험·국가 간 갈등을 태현의 선택에 따라 전개 |

> 구조 전체가 확정이다.
