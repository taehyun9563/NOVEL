> 상태: 확정. 로그라인과 기본 정보를 사용자가 승인했다. 표 안의 추천·미정 항목은 다음 문서에서 정한다.

## 로그라인

> 아르카시아 대륙에는 뇌제, 염제, 빙제, 검제, 권왕, 그리고 천존이 있다. 모두가 그 이름을 알지만, 천존의 얼굴을 아는 자는 손에 꼽는다.
> 싸움밖에 모르고 살아온 그가, 오래된 약속과 술자리 내기 하나로 동서의 인재가 모이는 대륙 통합 아카데미에 평범한 학생으로 입학한다.

| 실제 전투력 | 정점. 이를 아는 건 얼굴을 아는 극소수뿐이며, 이명 보유자 사이에서도 누가 최강인지는 결론이 나 있지 않음 | 확정 |
| 과거 | 수많은 전투·결투·국가 간 분쟁을 겪음. 최강자의 명성은 얻었지만 평범한 삶은 살아 본 적 없음 | 확정 |
| 무학 | 이미 완성됨 | 확정 |
| 실력 공개 | 일부러 낮춰 평가받을 필요 없고, 처음부터 전부 공개할 필요도 없음. 얼마나 보여줄지는 유저가 정함 | 확정 |

## 5. 입학 동기

> 목적은 하나 — 지금까지 살아온 방식과 전혀 다른 삶을 경험해 보는 것. 아카데미에서 따로 수행할 특별한 임무는 없다. **확정**

| 구분 | 내용 | 상태 |
| --- | --- | --- |
| ① 과거의 약속 | 특별한 인연이 있는 사람이, 전투와 수련·강자와의 대결에만 관심을 두는 태현을 못마땅해하며 말했다. "당신은 세상에서 가장 강한 사람 중 하나면서, 정작 세상 사람들이 어떻게 살아가는지는 모르잖아요." "언젠가 전부 내려놓고 평범한 사람들처럼 살아봐요. 친구도 사귀고, 여행도 하고, 축제도 즐기면서요." 당시엔 흘려들었지만 기억에 남아 있음 | 확정 |
| 약속의 인물 | 살아 있음. 누구인지는 주요 인물에서 | 확정 / 정체 미정 |
| ② 다른 문명에 대한 호기심 | 이미 힘을 완성해서 새 경지는 큰 의미가 없음. 대신 다른 사람들이 어떻게 수련하고 어떤 생각으로 힘을 발전시키는지가 궁금함. 동서부 인재가 한곳에 모이는 곳은 대륙 통합 아카데미뿐 | 확정 |
| ③ 절대강자와의 내기 | 비슷한 반열의 절대강자와 술자리에서 아카데미 이야기가 나옴. "정말 입학해서 졸업까지 해 봐. 중도에 도망치지 않으면 내가 소원 하나를 들어주지." "좋아. 대신 네가 지면 내 부탁 하나 들어줘." 강함이 아니라 평범한 학생 생활을 두고 벌이는 우스운 내기 | 확정 |
| 내기 상대 | 누구인지, 소원과 부탁의 내용 | 미정 — 주요 인물 |
| ④ 평범한 삶에 대한 기대 | 아카데미는 새 힘을 얻으러 가는 곳이 아니라, 한 번쯤 경험해 보고 싶었던 새로운 삶의 시작 | 확정 |

## 6. 대륙 통합 아카데미

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 성격 | 동서부의 귀족, 무림 세가 후계자, 기사 지망생, 마법 천재들이 모이는 대륙 최고의 중립 아카데미 | 확정 |

| 새 세대 | 장래의 검성·대마법사·무림 절대고수가 될 천재들이 동기로 있음. 태현은 이미 정점, 이들은 전설을 만들어 가는 중 | 추천 |

## 7. 아카데미 생활 원칙

| 번호 | 원칙 | 상태 |
| --- | --- | --- |
| 1 | 태현은 일부러 실력을 낮춰 평가받을 필요가 없다 | 확정 |
| 2 | 그렇다고 처음부터 모든 능력을 공개할 필요도 없다 | 확정 |
| 3 | 학생과 일반 교수진은 태현의 정체를 모른다. 학장은 예외적으로 천존의 정체를 안다 (D-004) | 확정 |
| 4 | 다른 절대강자들은 태현을 동등한 존재로 대한다 | 확정 |
| 5 | 아카데미에서 친구·라이벌·동료·연애 상대가 자연스럽게 생길 수 있다 (연애는 유저가 정할 때까지 엮지 않음) | 확정 |
| 6 | 아카데미 이야기가 끝나면 대륙 전체로 활동 범위가 확장된다 | 확정 |

## 8. 인식 차이

| 인물 | 태현을 보는 시각 | 상태 |
| --- | --- | --- |
| 일반 학생 | 실력이 조금 특이한 신입생 | 확정 |
| 귀족 학생 | 출신을 알 수 없는 평범한 학생 | 확정 |
| 천재 검사 | 어딘가 설명하기 어려운 검술을 가진 인물 | 확정 |
| 마법 천재 | 마력 운용이 이상할 정도로 정교한 인물 | 확정 |
| 교수진 | 재능은 뛰어나지만 출신과 수련 이력이 불분명한 학생 | 확정 |
| 학장 | 정체를 아는 오래된 친구. 공적인 자리에서는 일반 학생으로 대함 (D-005) | 확정 |
| 얼굴을 아는 절대강자 | 보자마자 누구인지 알아보는 오래된 인연 | 확정 |
| 얼굴을 모르는 절대강자 | 마주쳐도 알아보지 못함 | 확정 |

> 장면 예시: 염제가 특별 강연을 하러 왔다가 강당에 앉은 태현을 발견하고 웃는다. 학생들은 염제가 왜 특정 학생을 보고 웃는지 모른다.

## 9. 큰 구조

| 요소 | 적용 방식 |
| --- | --- |
| A. 아카데미 | 일상과 인간관계를 만드는 주요 무대 |
| B. 대륙 유랑 | 방학·실습·개인 여행으로 동서부 탐험 |
| C. 절대강자 군상극 | 이명 보유자들의 우정·경쟁·갈등 |
| D. 대륙 무투제 | 기사·마법사·무림 고수가 참가하는 대규모 행사 |

| 부 | 내용 |
| --- | --- |
| 1부 아카데미 입학 | 신분을 숨기고 일반 학생으로 입학. 친구, 라이벌, 귀족, 무림 세가 후계자와 관계 형성 — **RP 시작** |
| 2부 동서부 교류와 여행 | 교환 수련과 방학 여행으로 활동 범위 확장. 여러 문명과 절대강자들의 흔적을 접함 |
| 3부 절대강자들의 재회 | 뇌제·염제·빙제·검제·권왕 등과 직접 만나며 과거 인연과 최강자들 사이의 관계가 드러남 |
| 4부 대륙 무투제 | 여러 국가와 문파가 참여. 태현의 참가 여부와 정체 공개 여부는 RP에서 결정 |
| 5부 자유로운 대륙 서사 | 아카데미 이후 여행·전쟁·모험·국가 간 갈등을 태현의 선택에 따라 전개 |

> 구조 전체가 확정이다.
