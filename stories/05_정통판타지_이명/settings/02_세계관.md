## 3. 힘의 체계 — 같은 기운, 다른 길

대륙에 흐르는 기운은 하나다. 문명마다 그 기운을 얻는 곳과 드러내는 방식이 다르다. 동서의 힘을 일대일로 같은 수준에 맞추지 않고, 지역별 수련 문화와 전투 방식의 차이를 유지한다.

| 체계 | 기운을 얻는 곳 | 드러나는 방식 | 상태 |
| --- | --- | --- | --- |
| 마법 (서부) | 바깥 | 술식으로 형태를 줌 | 확정 |
| 오러 (서부 기사) | 몸 안의 흐름 | 신체와 무기에 두름 | 확정 |
| 내공 (동부) | 단전에 쌓음 | 초식(무공)으로 펼침. 검강은 검술의 표현 | 확정 |
| 신성력 (서부 성교회) | 신앙이 매개 | 치유와 정화 | 확정 |
| 정령술 (엘프) | 정령이 매개 | 계약으로 빌려 씀 | 확정 |
| 용족 권능 | 혈통 | 타고난 고유 능력. 배울 수 없음 | 확정 |
| 룬 (드워프) | 별도 원천 아님 | 위의 기운을 문자에 새겨 고정하는 기술 | 확정 |
| 신성력의 근원 | 실제 신격의 존재 여부 | — | 미정 |

## 4. 대륙 공통 등급

동서가 서로의 강함을 비교하려고 아카데미와 용병 길드에서 쓰는 참고 등급이다. 각 문명에는 고유 경지 이름이 따로 있으며, 공통 등급과 대략 대응할 뿐 일대일로 같지 않다 (예: 소드마스터와 절정을 같은 단계로 단정하지 않는다).

| 견습 | 정규 | 상급 | 초인 | 초월 | 절대 |
| --- | --- | --- | --- | --- | --- |
| 입문 | 숙련 | 일류 | 소드마스터·절정급 전후 | 그 위의 극소수 | 대륙 최상위 무력 |

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 절대와 이명 | 절대는 무력의 수준, 이명은 대륙의 인정으로 생긴 명성. 서로 별개다. 이명 없는 절대급도 존재할 수 있다 | 확정 |
| 세부 경지 | 문명별 세부 단계 | 미정 — 기술 |

## 5. 이명 제도

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 서열 | 없음. 모두 동렬 (D-002) | 확정 |
| 형성 | 공식 수여 기관 없음. 전적이 쌓이면 대륙이 그렇게 부르기 시작하며 자연스럽게 생긴다 | 확정 |
| 동료의 인정 | 다른 이명 보유자들의 인정은 명성을 굳히는 역할일 뿐, 수여 권한이나 절차가 아니다 | 확정 |
| 현재 이명 | 뇌제, 염제, 빙제, 검제, 권왕, 천존 외 | 확정 |
| 이명의 형식 | 무협식이 기본, 서부에서 붙은 이명은 서부식일 수 있음. 한 사람이 여러 이명을 가질 수 있음 (D-007) | 확정 |
| 출신 | 동서 양쪽에서 나옴. 명단은 `04_조연.md` §1 (D-014) | 확정 |
| 무투제와의 관계 | 무투제는 이명 서열을 정하는 행사가 아니다 | 확정 |

## 6. 얼굴 은폐

새로운 은폐 능력은 없다. 정보가 전해지는 방식과 인식 차이로 성립한다.

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 이명과 얼굴 | 이명과 업적은 결과로 퍼지고, 얼굴은 목격자의 기억에만 남는다. 전장의 거리와 혼전 때문에 기억이 흐리다 | 확정 |
| 초상화 | 목격담을 바탕으로 그려져 제각각이다. 엉터리 초상이 오히려 위장 노릇을 한다 | 확정 |
| 본 사람과 아는 사람 | 얼굴을 **본** 사람은 있어도, 그 얼굴이 **천존**이라는 걸 아는 사람은 극소수다 (콘셉트 §4의 해석) | 확정 |
| 아는 사람 | 직접 맞붙었거나 함께 싸운 자. 이명 보유자 중에서도 일부 | 확정 |

## 9. 입학 절차와 학장

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 입학 시험 | 실기와 필기. 태현은 실력을 낮추지 않는다 (콘셉트 원칙 1) | 확정 |
| 신원 검증 | 출신 서류 또는 공인된 인물의 추천서. 추천서는 학장실이 관리하는 문서로, 교수진에게 돌리지 않는다 | 확정 |
| 태현의 추천서 | 내기 상대 절대강자가 실명으로 쓴다. 보증하는 것은 등록상 신원, 입학 자격, 신원 보증 세 가지. 천존이라는 이명과 두 사람의 관계는 적지 않는다 | 확정 |
| 처리 | 학장이 직접 접수·확인한다. 추천서와 추천인 관계는 교수진·학생에게 공개하지 않는다 | 확정 |
| 학장 | 이명 보유자. 천존·내기 상대와 친분이 있다. 세 사람은 서로 다른 인물 (D-005) | 확정 |
| 학장의 임명 배경 | 종전 협약에 따라, 동서 어느 쪽에도 기울지 않는 중립의 상징으로 임명됨 | 확정 |
| 학장의 이름·이명 | 검제 세레나 아델하이트 (D-011) | 확정 |
| 학장의 정체 인지 | 학장은 태현의 정체를 안다. 학생과 일반 교수진은 모른다 (D-004) | 확정 |
| 특혜 금지 | 시험, 학사 규칙, 징계는 일반 학생과 똑같이 적용한다 | 확정 |
| 학장의 태도 | 아는 것과 돕는 것은 별개. 정체를 지켜 주지도 폭로하지도 않는다. 공적인 자리에서는 일반 학생으로 대한다. 개입은 아카데미 전체가 위험할 때만 | 확정 |
| 내기의 증인 | 학장은 천존과 내기 상대의 졸업 내기 증인이다. 증인이라 공정해야 하므로 태현을 도울 수 없다 | 확정 |
| 태현의 나이·학과 | 18세 입학, 기사과 (D-009) | 확정 |
