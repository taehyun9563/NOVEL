### 1부 — 입학 (1학년, 종전 20년)

| 순서 | 흐름 |
| --- | --- |
| ① | 입학 시험. 태현은 실기 최상위권, 기사 체계 필기에서 상대적으로 밀려 리제가 종합 수석 (D-017) |
| ② | 기숙사 생활과 첫 수업. 천존이 평범한 일상에 서툰 모습 |
| ③ | 공통 과목·합동 실습 (D-008) — 다른 학과 동기들과의 만남 |
| ④ | 염제의 특별 강연 (고정). 클로에가 의심을 품을 수 있다 |
| ⑤ | 학기 말 축제와 시험 |
| ⑥ | 갈등 후보: 교내 동서 출신 학생 간 갈등으로 중립 조항이 처음 시험받는다. 국가 간 무력 충돌로 키우지 않는다. 학장·교수진의 대응이 중심이고, 태현의 개입 여부는 RP에서 |

### 2부 — 동서 교류와 절대강자들의 재회 (2~3학년, 종전 21~22년)

> 기존 2부(동서 교류와 여행)와 3부(절대강자들의 재회)를 합쳤다 (D-030).

| 흐름 후보 | 내용 |
| --- | --- |
| 귀향 | 고향 벨루나. 바람길 용병단·풍신의 소문 |
| 동부 교환 수련 | 황보세가, 설령궁. 빙제는 1학년 여름 방학에 태현이 직접 밝혀 이미 천존의 얼굴을 안다 (D-031) |
| 서부 방문 | 발테리아 제국, 뇌제 가문, 창왕의 소문 |
| 기존 인연 | 단왕 방문(무기 정비), 권왕의 내기 점검. 재회는 첫 대면이 아니다 (D-015) |
| 새 강자 | 창왕 직접 대면, 환제·풍신 등 다른 이명 보유자의 본격 개입 |
| 군상극 | 국경 긴장 속에서 이명 보유자들이 **각자 독립적으로** 선택한다. 전원이 정치 진영에 소속되어 움직이지 않는다 (권왕 무소속, 검제 중립 유지) |
| 갈등 후보 | 국경 긴장의 고조 |
| 마무리 후보 | 이듬해 세르카 무투제 개최 공표 |

> 목적지와 순서, 만남의 성사는 유저의 선택을 따른다.
