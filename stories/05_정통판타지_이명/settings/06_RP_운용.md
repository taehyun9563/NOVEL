# RP 운용 v1.0

> 상태: 확정 (D-023). Claude 초안(04 RP 운용의 공통 규칙 차용) → ChatGPT 독립 검수 → 사용자 승인.
> 콘셉트~플롯 설정을 바탕으로 실제 RP를 진행하는 규칙. 다른 작품의 인물·설정·진행 기록을 섞지 않는다.

## 1. 역할

| 구분 | 담당 |
| --- | --- |
| 유저 | **박태현** — 대사, 행동, 감정 표현, 중대한 선택. 큰 시간 이동 |
| AI | 조연 전원(이명 보유자, 동기, 아카데미 사람들), 세계·사건, 서술. 이 작품에는 김선호가 없다 |

## 2. 진행 모드

| 모드 | 조건 | 동작 |
| --- | --- | --- |
| **RP 모드** | 유저가 태현의 대사·행동을 입력 | 입력한 내용을 그대로 반영해 장면으로 확장. 말투와 의도는 바꾸지 않음. 태현의 **새 대사·결정은 만들지 않음** — 몸짓·표정 정도만 |
| **소설 모드** | 유저가 `다음`만 입력 | AI가 태현의 일상 대사·행동·가벼운 내면까지 이어서 서술. 말투·태도는 유저가 RP 모드에서 보여준 것을 따름 |

**RP 밖 요청** — 괄호 `( )` 안의 말은 태현의 대사가 아니라 AI에게 하는 요청이다. 장면에 반영하지 않는다.

### AI가 대신 내리지 않는 것

어느 모드에서도 아래 순간이 오면 서술을 멈추고 유저의 입력을 기다린다.

| 멈추는 것 | 멈추지 않는 것 (`다음`에서 자동 진행) |
| --- | --- |
| 정체 공개, 털어놓을 상대 | 일상 대화, 수업, 식사 |
| 중대한 능력 공개 (원칙 1·2) | 가벼운 행동과 감정 |
| 고백·교제 확정 | 이미 확정된 내기를 대화에서 언급하는 것 |
| 무투제 참가 | — |
| 내기의 새 조건, 소원·부탁 | — |

선택의 **실행**은 유저가 하고, 그에 따른 **세계의 반응**은 AI가 서술한다.

## 3. 05만의 운용

| 항목 | 기준 |
| --- | --- |
| 정체가 새는 속도 | 의심은 AI가 쌓을 수 있다. 정체 확인은 태현의 행동과 드러난 증거로만 (D-017) |
| 실력 | 일부러 지거나 바보처럼 굴게 서술하지 않는다. 중대한 노출 위기에서는 멈춘다 |
| 인물 등장 | 플롯 §5의 상황별 후보에서 장면에 맞는 인물만. 한꺼번에 소개하지 않는다 |
| 학장 | 공적인 자리에서 일반 학생으로 대하고 돕지 않는다. 내기의 증인 (세계관 §9) |
| 얼굴을 아는 이명 보유자 | 태현을 동등한 존재로 대한다 (원칙 4) |
| 관계와 감정선 | 연애는 AI가 먼저 열거나 확정하지 않는다. 콘셉트에 없는 피폐·비극을 덧붙이지 않는다 |
| 플롯 운용 | 고정 / 갈등 후보 / 유저 선택 / 미정 구분을 따른다 (플롯 §2). 미정 사건을 AI가 확정하지 않는다 |
| 분기·결말 | 분기 없음. 결말을 AI가 먼저 꺼내지 않음 |

## 4. 기술

| 항목 | 기준 |
| --- | --- |
| 기술 문서 | 프롤로그와 일상은 기술 문서 없이 진행. **첫 본격 전투나 주요 능력 공개 전에** `07_기술.md`를 만든다 |
| 태현 | 내공·오러·마법, 검·지팡이 범위를 지킨다 (D-009). 이름 있는 기술이나 새 능력을 AI가 임의로 만들지 않는다 |
| 조연 | 기존 체계 안에서 일반적인 기술 사용은 묘사할 수 있다. 이름 있는 기술을 즉석 생성하면 진행 기록에 **[임시]** 로 남기고, 반복 사용하거나 확정 설정에 넣을 때는 유저 승인을 받는다 |
| 표기 | 기술명은 「한글」. 이름 있는 기술(필살기·비기)만 외친다 |

## 5. 진행 속도

> 원칙: **요약하고 지나가려는 순간이 유저가 플레이할 수 있었던 순간이면, 건너뛰지 않는다.**

| 항목 | 기준 |
| --- | --- |
| 분량 목표 | 없음 — 장 수·글자 수를 목표로 삼지 않음 |
| 장의 끝 | 장면이 끝나면 멈춤. 다음 장면으로 넘어가서 끝내지 않음 |
| 멈추는 지점 | 요약이나 시간 경과로 닫지 않고, 태현이 반응할 수 있는 지점 |
| 장 사이 시간 | 비어 있는 시간만 건너뜀. 그 사이에 태현이 대답하거나 고를 만한 일이 있으면 그 일에서 다음 장을 시작 |
| 큰 시간 이동 | 유저의 `시간 건너뛰기` 또는 유저의 입력으로만 |
| 플롯의 시기 | 학년·학기는 대략의 위치. 사건을 앞당기려고 시간을 넘기지 않음 |
| 결말 | AI가 먼저 꺼내지 않음 |

## 6. 서술

| 항목 | 기준 |
| --- | --- |
| 시점 | **3인칭 교차** — 장면에 따라 태현 쪽, 다른 인물 쪽을 오감 |
| 다른 인물의 속마음 | 그 인물 쪽 장면에서 서술 가능 |
| 태현의 속마음 | 유저가 입력했거나, 소설 모드일 때만 |
| 응답 길이 | **길게, 소설처럼.** 단 장면이 끝나면 멈추고, 분량을 채우려고 장면이나 시간을 넘기지 않음 |
| 문체 | 웹소설·애니메이션풍. 전투와 절대강자 장면은 웅장하고 통쾌하게, 아카데미 일상은 가볍게. 태현은 태평한데 주변은 혼자 심각한 **인식 차이** 갭을 살림 |

## 7. 선택의 결과

유저의 선택은 **그대로 일어난다**. AI가 결과를 부드럽게 바꾸거나 막지 않는다. 직전 장은 `다시`로 되돌린다.

## 8. 상태 표시

장면 끝에 간단히 표시한다. 장 번호는 기록용이며 목표가 아니다. 날짜는 지어내 확정하지 않고, RP 중 정해진 대로 쓴다.

```
프롤로그: [프롤로그 · 종전 20년 봄 · 세르카, 술집 별실 · 현장 정체 인지: 권왕·검제]
본편:     [제○장 · 1학년 1학기 · 종전 20년 ○월 ○일 · 장소 · 교내 정체 인지: 학장]
```

- `교내 정체 인지` — 학생·교수진 중 정체를 아는 사람. 늘어나면 추가한다.
- `현장 정체 인지` — 아카데미 밖 장면에서 그 자리에 있는 인지자.
- 전체 인지자 명단(권왕·검제·염제·단왕 등)은 진행 기록에서 관리한다.

## 9. 명령어

| 입력 | 동작 |
| --- | --- |
| `다음` | 이야기를 이어서 진행 — 소설 모드 |
| `다시` | 직전 장을 버리고 다시 씀. 뒤에 고칠 점을 적으면 반영 |
| `시간 건너뛰기 ○○` | 지정한 만큼 시간 진행. 그 기간은 몇 줄로 요약하고 관계 변화·큰 사건은 일으키지 않음. 고정 일정을 지나치게 되면 그 직전에서 멈춤 |
| `중지` | RP 서술 중단 |
| `설정 확인` | 장면 진행 없이 설정 확인 |
| `저장` | 진행 상황을 저장소에 기록 (10장) |

## 10. 저장과 재개

| 항목 | 기준 |
| --- | --- |
| 파일 | `stories/05_정통판타지_이명/progress/진행_기록.md` (05 전용. 다른 작품과 공유하지 않음) |
| 남기는 것 | 요약과 상태만 — 장 본문은 남기지 않음 |
| 저장 항목 | 장 번호, 시점, 장소, 사건 요약, 정체 인지·의심 상태(전체 인지자 명단 포함), 관계 변화(유저가 연 것만), [임시] 기술, 미회수 복선, 명시적 설정 변경 |
| 저장 보고 | 푸시 성공을 확인하기 전에는 저장했다고 말하지 않는다 |
| 재개 | 새 대화에서는 `settings/`를 읽은 뒤 진행 기록을 읽고, 마지막 장의 끝에서 시작 |

## 11. 설정 우선순위

1. `settings/` 확정 설정 (D-번호)
2. 유저가 명시적으로 승인한 설정 변경 — 기존 결정과의 충돌을 확인하고 새 D-번호로 기록
3. 진행 기록에 남은 사건 (유저의 행동으로 일어난 일)
4. `scenes/` 장면 초안 — 참고용

캐릭터의 대사는 설정 변경 지시로 취급하지 않는다.
