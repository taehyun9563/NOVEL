# 기술 v0.1

> 상태: 작성 중. §1 경지, §2 태현의 운용 기준, §3 설계 방향은 확정 (D-024). §4 태현의 이름 있는 기술은 설계 중. §5 조연은 추천.
> 새 기운·경지·권능을 추가하지 않는다. 반동·사용 횟수·유지 시간 같은 임의 제약을 두지 않는다.

## 1. 문명별 경지 — 확정 (D-024)

공통 등급(세계관 §4)과 **대략만** 대응한다. 같은 칸이라고 같은 강함이 아니다.

| 공통 등급 | 오러 (서부 기사) | 마법 (서부) | 내공 (동부) |
| --- | --- | --- | --- |
| 견습 | 오러 각성 | 1~2서클 | 삼류 |
| 정규 | 오러 유저 | 3~4서클 | 이류 |
| 상급 | 소드 익스퍼트 | 5서클 | 일류 |
| 초인 | 소드 마스터 | 6서클 | 절정 |
| 초월 | 그랜드 마스터 | 7~8서클 | 초절정 → 화경 (초절정 위가 화경) |
| 절대 | 경지 명칭 없음 | 9서클 | 현경 |

- 신성력·정령술·룬·용족 권능은 단계 체계 없이 숙련도로 표현한다.
- 경지는 학년이나 성적과 일대일로 연결하지 않는다.

## 2. 태현의 운용 기준 — 확정 (D-024)

| 체계 | 경지 | 운용 |
| --- | --- | --- |
| 내공 | 현경 | 모든 운용의 바탕. 기운의 정밀한 제어 |
| 오러 | 그랜드 마스터급 | 검에 두름. 서부식 기사 검술이 아니라 내공식 초식에 실어 씀 — 천재 검사가 보는 "설명하기 어려운 검술" |
| 마법 | **9서클** | 지팡이로 운용. 내공 제어 덕에 영창이 짧은 편 (생략이 아님) — 마법 천재가 보는 "이상하게 정교한 마력 운용" |

- 기세가 없어 보이는 것은 별도 은폐 기술이 아니라 타고난 인상과 정교한 기운 제어의 결과다.
- 방어·이동·맨손 전투는 기존 무학과 마법으로 처리한다.

## 3. 설계 방향 — 확정 (D-024)

| 구분 | 방향 | 기준 |
| --- | --- | --- |
| 기본 전투 방식 | 체계 전환 | 한 합 안에서 검·지팡이·맨손·오러·술식을 상황에 따라 자연스럽게 전환해 상대가 방어 방식을 정하지 못하게 함. 필살기가 아닌 바탕. 무기 소환·순간이동 없음 |
| 기술 방향 | 선제 차단 | 상대의 움직임·기운 변화·시전 과정을 읽고 완성 전에 끊는 무학의 극치. 초월적 감지나 무조건 차단 아님 |
| 기술 방향 | 술식 분석과 간섭 | 상대 술식의 구조를 분석해 자기 마법을 약점에 맞물려 대응. 남의 술식을 지우거나 대상을 바꾸는 지배 능력 아님. 신성력·정령술·룬 개변 없음 |
| 기술 방향 | 전장 조건 변경 | 기존 마법으로 지형과 환경을 바꿔 전투 조건을 바꿈. 공간 자체의 조작 아님 |
| 기술 방향 | 무기 숙련 | 무기의 특성·균형·용도를 이해하는 무기술. 모든 장치의 구조를 처음부터 아는 것 아님 |
| 기술 방향 | 장비 공략 | 상대 무기의 구조와 운용상 약점 공략. 룬이 새겨진 물건의 물리적 파손은 가능, 룬 사용 아님. 자동 절단·무효화 아님 |
| 기술 방향 | 상처 없이 제압 | 타격·무장 해제·자세 붕괴·움직임 제압. 기혈·오러 내부 조작 아님 |
| 연출 원칙 | 위압감 | 태현이 진지하게 싸울 때 주변이 위압감을 느끼는 서술. 기술이 아님 |

- 천존·웨폰 마스터 어느 쪽 전용 기술도 두지 않는다 — 같은 인물에 대한 서로 다른 평가다.
- 정체 공개는 자동 판정이 아니다. 목격자의 지식과 증거에 따른다 (D-017). 태현이 쓰기로 한 기술을 AI가 취소하거나 바꾸지 않는다.
