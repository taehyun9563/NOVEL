# 기술 v0.2

> 상태: 작성 중. §1 경지, §2 태현의 운용 기준, §3 설계 기준은 확정 (D-024·D-025). §4 태현의 이름 있는 기술은 설계 중. §5 조연은 추천.
> 새 기운·경지·권능을 추가하지 않는다. 반동·사용 횟수·유지 시간 같은 임의 제약을 두지 않는다.

## 1. 문명별 경지 — 확정 (D-024)

공통 등급(세계관 §4)과 **대략만** 대응한다. 같은 칸이라고 같은 강함이 아니다.

| 공통 등급 | 오러 (서부 기사) | 마법 (서부) | 내공 (동부) |
| --- | --- | --- | --- |
| 견습 | 오러 각성 | 1~2서클 | 삼류 |
| 정규 | 오러 유저 | 3~4서클 | 이류 |
| 상급 | 소드 익스퍼트 | 5서클 | 일류 |
| 초인 | 소드 마스터 | 6서클 | 절정 |
| 초월 | 그랜드 마스터 | 7~8서클 | 초절정 → 화경 (초절정 위가 화경) |
| 절대 | 경지 명칭 없음 | 9서클 | 현경 |

- 신성력·정령술·룬·용족 권능은 단계 체계 없이 숙련도로 표현한다.
- 경지는 학년이나 성적과 일대일로 연결하지 않는다.

## 2. 태현의 운용 기준 — 확정 (D-024)

| 체계 | 경지 | 운용 |
| --- | --- | --- |
| 내공 | 현경 | 모든 운용의 바탕. 기운의 정밀한 제어 |
| 오러 | 그랜드 마스터급 | 검에 두름. 서부식 기사 검술이 아니라 내공식 초식에 실어 씀 — 천재 검사가 보는 "설명하기 어려운 검술" |
| 마법 | **9서클** | 지팡이로 운용. 내공 제어 덕에 영창이 짧은 편 (생략이 아님) — 마법 천재가 보는 "이상하게 정교한 마력 운용" |

- 기세가 없어 보이는 것은 별도 은폐 기술이 아니라 타고난 인상과 정교한 기운 제어의 결과다.
- 방어·이동·맨손 전투는 기존 무학과 마법으로 처리한다.

## 3. 설계 기준 — 확정 (D-025, D-024 §3 대체)

> 대응형 콘셉트(선제 차단, 상대 마법 해체, 무기 탈취, 장비 약점 분석·파괴)는 폐기한다. 천존은 상대의 기술이나 장비를 역이용해야 강한 인물이 아니라, 본인의 무학·오러·마법으로 전투를 주도하는 대륙 정점의 절대강자다.

| 번호 | 기준 |
| --- | --- |
| 1 | 공격·방어·이동·검술·체술·마법 등 다양한 **독자 기술** |
| 2 | 천존의 절대적인 위엄과 **패도**가 느껴지는 전투 방식 |
| 3 | 내공 현경, 오러 그랜드 마스터급, 마법 9서클을 충분히 활용 |
| 4 | 웨폰 마스터의 무기 숙련도는 유지하되 상대 무기 탈취에 의존하지 않음 |
| 5 | 새로운 기운·권능, 불필요한 사용 제약(반동·횟수·유지 시간 등)을 만들지 않음 |
| 6 | 기술명은 애니메이션·웹툰·웹소설의 최강자 기술처럼 인상적으로 |

### 유지 (D-024에서 계속)

| 항목 | 내용 |
| --- | --- |
| 기본 전투 방식 | 체계 전환 — 한 합 안에서 검·지팡이·맨손·오러·술식을 자연스럽게 전환. 무기 소환·순간이동 없음 |
| 연출 원칙 | 태현이 진지하게 싸울 때 주변이 위압감을 느끼는 서술 |
| 이명 | 천존·웨폰 마스터 전용 기술을 따로 두지 않음 |
| 정체 | 자동 판정 없음. 목격자의 지식과 증거에 따름 (D-017). 태현이 쓰기로 한 기술을 AI가 취소하거나 바꾸지 않음 |

## 5. 조연 — 추천

전투 방식과 대략적 경지만 둔다. 이름 있는 기술은 RP 중 [임시]로 만들고 유저 승인 후 편입한다 (D-023).

| 인물 | 경지 (대략) | 전투 방식 |

| 권왕 석무진 | 현경 | 권법. 한 방이 무거움 |
| 검제 세레나 | 그랜드 마스터 | 정밀한 오러 검술 |
| 염제 오스왈드 | 9서클 | 광역 화염 |
| 리제 | 소드 익스퍼트 | 정석 기사 검술. 뇌전 계열 오러가 싹틈 |
| 아리엔 | 오러 유저 | 레이피어 찌르기 |
| 미아 | 오러 유저 | 쌍단검, 기동 |
| 루카 / 클로에 | 4서클 | 이론형 만능 / 화염 특화 |
| 황보연 / 설유나 / 사도린 | 이류~일류 | 진법 / 빙공 / 암기·경공 |
| 세실리아 / 엘린 / 브리다 | 숙련도 | 치유·정화 / 정령 소환 / 룬 공예 |
