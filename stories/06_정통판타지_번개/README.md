## 주의
이번 승인에 포함되지 않은 상세 설정은 생성하거나 확정하지 않는다. 기존 작품과 세계관·인물을 공유하지 않는다. 경지 체계(D-004~D-005), 최고위 마법 4종의 이름·효과·정식 영창(D-006), 주인공 이명·성격(D-007~D-008), 프로필·극의·전력 평가·과거·소속(D-009~D-013), 주요 인물 3인과 관계 축 및 카르젠과의 미결 승부(D-014~D-016), 4부 본편의 배경 갈등·등장 배치·구조(D-017~D-019), RP 운용·시작점 및 최고위 4종 정식 영창 필수 조건(D-020~D-022)은 확정되었으며, 연애·감정선·실제 사건의 전개와 결말·RP 집필 담당자는 미확정이다. Claude의 1차 독립 검수(2026-11-20)와 사용자 조율 결정에 따라 문서 동기화를 수행했다. 이 작업은 확정 설정의 변경이 아니다.

## 06 설계·검수 운영 결정 (2026-11-20)
- 이 작품의 **설정 설계: ChatGPT / 독립 검수: Claude / 최종 결정: 사용자**. 다른 작품에 자동 적용하지 않는다.
- 중요 세계관·능력·주요 인물·서사 분기는 **ChatGPT 초안 → Claude 독립 검수 → ChatGPT 조율 → 사용자 승인 → 저장소 반영**을 기본으로 한다.
- 단순 문서 동기화·오탈자·링크 등 의미가 바뀌지 않는 정리는 간소화한다.
- 국가 전략급 해당 여부는 후속 전력 설계 및 Claude 검수를 거쳐 **D-012에서 [확정]**되었다. 각국이 뇌제를 국가 전략급 인물로 평가하지만, 새로운 경지는 아니다.
- 국경 분쟁 개입 동기는 사람 보호가 아닌 **강적과의 대결 욕구**로 D-011에 확정되었다. 그때 맞붙은 상대가 카르젠이며 직접 승부가 미결이라는 점은 D-016에 확정되었다.
- 현재의 무역·군사적 긴장은 과거 D-011의 분쟁과 자동으로 동일시하지 않는다. 본편 4부 구조가 확정되었더라도 태현의 행위·실제 전쟁·연애·재대결 결과는 D-019에 따라 사용자가 RP에서 결정한다.
- RP 진입은 `RP 시작`으로 구분하고, 실제 진행 전에는 본문을 쓰지 않는다(D-020~D-021). D-006 최고위 4종의 장문 정식 영창은 **전문 필수·단축/생략 금지**(D-022), 일반 마법에는 D-004를 적용한다.
- **10단계 종합 검수 완료(2026-11-20):** ChatGPT 자체 점검과 Claude 독립 검수 모두 중대 충돌·필수 설계 누락 없음으로 판정, 사용자 승인으로 **설계 완료 / 본편 시작 대기**로 상태 변경. 이는 D-000~D-022의 의미 변경이나 신규 D-결정이 아니다.
- **운영 주의:** 최고위 영창 중 이동·회피 및 영창 중단·재개 규칙은 미정이므로 최초 필요 시 사용자 결정으로 다룬다. RP 중 처음 정해지는 도시명 등은 `progress/진행_기록.md`에 기록하여 일관성을 유지하되, 별도 승인 없이 `settings/`의 확정 설정으로 올리지 않는다.
