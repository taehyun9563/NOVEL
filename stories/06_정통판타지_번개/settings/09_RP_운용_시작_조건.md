# 09 — RP 운용 규칙 및 본편 시작 조건

> **상태: [확정] — 사용자 승인 2026-11-20**
> 관련 결정: **D-020~D-022**
> 초안·조율: ChatGPT / 독립 검수: Claude / 영창 범위 최종 선택·승인: 사용자
> **범위:** 소설형 자동 진행과 직접 RP의 결합, 사용자 선택권, NPC·국가의 자율성과 사건 예고, 시간·문체·명령어·저장, 본편 첫 장면 및 최고위 4종의 정식 영창 필수 규칙을 확정한다.
> **주의:** 문서가 확정되어도 **본편은 아직 시작하지 않는다.** RP 집필·진행 담당자는 **사용자가 별도로 지정**한다(`ai/README.md`). 기존 D-000~D-019 유지.

## 1. 진입 및 진행 방식 [확정 · D-020]

- 기본 형식은 **웹소설형 서술 + 직접 대사·행동 입력형 RP 혼합**이다.
- `RP 시작` 명령으로 설계·검토 상태에서 **본편 진행 상태**로 진입한다. 그 전까지 `다음`은 설정 설계의 다음 단계이며, RP 명령으로 해석하지 않는다. RP 문서 본문에서의 `다음`은 **본편 진입 후**의 자동 진행만을 뜻한다.
- 본편에서 `다음`을 입력하면 장면을 자연스럽게 진행한다. **태현의 평범한 대사·반응·행동도 서술**하며, 태현을 침묵시키고 주변 NPC만 말하도록 반복하지 않는다.
- 사용자가 태현의 대사나 행동을 직접 지정하면 그 의미를 **우선 반영**한다. `대사 다듬어줘` 등 별도 지시가 없는 한 발언 의미, 상대, 의도를 임의로 확대·반전하지 않는다.
- 사용자가 선택·대사를 지정한 장면은 그 지정에 따른 NPC 반응과 결과까지 이어서 쓴다. 불필요하게 매 문장마다 확인하지 않는다.

## 2. 자동 진행의 경계와 선택권 [확정 · D-020]

| 영역 | 자동 진행 가능 | 사용자 결정으로 남길 것 |
|---|---|---|
| 일상·대화 | 걷기, 식사, 관찰, 농담, 인사, 가벼운 도발과 평범한 답변 | 개인의 장기적 신념을 뒤집는 결정, 지속적 복종·고용·충성 |
| 전투 | 강적에 대한 흥미·도발, 기습에 대한 회피·방어, 이미 진행 중인 교전의 비결정적 기본 반격 | 태현의 주도적 중대 결투 개시, 카르젠 재대결 수락·시기, 주요 인물 살해·대규모 파괴 |
| 최고위 마법 | 기본 번개 강화·일상적 전격 운용 및 서술 | D-006의 최고위 네 마법 중 어느 것을 언제 발동할지 |
| 정치·이동 | 장면 안의 사소한 물품 구매나 대화, 짧은 이동 | 국가의 중대한 제안 수락·거절, 국가 편입·전쟁 참전, 타국으로의 중대한 무대 이동 |
| 관계 | 상대의 행동에 따른 자연스러운 신뢰·호감·경계 변화 | 태현의 고백·명시적 교제 수락 또는 거절·결별 같은 공식 관계 전환 |

- **태현의 호전성(D-008)은 강제 전투 개시 규칙이 아니다.** 도발·흥미 발언은 자동 서술할 수 있으나 중대한 공격 개시·결투 선택은 사용자에게 남긴다.
- NPC가 먼저 공격할 수 있고 태현이 기본 방어·회피로 반응할 수 있다. 단순 공격을 받았다는 사실만으로 AI가 태현에게 상대 처형, 전면전 선포, 최고위 마법 사용을 대신 결정하지 않는다.
- 경미하고 되돌릴 수 있는 일상적 판단마다 멈추지는 않는다. **정치·전투·관계에서 지속적·중대한 결과가 발생하는 지점**에 사용자 개입 기회를 보장한다.
- 사용자 입력을 기다리는 장면에서는 전형적인 선택지 목록이나 메타 설명을 매번 내보내지 않고, 자연스러운 서사적 순간에서 멈춘다.

## 3. 국가와 NPC의 자율성 및 대사건 [확정 · D-020]

- 각국과 레아·에른·카르젠은 D-002·D-014~D-019의 **자기 목표와 성격에 따라 태현 없이도 행동**한다. 태현의 결정권은 NPC의 행동 전부를 정지시키는 권한이 아니다.
- **전쟁 개시·국가 간 조약 등 세계의 대사건**은 인과관계와 앞선 사건의 축적에 따라 NPC·국가의 행동으로 발생할 수 있다. 단, 태현이 영향을 미치거나 외면할 수 있는 중대한 사안이라면 **징후 → 정보를 접할 기회 → 행동·방관의 선택 기회 → 결과**의 순서를 원칙으로 한다.
- `다음` 한 번으로 사전 맥락 없는 전쟁을 발발시키고 종결하거나, 태현의 개입 기회를 건너뛰지 않는다. 사용자가 방관·거절을 선택하면 국가는 그와 독립적으로 결정을 이어갈 수 있다. 모든 사건을 반드시 태현이 해결하지도 않는다.
- 레아는 업무와 판단을 계속하고, 에른은 국가 책임을 우선하며, 카르젠은 사절단 호위 임무와 개인적 승부욕을 함께 지닌다.
- **레아의 자연스러운 호감·경계·신뢰 변화는 서술 가능**하지만 사용자 결정 없이 연애가 성립했다거나 과거부터 사랑해 왔다는 설정을 덧붙이지 않는다(D-015).
- D-011의 과거 국경 분쟁을 현재 D-017의 무역 갈등과 동일 사건으로 합치지 않고, 카르젠과의 과거 직접 대결은 D-016에 따라 **승부 미결**로 유지한다.

## 4. 문체·전투·기술 표기 [확정 · D-020·D-022]

- 실제 웹소설처럼 **자연스럽고 유려한 서술**을 사용한다. 대사와 행동·묘사는 **빈 줄을 둔 문단**으로 구분하고, 인물별로 고정된 어미·말버릇을 반복하지 않는다.
- D-008을 준수한다. 평소 태현은 **자신감·유머·솔직함**이 있으며, 강적 앞에서는 즐거움을 보이고 진정으로 분노하면 차가워진다. 이전의 과묵한 정체은폐형으로 바꾸지 않는다.
- 장면 끝에 매번 요약·표·해설·기계적인 선택지 목록을 붙이지 않는다.
- **이름이 확정된 기술에만** 해당 명칭을 사용한다. 기술명이 필요한 경우 `「기술명」`으로 표기하며, 평범한 타격·회피·기본 전격에 임의의 기술명을 발명하거나 불필요하게 외치지 않는다.
- 최고위 번개 마법 네 가지의 **마법명·효과·정식 영창 원문은 D-006**(`settings/04_주인공_마법.md`)을 따른다. 진명 표기는 예컨대 `「제르바인 아르카 레비아투스」`처럼 원문 그대로 사용한다.
- **D-022:** 이 최고위 네 마법은 발동할 때마다 **해당 정식 영창 전체를 순서대로 완료해야 하며 단축·생략·무영창 발동이 불가능**하다. 이름만 외치거나 `영창을 외웠다`라는 요약으로 대신하여 즉시 발동시키지 않는다.
- **일반 마법은 D-004의 경지별 운용 규칙을 유지한다.** 대가 이상에게 적용되는 일반적인 단축 영창 운용을 최고위 네 마법까지 확장하지 않는다. 전신 번개 강화·기본 전격 운용에 별도 장문 영창을 강제하지 않는다.
- 정식 영창의 필수성은 자동 무적·자동 명중·시간 정지·상대 행동 봉쇄·고정 반동·영창 중 무조건 안전을 뜻하지 않는다. **완료하기 전에는 해당 최고위 마법이 발동하지 않으며**, 적의 대응·방해와 전투 결과는 D-004·D-010에 맞춰 전개한다.
- **최고위 마법의 자발적인 사용 선택은 사용자에게 남긴다.** 이미 선택된 마법을 사용자 의사에 반하여 다른 최고위 마법으로 대체하지 않는다.

## 5. 시간·명령어·상태 표시 [확정 · D-020]

- **큰 시간 건너뛰기는 사용자의 명시적 요청으로만 한다.** 평범한 장면 내 이동·대화에 따라 분·시간이 자연스럽게 흐르는 것은 가능하다.
- **사용자가 플레이할 수 있었던 중요한 사건·협상·결투·관계 전환은 요약으로 건너뛰지 않는다.** 장 수·분량 목표나 자동으로 다음 부에 진입해야 하는 기한은 없다.
- 상태 표시는 기본적으로 짧게 `[제○부 · 본편 ○일차 · 장소]`로 하며, **시간대가 필요한 경우** `[제○부 · 본편 ○일차 · 낮/밤 등 시간대 · 장소]`처럼 추가할 수 있다. 세계의 공식 연호·달력을 창작하지 않고 상대적인 **본편 일차**를 사용한다. 장면마다 매번 필수 반복하지 않고 날짜·장소 변화 시 명확하게 표시한다.

| 입력 | 의미 |
|---|---|
| `RP 시작` | 사용자가 본편 진행을 명시적으로 시작 |
| `다음` | 본편 진입 후 현재 장면을 소설형으로 이어서 진행 |
| `다시` | 직전 장면을 다시 서술, 그 전의 확정 경과·원본 설정 보존 |
| `시간 건너뛰기` | 사용자가 지정한 시간 범위로 이동. 지정되지 않았다면 한 번 확인 |
| `중지` | 본편 진행 중단, 메타 대화·설정 검토로 전환 |
| `설정 확인` | 최신 GitHub 원본 D-번호와 실제 RP 경과를 대조 |
| `저장` | 작품 06 전용 실제 RP 진행 기록을 GitHub에 생성·갱신 |

- 사용자 지시가 명확하면 별도 명령어를 정확히 입력하지 않아도 의도를 따른다.
- `다시`는 **직전 미확정 장면의 재작성**이며, 이미 확정된 D-결정이나 그 이전의 합의된 결과를 무단으로 삭제하지 않는다.

## 6. RP 기록과 설정 변경의 분리 [확정 · D-020]

- 실제 RP가 시작된 뒤 `저장` 시 `stories/06_정통판타지_번개/progress/진행_기록.md`에 **이미 발생한 사건·날짜/위치·태현과 NPC의 선택·관계 변화·현재 진행 위치**를 기록한다.
- `progress/`는 본편 경과이지 세계관 확정 설정 원본이 아니다. 실제로 일어나지 않은 사건이나 예측한 결말을 사실처럼 저장하지 않는다.
- 설정의 새로운 확정·수정은 `settings/`와 `DECISIONS.md`에서 사용자의 승인과 별도 D-번호로 관리한다. 기존 결정은 임의로 덮어쓰지 않는다.
- GitHub 기록 기능을 사용할 수 없는 환경에서는 **저장했다고 주장하지 않는다.** 파일 접근이 필요할 때도 최신 상태를 확인한 후 기록한다.
- **현재는 본편이 시작되지 않았으므로 진행 기록 파일을 새로 생성하지 않는다.**

## 7. 본편 시작 조건 [확정 · D-021]

- **RP 시작 명령 전에는 본문을 쓰지 않는다.** 사용자가 RP 담당자를 별도 지정한다. 설계 담당이 ChatGPT라는 사실만으로 본문 집필 담당이 자동 결정되지 않는다.
- **시작 시점:** `[제1부 · 본편 1일차 · 낮 · 루메인 항구도시]`
- **첫 순간:** 뇌제 박태현이 **평소처럼 루메인 연맹의 어느 항구도시에 들어서는 순간**. 고정된 도시명·숙소·거점·구체적 날짜를 추가하지 않는다.
- 태현에게는 특별한 국가 임무나 루메인 소속이 없다(D-013). 항구도시에서는 카르디스의 광물·무기 공급 갈등과 제국 사절단에 관한 소문이 들릴 수 있다(D-017~D-018).
- 카르젠의 존재는 **제1부에서 도착 소식으로 암시**하고 직접 재회·결투를 강제하지 않는다. 레아의 첫 만남·업무상 거래·감정 변화도 강제하지 않는다(D-015·D-018~D-019).
- 사용자의 첫 입력 지점은 **태현이 항구도시에 들어선 순간**이다. 실제 RP 진입 직후 사용자가 `다음`을 선택하면 평범한 행동·대사를 포함해 그 자리에서 자연스럽게 이야기를 진행한다.
- 새로운 주요 NPC, 특수 능력, 국가 조직, 사건의 승패·로맨스·결말을 시작 장면에 임의로 선확정하지 않는다.

## 8. 여전히 미정인 사항

- **RP 실제 집필·진행 담당자**(별도 사용자 지정)
- 실제 시작 일시, 도시의 고유명과 세부 지리, 최초 인물 접촉·대사·협상, 카르젠 재대결 시점
- 전쟁 발발·정세 변화·재대결 결과, 연애 관계와 감정선의 구체적 진행 및 결말
- 최고위 네 마법 이외의 일반 기술명·상세 전투 수치·기타 새로운 마법 영창
