# DECISIONS — 07 북부대공 빙제

이 문서에는 **결정 요약·제안자·상태·본문 위치**를 기록한다. 정식 영창과 상세 효과는 `settings/`에서만 관리한다. 확정된 결정을 변경할 때는 새 D-번호를 발급하고 옛 결정은 [대체됨 → D-신규]로 표기한다.

### D-000 [확정]
- 주제: 07 기본 콘셉트
- 요약: 별개 작품 07의 주인공은 박태현이며, 북부대공의 신분과 빙제(氷帝)의 이명을 지닌 얼음 마법사로 설계한다. 세계관 상세와 본편은 아직 확정·시작하지 않는다.
- 제안자: 사용자 (핵심 콘셉트 직접 선택)
- 본문 위치: `settings/01_콘셉트.md`
- 승인일: 2026-11-21 (기존 대화 승인 사항의 최초 GitHub 기록)

### D-001 [확정]
- 주제: 마나·경지·빙제 전투 체계
- 요약: 단일 마나와 개인별 고유 속성, 익스퍼트·엘리트·마스터·그랜드마스터·초월 5단계를 사용한다. 이명은 초월에 도달한 자에게 붙고 이명 강자 간 고정 서열은 없다. 태현은 얼음 속성의 순수 마법사로 광역 빙결·무기 생성·빙룡·천후 지배를 운용한다. 얼음 육체화·해방 형태를 제외하고 별도 대가·제약을 추가하지 않는다.
- 제안자: 사용자 (Claude 대화 확정·Claude 독립 검수서에서 전달)
- 본문 위치: `settings/03_능력_체계.md`
- 승인일: 2026-11-21 (기존 승인 사항의 최초 GitHub 기록)

### D-002 [확정]
- 주제: 최고위 빙결 마법 3종의 명칭·효과·정식 영창
- 요약: 보레아스 니베 드라시엘(거대 빙룡 조각상), 에르나디아 녹스 네벨리움(절대영도에 가까운 세계 동결), 글라시온 히에마 발케스타(빙성·수만의 조각 기사·독립 빙검) 3종의 최종 명칭·효과·영창·연출을 승인한다. 빙성은 집단 명령·개별 기사 조종·독립 빙검 제어를 모두 허용한다. 네 번째 최고위 마법은 추가하지 않는다.
- 제안자: ChatGPT (효과·영창 초안 및 수정); Claude (Ⅰ·Ⅲ 최종 명칭 최초 제안, 독립 검수)
- 본문 위치: `settings/04_최고위_빙결_마법.md` §1~4
- 승인일: 2026-11-21

### D-003 [확정]
- 주제: 최고위 3종 정식 영창 전문 의무
- 요약: 최고위 Ⅰ~Ⅲ은 매번 정식 영창 전문을 처음부터 끝까지 완료해야 발동한다. 단축·생략·무영창은 불가하고, 영창 중 자동 무적·발동 보장 등은 없다. 일반 마법에는 이 특별 의무를 강제하지 않으며 별도의 반동·횟수 제한·봉인을 추가하지 않는다.
- 제안자: 사용자 (06번 방식의 필수 영창을 직접 선택)
- 본문 위치: `settings/04_최고위_빙결_마법.md` §5
- 승인일: 2026-11-21

### D-004 [확정]
- 주제: 사용자 기확정 콘셉트 세부 복원
- 요약: 북부 수호와 황실 정치의 이중 중심축, 정통 판타지에 영지 일상·가벼운 장면 병행, 본편 시작 시 대공 즉위 후 수년 경과 및 빙제 이명의 대륙 내 인지도 확립. 연애는 미정.
- 제안자: 사용자 (기존 Claude 대화 승인 사항 복원)
- 본문 위치: `settings/01_콘셉트.md`
- 승인일: 2026-11-21 (기존 승인 사항 기록 복원)

### D-005 [확정]
- 주제: 대륙 구도·북부 역사·북방 위협
- 요약: 제국과 남·서쪽 경쟁국 몇 개, 옛 북부 왕국의 제국 편입 및 자치권·독자 군대, 설원 마수의 주기적 대규모 남하와 북방 이민족·설원 부족을 세계 구조로 확정. 동부 무예·마법 문화권은 채택하지 않으며 개별 사건은 미정.
- 제안자: 사용자 (기존 Claude 대화 승인 사항 복원·검수 후 재승인)
- 본문 위치: `settings/02_세계관.md` §1~2·4·6
- 승인일: 2026-11-21

### D-006 [확정]
- 주제: 황제와 북부대공의 출병 권한
- 요약: 황제는 북부군 출병을 요청할 수 있으나, 실제 출병에는 북부대공의 동의가 반드시 필요하다(B안). 북부 내정·군 지휘·긴급 방어는 대공의 권한이고, 제국 차원 외교·전쟁 선포는 황제 권한이다.
- 제안자: 사용자 (B안 직접 선택)
- 본문 위치: `settings/02_세계관.md` §3
- 승인일: 2026-11-21

### D-007 [확정]
- 주제: 북부의 식량·경제 기반
- 요약: 북부는 식량 자체 생산·비축 기반이 있으나, 긴 겨울 때문에 필요한 곡물의 일부를 외부 교역에 의존한다. 전량 수입이나 황제의 교역 독점은 확정하지 않는다.
- 제안자: 사용자 (Claude·ChatGPT 추천안 선택)
- 본문 위치: `settings/02_세계관.md` §5
- 승인일: 2026-11-21

### D-008 [확정]

- 요약: 태현은 28세이며, 전임 대공의 사망으로 정식 세습했다. 재임 기간은 수년이지만 정확한 즉위 연도·초월 시기·사망 원인·가족 관계·외형은 미정이다.
- 제안자: 사용자 (28세 및 사망 후 세습 직접 선택)
- 본문 위치: `settings/05_주인공.md` §1
- 승인일: 2026-11-21

### D-009 [확정]
- 주제: 박태현의 혼합 성격
- 요약: 오만한 절대강자·냉혹한 군주·자유분방한 반항아의 혼합 성격, 결정권과 결과에 대한 자기 책임, 강자의 여유와 통치 책임의 공존, 적과 배신에 대한 냉혹함을 확정한다. 개별 서사 사건·연애 성향은 미정이다.
- 제안자: ChatGPT (성격 후보·혼합안 최초 제안); 사용자 (세 요소 선택·최종 승인); Claude (독립 검수)

### D-010 [확정]
- 주제: 대상별 말투·황제 하대 C안 수정본·RP 적용
- 요약: 황제에게도 자연스럽고 차분한 하대를 기본으로 하되 자치권을 침해받으면 냉혹하게 선을 긋는다. 중앙 귀족·북부 지휘관·다른 초월자 등 대상별 말투와 사용자 승인 기준 대사를 기록한다. 대사·어미를 고정하지 않고 사용자 RP 직접 지시를 우선한다.
- 제안자: 사용자 (황제 하대·대상별 표현 최초 직접 제시 및 C안 선택); ChatGPT (C안 수정 대사 제안); Claude (독립 검수)
- 본문 위치: `settings/05_주인공.md` §3~5
- 승인일: 2026-11-21
