# 07 — 북부대공 빙제

- 작품 번호: **07**
- 작품명: **미정** (현재 구분명: 북부대공 빙제)
- 주인공: **박태현**, **28세**, 북부대공, 이명 **빙제(氷帝)**
- 장르 방향: 정통·제국 판타지 / 북부 수호·황실 정치 / 영지 일상
- 상태: **기본 콘셉트·세계관·능력 체계·최고위 빙결 마법·주인공 성격·말투 및 황제·태현 관계 및 북부군 총사령관·행정총관 설정 확정 / 기타 인물 관계·본편 설계 중 / 본편 미시작**
- 최종 결정권: 사용자
- 설계 과정: ChatGPT 제안·조율, Claude 독립 검수, 사용자 최종 승인. 일부 콘셉트·세계관은 Claude 대화의 기존 사용자 승인 사항을 복원함.
- **07의 전체 상시 설계·검수 및 본문·RP 담당자는 아직 별도로 지정되지 않음**. 06의 역할 예외를 07에 자동 적용하지 않는다.

## 핵심 확정 내용

- **북부:** 옛 북부 왕국이 제국에 편입되며 자치권·독자 군대를 보유. **현행 조약상** 북부군 출병에는 **북부대공 동의 필수**. 황제는 편입 조약을 **일방 개정할 법적 권한**이 있지만 실제 개정 사건·북부의 대응은 미정(D-011).
- **위협:** 설원 마수의 주기적 대규모 남하, 북방 이민족·설원 부족. 구체적인 사건은 미정.
- **경제:** 식량 자체 생산·비축 + 외부 곡물 교역 일부 의존.
- **주인공:** 28세, 전임 대공 사망 후 정식 세습, 수년째 통치 중. 빙제라는 이명은 대륙에 알려짐.
- **성격:** 오만한 절대강자·냉혹한 군주·자유분방한 반항아. 황제에게도 자연스럽고 차분한 **하대**를 기본으로 함.
- **황제:** 50세 전후의 유능한 권위주의적 남성 황제. 황권 강화·중앙집권을 지향하며 태현의 힘을 인정하지만 독자 군권을 견제함(D-012~D-013).
- **북부군 총사령관:** 로데릭 벨하임, 45세 그랜드마스터. 전임 대공 시절부터 복무했고 태현이 총사령관으로 임명. 북부와 대공 모두에게 충성하는 공적인 충신이며 위임받은 작전·긴급 방어를 지휘함(D-014).
- **북부 행정총관:** 에블린 카르델, 32세 여성. 전임 대공 시절부터 행정 실무에 종사했고 태현이 직접 발탁. 원칙주의 성격으로 행정·재정·식량을 책임지며 로데릭과 동등하게 협력함(D-015).
- **초월 경지:** 초월자 간 공식 고정 서열 없음.
- **최고위 마법:** 보레아스 니베 드라시엘(거대 빙룡 조각상), 에르나디아 녹스 네벨리움(극한 광역 동결), 글라시온 히에마 발케스타(빙성·수만 조각 기사·독립 빙검). **매번 정식 영창 전문을 완료해야 발동**.

## 미정·주의

- 국가·영지 이름, 옛 왕국 역사·가문 관계, 황제의 이름·경지·과거 관계, 로데릭의 개인 무기·속성 종류·외형, 에블린의 경지·속성 종류·무기·외형 및 기타 측근·다른 초월자 인물, 구체적 RP·연애·전쟁·결말.
- 태현의 외형, 전임 대공 사망 원인, 정확한 즉위 연도·초월 도달 연도는 미정. 예전 23세 즉위·25세 초월 초안은 확정 아님.
- 과거 미채택 이름(에르데인·노르바인·황실 사절 등)을 확정 설정으로 사용하지 않는다.
- 06 세계관·인물·경지·기술명은 07에 자동 유입하지 않는다.
- 본편은 시작하지 않았고 `progress/` 진행 기록을 만들지 않는다.
