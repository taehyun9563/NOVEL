# 03 — 마나·경지·주인공 전투 방식

> 상태: **[확정] — 사용자 결정으로 전달된 07 능력 체계**
> 결정: `DECISIONS.md` D-001
> 출처 경위: Claude의 07 독립 검수 문서에서 'Claude 대화에서 사용자가 확정'한 항목을 인계받음. 2026-11-21 GitHub에 최초 반영. 세부 역학이 없는 부분은 임의 보완하지 않는다.

## 기본 원리 [확정 · D-001]

- 마나는 **하나의 공통 근원**이며, 사람마다 **타고난 속성**이 다르다.
- 박태현의 타고난 속성은 **얼음**이다.

## 경지 [확정 · D-001]

`익스퍼트 → 엘리트 → 마스터 → 그랜드마스터 → 초월`

- **초월**에 오른 인물에게 이명이 부여된다.
- 초월 경지의 이명 강자 사이에는 **확정된 서열이 없다**.
- 후속 D-017: 본편 시작 시점 초월자는 대륙 전체 **총 8명**. 제(帝)·왕(王)·그 외 이명은 세간의 별호로서 **공식적인 위계·경지·전투 순위를 뜻하지 않는다**. 명단은 `10_초월자.md` 참조.
- '빙제'는 박태현의 **이명**이며, 경지 이름을 대체하지 않는다.

## 박태현의 전투 방식 [확정 · D-001]

- **순수 마법사**. 검술가 직업이나 별도 검술 경지를 부여하지 않는다.
- 얼음 무기를 즉석에서 만드는 것도 **빙결 마법의 운용**으로 간주한다.
- 일반 능력 범위: **광역 빙결 / 얼음 무기 생성 / 빙룡 / 천후 지배**.
- **제외:** 신체를 얼음으로 바꾸는 능력, 별도의 해방 형태.
- 별도의 대가·반동·사용 횟수 제한 등 **추가 제약은 두지 않는다.**
- 대표 일반 빙결 마법 12종의 이름·효과, 일반 빙룡과 최고위 빙룡의 구분은 후속 `12_일반_빙결_마법.md`(D-020)로 확정했다. 일반 마법의 실제 가능한 형태는 이 12종으로 제한하지 않는다.
- 최고위 빙결 마법 3종은 별도 문서 `04_최고위_빙결_마법.md`에서 확정했다. 그 3종에 한해서는 사용자 선택으로 **정식 영창 전문 필수**라는 발동 조건을 둔다(D-003).

## 미정

- 타인의 속성별 개별 상세, 경지마다 가능한 구체 마법 목록
- 마나 사용의 물리적 수치와 전투력 순위, 추가 일반 기술의 이름(대표 12종은 D-020으로 확정)
- 07만의 구체적인 영창·마법 교육 및 사회 제도

**주의:** 06번의 별개 5경지(입문·숙련·상급·대가·극의)를 복사하지 않는다.
