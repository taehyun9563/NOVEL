# 09 — 국가·도시·북부대공령 명칭

> 상태: **[확정] — D-016 / 사용자 기존 추천안 유지 선택 및 2026-11-21 통합안 반영**
> 선행 기준: \`02_세계관.md\` D-005·D-007·D-011
> 본문 진행·개별 국가 간 전쟁·교역 계약은 이 문서로 발생하지 않는다.

## 1. 국가와 방향 [확정 · D-016]

| 구분 | 명칭 | 정치적 위치 |
| --- | --- | --- |
| 중앙 | **베르티안 제국** | 황제가 통치하는 제국 |
| 제국 북부 | **설가르 북부대공령** | 옛 설가르 왕국이 제국에 편입된 자치 대공령; **별도 주권국 아님** |
| 대륙 남부 | **리오네 왕국** | 남쪽 경쟁국 |
| 대륙 서부 | **크레도스 왕국** | 서쪽 경쟁국 |

- 리오네=남부, 크레도스=서부는 사용자가 선택한 기존 통합 추천안의 배치다. 국가 명칭만 채택하고 방향이 비어 있다고 간주하지 않는다.
- 제국의 외교·전쟁 선포권은 황제에게, 설가르의 현행 내정과 북부군 지휘권은 대공에게 있다(D-011). **황제의 편입 조약 일방 개정권도 그대로 유지**한다.
- 크레도스·리오네의 세부 국경·거리·역사 및 각 국가 간 전쟁 상태는 미정이다. 제국 밖 경쟁국이 반드시 적국인 것은 아니다.

## 2. 제국·북부·왕국 주요 도시 [확정 · D-016]

| 소속 | 이름 | 용도·위치 |
| --- | --- | --- |
| 베르티안 | **세라덴** | 제국 수도·황궁 |
| 베르티안 | **베르몬** | 제국 서부의 교역·군사 거점 |
| 베르티안 | **라티아** | 제국 남부의 곡물 유통 거점 |
| 설가르 | **칼드베인** | 북부대공령 수도·대공성 |
| 설가르 | **노르센** | 북부 최전선 성채 도시 |
| 설가르 | **베르삭** | 북부 물자·군수 생산 도시 |
| 설가르 | **헤이마르** | 북부 해안 항구도시 |
| 리오네 | **리에나** | 남부 왕국 수도 |
| 리오네 | **미라젠** | 곡물 생산·교역 도시 |
| 크레도스 | **드라킨** | 서부 왕국 수도 |
| 크레도스 | **켈베스** | 국경 교역·방어 도시 |

- 위 11개는 주요 명명 거점이며, 세계의 모든 도시를 열거한 목록이 아니다.
- 북부는 자체 식량 생산·비축 기반이 있으면서 일부 곡물만 외부 교역에 의존한다(D-007). 라티아·미라젠이 존재한다는 사실만으로 특정 교역 계약·독점을 확정하지 않는다.
- 벨/베르 계열 이름의 유사성은 Claude 검수 R1에서 지적되었으나 대체 명칭 선택은 아직 없다. **기존 사용자 선택 이름을 임의로 변경하지 않는다**. 향후 개명은 별도 신규 결정으로 처리한다.

## 3. 보류

세부 지도·거리, 국경선, 교역량·운송로·환율, 각 국가의 왕족 구성, 설가르 편입 조약 체결 연도 및 옛 왕국의 상세 역사.
