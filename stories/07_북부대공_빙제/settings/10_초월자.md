# 10 — 대륙의 초월자 8명과 제국 중앙의 정치적 관계

> 상태: **[확정] — D-017 / 사용자 총 8명·국가 배치 선택, Claude M2·M3 검수 후 ChatGPT 조율안 반영**
> 기존 원칙: \`03_능력_체계.md\` D-001 / \`02_세계관.md\` D-005·D-011 / \`06_황제_및_관계.md\` D-012~D-013

## 1. 본편 시작 시점의 전체 명단 [확정 · D-017]

**본편 시작 시점 대륙 전체 초월자는 정확히 8명.** 설가르는 독립국이 아니므로 박태현은 베르티안 제국의 4명 중 1명이다.

| 소속 | 인물 | 이명 | 타고난 속성 | 지위·정치적 위치 |
| --- | --- | --- | --- | --- |
| 베르티안 / 설가르 북부 | **박태현** | **빙제(氷帝)** | 얼음 | 북부대공, 북부 독자 군권 보유(D-000·D-011) |
| 베르티안 / 중앙 | **카이런 레스타** | **염왕** | 불 | 황실 직접 협력 전력 |
| 베르티안 / 중앙 | **세리나 벨프** | **성광** | 빛 | 제국 소속이지만 황실 직속이 아닌 독립적 초월자 |
| 베르티안 / 중앙 | **하르벤 로스텔** | **산왕** | 땅 | 제국의 이익과 황제의 정책을 사안별로 판단하는 초월자 |
| 리오네 / 남부 | **르하인 세르** | **뇌제** | 번개 | 리오네 소속 |
| 리오네 / 남부 | **이사벨 로메아** | **해왕** | 물 | 리오네 소속 |
| 크레도스 / 서부 | **테르윈 베크** | **풍왕** | 바람 | 크레도스 소속 |
| 크레도스 / 서부 | **나디아 르펜** | **야왕** | 어둠 | 크레도스 소속 |

**국가별 총계: 베르티안 4명(중앙 3·북부 1), 리오네 2명, 크레도스 2명.**

- 명단의 속성은 캐릭터의 고유 속성이다. 각자의 개별 기술·전투법·승패 기록은 미정이다.
- D-001의 경지 \`익스퍼트 → 엘리트 → 마스터 → 그랜드마스터 → 초월\`는 유지한다.
- 이명은 세간이 붙인 별호다. **제(帝)·왕(王)·그 밖의 표기 사이에는 공식 경지·지휘권·위력 서열이 없다.** 사회적 평판이나 개인별 경쟁 의식은 다를 수 있다.
- 현재 8명 이외의 숨겨진 기존 초월자를 임의 설정하지 않는다. 추후 누군가 초월에 도달한다면 사용자 승인에 따른 별도 서사·설정 결정이 필요하다.

## 2. 제국 중앙 초월자 3명과 황실 [확정 · D-017]

Claude 검수 M2에 대해 사용자 승인을 받은 **C안: 일부 황실 측, 일부 독립적** 관계를 적용한다.

| 인물 | 황실과의 관계 | 경계선 |
| --- | --- | --- |
| 카이런 레스타 | 황제의 군사적 요청에 직접 협력하는 **황실 측 전력** | 북부대공의 북부군 지휘권을 대신 행사할 수 없음 |
| 세리나 벨프 | **황실 직속이 아닌 독립적 초월자**; 제국의 구성원 | 황제의 모든 요청을 무조건 수행할 의무·사건을 자동 설정하지 않음 |
| 하르벤 로스텔 | 황제의 통치를 존중하되 사안별로 제국의 이익을 판단 | 황제의 무조건적 충신·영구 반대파 어느 쪽도 아님 |

- 중앙의 3명이 한몸처럼 북부대공을 공격하거나, 반대로 모두 황제를 거역하는 사건은 확정되지 않았다.
- 황제에게 경지가 없더라도 유능한 통치권자라는 D-012가 유지된다. **초월자 소속은 황제의 북부 편입 조약 일방 개정권을 증감시키지 않는다**(D-011).
- 세리나의 연애 후보 지위는 황실 복종을 뜻하지 않는다. 실제 관계 전개는 \`11_히로인_연애.md\`에 따른다.

## 3. 보류

각 초월자의 나머지 외형·과거·세부 기술·전투력 수치, 실제 협력·결투·전쟁 사건. 초월자 간 고정 1~8위 순위는 두지 않는다.
