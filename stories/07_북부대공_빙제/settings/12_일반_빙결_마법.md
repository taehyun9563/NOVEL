## 1. 이름이 붙은 일반 마법 12종 [확정 · D-020]

| 분류 | 이름 | 기본 효과·용도 |
| --- | --- | --- |
| 근접 | **서리검** | 빙결 마법으로 검 형상을 생성하여 사용. 검술가 직업·별도 검술 경지를 얻는 것은 아님 |
| 원거리 | **빙창** | 얼음 창을 생성해 목표 방향으로 투사 |
| 원거리 | **설편우** | 다수 얼음 파편을 광범위하게 흩뿌림 |
| 정밀 공격 | **빙정격** | 얼음 결정을 한 목표 또는 좁은 영역에 집중시켜 공격 |
| 구속 | **동결쇄** | 얼음 사슬·결빙으로 상대 움직임 제약 |
| 범위 제어 | **설빙지대** | 지면을 얼려 이동·진형을 방해 |
| 방어 | **설벽** | 공간을 나누거나 접근을 차단하는 얼음 장벽 생성 |
| 방어 | **빙정방패** | 개인 주변 또는 특정 방향의 국소 방어막 형성 |
| 교란 | **빙경** | 얼음 반사면을 만들어 시야·거리 판단을 교란 |
| 이동 | **빙하보** | 발판과 미끄럼·도약용 얼음 경로를 형성해 이동 |
| 지형 | **빙정계단** | 얼음 계단·기둥 등의 구조물을 만들어 높이 확보 |
| 천후 | **설풍** | 눈과 차가운 바람을 조종해 압박·시야 변화·환경 제어 |

- 이 12개는 **이름 붙은 대표적 일반 마법의 완결된 목록**이며, 사용 가능한 일반 빙결 마법 자체를 12개로 한정하지 않는다.
- 일반 마법에 별도 반동·횟수·사용 시간·장문 정식 영창 의무를 추가하지 않는다(D-001·D-003).
- 설풍은 일반 천후 지배 범위의 명명 기술 중 하나일 뿐, D-001의 더 폭넓은 천후 지배 능력을 소거하거나 제한하지 않는다.
- 빙하보는 이동 경로, 빙정계단은 지형·높이 확보에 중점을 둔다. 설벽은 구역 차단, 빙정방패는 국소적 보호에 중점을 둔다.

## 2. 일반 빙룡과 최고위 마법 Ⅰ 구분 [확정 · D-020]

- D-001에 따라 **일반 빙결 마법으로 빙룡 형상을 생성·조종하는 능력**은 유지한다.
- D-002의 최고위 Ⅰ **「보레아스 니베 드라시엘」**은 **초거대 빙룡 조각상과 정식 전투 효과(초거대 형상·지속 전투·냉기 브레스·육탄 공격의 완성된 결합)**를 구현하는 특정 최고위 마법이다.
- 최고위 Ⅰ을 **다른 이름의 일반 빙룡**으로 대체하거나 영창 없이 동일한 완성 효과를 구현할 수 없다(D-003).
- 일반 빙룡에 **'반드시 소~중형' 같은 신규 절대 크기 제한은 추가하지 않는다.** 구별 기준은 해당 최고위 마법의 고유 완성 효과·발동 방식이다.
- 이미 정해진 최고위 Ⅱ·Ⅲ 역시 일반 마법 조합이나 기술명 변경만으로 정식 영창 의무를 우회하지 않는다.
- D-003: 세 최고위 마법은 **사용할 때마다 정식 영창 전체를 순서대로 끝내야 발동**. 영창 중 자동 무적·발동 보장은 없다.

## 3. 보류

추가 일반 마법의 작중 자연스러운 운용, 정량 위력·크기·속도·마나 소모량, 특정 상대에 대한 자동 승패. 강제적인 검술 경지·신체 얼음화·해방 형태는 도입하지 않는다.
