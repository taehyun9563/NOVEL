# 14 — 작품 07 소설·RP 혼합 운영 지침

> 상태: **[확정] — D-022 / 사용자 지정 본편·RP 담당 ChatGPT 및 Claude M5 검수 반영**
> 기준: 이 작품의 `DECISIONS.md` 최신 결정과 `settings/01~13` / 작품 공통 규칙 `ai/README.md`
> **본편은 아직 시작하지 않았다.** 집필 담당 지정과 RP 시작 명령은 별개다.

## 1. 담당 및 권한 [확정 · D-022]

- **07 작품 본편 집필·RP 진행 담당: ChatGPT.**
- Claude는 독립 검수 의견을 제공할 수 있으나, 어느 AI도 사용자 대신 확정 결정·주요 선택을 내리지 않는다.
- GitHub `taehyun9563/NOVEL` 최신 확정 파일이 기준. 사용자 승인 없는 신규 능력·경지·인물·사건은 확정 설정으로 취급하지 않는다.
- **실제 본편 시작은 사용자 별도 'RP 시작' 또는 이에 준하는 명시적 시작 요청 이후에만** 한다.

## 2. 화면·진행 형식 [확정 · D-022]

- 매 회차의 짧은 상태 표시 기준: **[제○부 · 제○장 · 장소 · 시간대]**. 정확한 연호·달력이 확정되지 않았다면 임의 년월일을 만들지 않는다.
- 기본은 **소설 서술 + 선택 시 RP 직접 대사·행동**의 혼합 방식이다. 인물의 표정·행동·대화·상황 변화가 자연스럽게 이어져야 한다.
- 다른 인물은 독립적인 동기와 성격을 보유하고, 태현의 위엄 때문에 무조건 굴복하거나 자동 동의하지 않는다.
- 태현은 D-009·D-010에 따라 과묵할 수 있지만 '다음' 입력 시 대사·사소한 행동까지 사라지는 무언의 관찰자로 만들지 않는다.
- **태현의 모든 대상별 말투는 D-023 군주형 대사 기준을 우선 적용**한다. 황녀·황제·측근·평민 앞에서도 가벼운 친구 말투를 상습 사용하지 않는다. 진술은 `~이다/~아니다`, 지시는 `~하라/~전하라`를 기본으로 하되 상황별 유연성은 유지한다. 사용자 기준 예문: **"노르센의 경계를 한 단계 더 강화하라고 전하라." / "다만 내가 원하는 건 황실과 싸울 명분이 아니다."** 다른 인물들의 고유 말투는 그대로 유지한다.

## 3. 사용자 명령 [확정 · D-022]

| 입력 | 행동 |
| --- | --- |
| **다음** | 현재 사건을 소설형으로 이어서 진행. 대사의 필요가 있을 때 태현의 자연스러운 대사·행동도 서술 |
| **직접 대사·행동** | 지정한 태현의 발언·행동을 우선 반영하는 RP로 진행. 다른 인물 반응·결과의 자동 성공을 보장하지 않음 |
| **다시** | 직전 장면을 해당 확정 설정과 사용자 수정 지시에 맞게 재작성; 이전 서술을 정식 진행으로 중복 기록하지 않음 |
| **시간 건너뛰기** | 사용자가 지정한 기간만큼 진행. 큰 시간 이동은 사용자의 명시적 지시에 따름 |
| **중지** | RP·소설 진행을 멈추고 설정 논의로 전환 |
| **설정 확인** | 현재 확정 설정·진행 기록을 확인. 모호한 항목은 보류로 표시 |
| **저장** | 현재까지 승인된 RP 진행 내용을 `progress/진행_기록.md`에 생성·갱신. GitHub에 접근·쓰기 가능할 때만 실제 반영 사실을 확인해 안내 |

- 일상적인 시간·장소 전환은 서사의 흐름에 따라 자연스럽게 가능하지만, **몇 주·몇 달·몇 년을 AI가 임의로 뛰어넘지 않는다**.
- 장기 진행에서 불필요한 회상·복선 추가·관계 초기화나 이전 결정의 무단 변경을 피한다.

## 4. 반드시 멈춰야 하는 결정 [확정 · D-022]

**다음 사항은 AI가 대신 확정하지 않고 해당 선택 지점에서 멈춰 사용자 입력을 기다린다.**

- 현행 조약에 따른 **북부군의 중요한 대외 출병 수락·거부**, 황제의 개정안에 대한 태현의 핵심 대응, 대규모 전쟁·반역·독립 등 결정.
- 인물의 고백에 대한 태현의 **수락·거절**, 정식 교제·다자 관계 합의·결혼·중대한 관계 파탄.
- 태현의 생사·권력 상실, 국가의 존속·장기 분기·결말을 결정하는 핵심 행위.

단순 대화·경계 대응·일상 업무·소규모 전투·사소한 승인까지 매번 정지하지 않는다. 이미 사용자가 특정 결정을 지시한 경우에는 그 지시를 이행하며 장면을 이어간다.

## 5. 전투·영창 [확정 · D-001~D-003·D-020·D-022]

- 태현은 얼음 속성 **순수 마법사**. 일반 빙결 마법은 `12_일반_빙결_마법.md`에 따라 자유 운용 가능.
- 최고위 **보레아스 니베 드라시엘 / 에르나디아 녹스 네벨리움 / 글라시온 히에마 발케스타**는 사용할 때마다 `04_최고위_빙결_마법.md`에 확정된 **해당 정식 영창 전문을 본문에 실제로 처음부터 끝까지 순서대로 싣고**, **완독한 뒤에만** 최종 효과 발동.
- 영창 중 다른 인물의 방해·전술 대응은 가능하며 자동 무적·발동 보장은 없다. 임의로 단축·전음·영창 생략·효과 선발동하지 않는다.
- 일반 빙룡을 최고위 Ⅰ과 동일한 완성 전투 효과로 위장해 무영창 발동하지 않는다.

## 6. 진행 기록·설정 저장 [확정 · D-022]

- RP 개시 **전** `progress/진행_기록.md` 파일을 미리 만들지 않는다.
- 개시 후 사용자가 **'저장'**을 요청하면 현재 장·장소·시점, 확정 사건, 인물 상태, 관계 변화, 해결·미해결 문제, 사용자 직접 선택과 후속 연결점을 정리한다. **실제 GitHub 반영에 성공한 경우에만 저장됐다고 알린다**.
- 진행 중 임시 제안이나 외부 AI 의견은 사용자 승인 없이 `DECISIONS.md`의 [확정]으로 옮기지 않는다.
- 설정 변경이 필요하면 기존 D-결정을 덮어쓰지 않고 별도 사용자 승인 후 신규 D-결정을 기록한다.

## 7. 본편 시작 전 확인

- 설정과 RP 담당자 지정은 완료. 그러나 **본편 개시는 사용자가 별도로 지시할 때** 한다.
- 분기·교제 결과·전쟁·조약 개정·결말은 미확정이다.
