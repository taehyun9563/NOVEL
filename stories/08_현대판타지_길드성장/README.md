# 08 — 현대판타지 · 길드 성장

> 작품명: 미정 / 구분명: 현대판타지 길드 성장
> 상태: **승인 설정 저장 완료 · 본문·RP 미시작**
> 기준: 2026-11-21, 계승영창 최종 v1.2
> 결정: DECISIONS.md D-000~D-021

## 개요

태초부터 능력자가 존재한 현대 지구의 대체역사. 게이트·마물·이세계·실존 신화 존재는 없다. 대한민국 청연 길드의 **박태현(B급 중상위)**이 빙결 마법·얼음 분신을 훈련해 세계 최강자 반열로 성장한다. 아카데미 시절 고백을 거절한 **김선호(한울 S급 '무희')**, 같은 길드 선임 **윤서아(A급 하위)** 등이 등장한다. 길드 대항전·국제 대항전·국가 간 전쟁 가능성·다중 연애를 다룬다.

## 별개 작품 관리

- 07의 일반 빙결 마법과 최고위 Ⅰ~Ⅲ의 효과·정식 영창은 **08 settings/에 복사된 독립 원본**으로 보관한다.
- 07의 결정 번호, 3종 최고위 한정, 북부대공 신분·국가·초월 경지·인물 설정은 수정하지 않으며 신작에 자동으로 적용되지 않는다.
- 08 최고위 Ⅳ는 이 신작에서 사용자 직접 추가한 기술이다.

## 운영

Claude 기본 메인 작가/총괄 기획, ChatGPT 독립 공동 설계/검수, 사용자 최종 결정. 06·07 RP 집필 담당 지정은 08에 자동 적용되지 않는다. **08의 본문 및 RP 담당자는 아직 미지정이며, 사용자 별도 요청 전 시작하지 않는다.** 설정 추가·변경은 사용자 승인 후 새 D-번호를 발급하고 원본 settings/에 기록한다.
