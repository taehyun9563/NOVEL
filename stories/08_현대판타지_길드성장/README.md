# 08 — 현대판타지 · 길드 성장 / 전쟁 용병의 귀환

> 작품명: 미정 / 구분명: 현대판타지 길드 성장
> 상태: **승인 설정 저장 완료 · 본문·RP 미시작**
> 기준: 2026-11-22, 전쟁 용병 귀환 개편 v2.1·계승영창 v1.2 유지
> 결정: DECISIONS.md D-000~D-035

## 개요

태초부터 능력자가 존재한 현대 지구의 대체역사. 게이트·마물·이세계·실존 신화 존재는 없다. **박태현은 23세 B급 아카데미 졸업 후 청연에 가입하지 않고**, 여러 국가의 전쟁·분쟁 지역에서 **3년간 무소속 전쟁 용병**으로 활동해 **26세 실제 S급 최상위**가 되어 한국으로 귀환한다. 해외 전장에서는 **백야·백은의 군주·빙제·겨울의 황제·하얀 사신·영겁의 지배자**로 불렸고, 국내 길드의 대항전 중심 문화와 태현의 실전·살상전 가치관이 충돌한다. **김선호(한울 S급 '무희')**, **윤서아(청연 A급 하위)** 등과의 관계, 국내·국제 대항전 참여, 전쟁·연애 결과는 RP에서 결정한다.

## 별개 작품 관리

- 07의 일반 빙결 마법과 최고위 Ⅰ~Ⅲ의 효과·정식 영창은 **08 settings/에 복사된 독립 원본**으로 보관한다.
- 07의 결정 번호, 3종 최고위 한정, 북부대공 신분·국가·초월 경지·인물 설정은 수정하지 않으며 신작에 자동으로 적용되지 않는다.
- 08 최고위 Ⅳ는 이 신작에서 사용자 직접 추가한 기술이다.
