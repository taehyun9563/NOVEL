# 01 — 콘셉트 및 운영

> 상태: [확정] D-000·D-001·D-015·D-028·D-031·D-033·D-035

## 기본 콘셉트

- 능력자가 인류 역사 초기부터 존재해 현대 문명과 국가 체계가 형성된 **대체역사 지구**. 게이트·마물·이세계·차원문·실존 신화 존재는 없음.
- 장르: 현대 능력자 판타지, 전쟁 용병의 귀환, 최상위 먼치킨, 길드 경쟁, 국내·국제 대항전, 전쟁 가능성, 복수 연애·하렘.
- 주인공 **박태현**은 23세에 실제 **B급**으로 아카데미를 졸업한 뒤 청연 길드에 가입하지 않고 **3년간 여러 국가의 전쟁·분쟁 지역을 이동하는 무소속 용병**으로 활동했다. 26세 한국 귀환 시점의 실제 전력은 **S급 최상위**이며, 한국의 마지막 공식 등급 기록은 졸업 당시 B급이다(D-031). 숨은 봉인·혈통·신규 각성 없이 실전·수련·기존 마력회로 확장으로 성장했다.
- 아카데미 동기였던 태현과 **김선호**: 태현은 고백했고 당시 연애 감정이 없던 선호가 거절했다. 현재 선호는 한울의 S급 최상위 '무희'.
- 태현에게는 해외 전장마다 붙은 **여섯 이명**이 있으며, 일부 관련자만 그것들이 동일 인물을 가리킴을 안다(D-032). 국내 대항전과 실제 전쟁의 전투력·경험·전투관 차이는 사용자 개편안 C안을 따른다(D-035).
- 07 《북부대공 빙제》의 확정 빙결 기술을 **08에 사본으로 보관**. 07의 신분·정치·국가·경지·인물관계는 자동 복사하지 않는다.
- 사용자 승인된 다중 교제·하렘은 가능성이며 실제 관계·참전·전쟁·승패·결말은 RP에서 결정한다.

## 운영

- DECISIONS.md: 각 D-번호의 결정 요약·실제 최초 제안자·상태·설정 본문 위치만 기록.
- settings/: 각 상세 설정의 유일한 원본. [확정]과 [미정]/[보류] 엄격히 구분. 무소속 용병·여섯 이명·전투관의 상세는 `settings/12_용병_귀환_전투관.md`에 기록.
- Claude 기본 메인 작가·총괄 기획, ChatGPT 독립 공동 설계·검수, 사용자 최종 결정. **작품 08 본문 집필·RP 진행 담당은 사용자 지정 ChatGPT**(D-028). Claude의 독립 검수와 사용자 최종 결정권을 유지한다. 06/07의 별도 담당 지정은 08에 자동 적용하지 않는다.
- **08의 본문·RP 담당은 ChatGPT로 확정. 본편 시작 시점은 미정이며 사용자의 별도 `RP 시작` 요청 전 본문·RP 시작 금지.** 운영 세칙은 `settings/11_RP_운영.md`에 따른다.
