# 03 — 국가·길드·평시 업무·대항전

> 상태: [확정] D-003·D-004·D-005

## 국가별 운용 방향

| 국가/지역 | 방향 |
| --- | --- |
| 대한민국 | 민간 5대 길드와 국가 방위 협력 |
| 미국 | 군 중심 대규모 능력자 전력 |
| 중국 | 국가 주도 능력자 양성 |
| 일본 | 민간 길드·국가 부대 병행 |
| 유럽 주요 국가 | 개별 국가의 독립 운용 방식 |

## 대한민국 5대 길드

| 길드 | 주특기 | 확정 소속 인물 |
| --- | --- | --- |
| **청연** | 소수 정예·개인전·정밀 제어·정보전 | 박태현·윤서아 |
| **한울** | 종합 전투·국제 교류 | 김선호 |
| 백산 | 근접전·기동전 | 미정 |
| 철림 | 방어·거점전·조직전 | 미정 |
| 유성 | 광역 화력·원거리 제압 | 미정 |

청연·한울은 대항전 경쟁 상대지만 국가 위기에는 협력 가능. 그 밖의 일반 길드도 존재하지만 조직/주요 인물은 미정.

## 길드 평시 업무

- 능력자 범죄 대응(국가기관과 협력)
- 요인·시설 경호
- 국가 위탁 특수 임무
- 능력자·위험 조직 관련 정보 수집(청연 강점)
- 합법적 해외 의뢰·경호·국제 교류
- 길드 훈련 및 대항전 참가

게이트나 마물을 상대하는 임무는 없음.

## 전시 동원

민간 길드원은 **계약 또는 자발적 참여 중심**. 태현과 선호의 자동 참전, 국가의 자동 전쟁 참여는 확정하지 않는다.

## 대회

| 종목 | 형식 |
| --- | --- |
| 개인전 | 1대1 |
| 팀전 | 5대5 |
| 거점전 | 거점 점령·방어 |

3부는 **국내 길드 대항전**, 4부는 **국제 대항전**. 개최지·선발 절차·규칙·경기 결과는 미정.
