# 04 — 일반 빙결 마법 12종

> 상태: [확정] D-007·D-023 / 작품 07의 12종 효과를 작품 08로 독립 복사

| 분류 | 이름 | 기본 효과·용도 |
| --- | --- | --- |
| 근접 | **서리검** | 빙결 마법으로 검 형상을 생성하여 사용. 검술가 직업·별도 검술 경지를 얻는 것은 아님 |
| 원거리 | **빙창** | 얼음 창을 생성해 목표 방향으로 투사 |
| 원거리 | **설편우** | 다수 얼음 파편을 광범위하게 흩뿌림 |
| 정밀 공격 | **빙정격** | 얼음 결정을 한 목표 또는 좁은 영역에 집중시켜 공격 |
| 구속 | **동결쇄** | 얼음 사슬·결빙으로 상대 움직임 제약 |
| 범위 제어 | **설빙지대** | 지면을 얼려 이동·진형을 방해 |
| 방어 | **설벽** | 공간을 나누거나 접근을 차단하는 얼음 장벽 생성 |
| 방어 | **빙정방패** | 개인 주변 또는 특정 방향의 국소 방어막 형성 |
| 교란 | **빙경** | 얼음 반사면을 만들어 시야·거리 판단을 교란 |
| 이동 | **빙하보** | 발판과 미끄럼·도약용 얼음 경로를 형성해 이동 |
| 지형 | **빙정계단** | 얼음 계단·기둥 등의 구조물을 만들어 높이 확보 |
| 천후 | **설풍** | 눈과 차가운 바람을 조종해 압박·시야 변화·환경 제어 |

- 이 12개는 이름 있는 대표 일반 기술이다. 기타 빙결 응용·빙룡 생성·천후 지배·광역 빙결 능력도 그대로 존재한다.
- **일반 빙룡·천후 지배·광역 빙결은 B급부터 사용 가능**하다. 아카데미 시절 B급일 때는 실제 B급 출력·숙련에 맞게 구현되었고, 해외 용병 생활을 통해 S급 최상위가 된 현재는 성장한 출력·제어·숙련에 따라 규모·위력이 확대된다(D-023·D-031).
- 일반 빙룡에 소~중형 고정 상한을 신설하지 않는다.
- 일반 기술의 명칭 변경이나 조합만으로 최고위 Ⅰ~Ⅳ의 정식 영창 조건을 우회할 수 없다.
- 일반 기술에는 최고위 마법의 장문 영창 전문·봉인·횟수 제한을 적용하지 않는다.
- 서리검 사용은 빙결 마법 운용이다. 08 태현은 기본 검술 훈련을 하지만 별도 검술 경지·검사 계급은 얻지 않는다.
- 신체 얼음화·별도 해방 형태를 추가하지 않는다.
