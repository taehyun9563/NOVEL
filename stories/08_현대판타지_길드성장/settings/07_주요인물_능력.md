# 07 — 주요 인물·능력·전투 기술

> 상태: [확정] D-006·D-012·D-013·D-017 / 관계 진전은 [RP 결정]

## 박태현

| 구분 | 설정 |
| --- | --- |
| 성별 | 남성 |
| 현재 길드 | **청연** |
| 시작 등급 | **B급 중상위**, 실제 B급 |
| 고유 능력 | 얼음·빙결 마법 |
| 분신 | B급 시작부터 보유, 일반 마법 각개전투 |
| 성장 | A급 중위에서 최고위 4종, 최종 세계 최강자 반열 |
| 이명 | 시작 시 없음, 최종 이명 미정 |
| 검 사용 | **기본 검술 훈련만 수행**하며 빙결 마법 주력, 별도 검사 경지나 검술 능력 등급은 만들지 않음 |
| 과거 | 김선호와 아카데미 동기, 태현이 고백했지만 거절당함 |

과묵·독립적 태도는 추천 방향이지만 구체 대사 규칙과 현재 정확한 나이는 [미정].

## 김선호 — 무희

| 구분 | 설정 |
| --- | --- |
| 성별 | 여성 |
| 길드 | **한울** |
| 등급 | **S급 최상위** |
| 이명 | **무희** |
| 무기 | 레이피어 |
| 고유 능력 | **초가속** |
| 전투 | 순간 가속·반응 강화·방향 전환·균형·연속 기동·정밀 찌르기 |

초가속은 단일 고유 능력을 극한까지 단련한 결과다. 별도의 순간이동·미래 예지·시간 정지는 없다. 선호는 독립적인 최상위 강자이지 태현을 돋보이게 하기 위해 수동적으로 약해지는 인물이 아니다.

### 선호 기술 6종 [확정]

| 이름 | 효과 |
| --- | --- |
| **유영보** | 부드러운 발놀림·초고속 접근 |
| **회선** | 공격선을 벗어난 측면 이동과 반격 |
| **연무삼침** | 서로 다른 급소를 향한 초고속 3연속 찌르기 |
| **수월반격** | 공격을 레이피어로 흘린 뒤 즉각 반격 |
| **원무** | 여러 각도에서 연속 고속 기동과 공격 |
| **종막·일점관통** | 초가속과 신체 제어를 단일 정밀 찌르기에 집중. 절대 관통·무조건 명중 아님 |

아카데미 재학 시절 선호는 태현을 연애 대상으로 보지 않아 고백을 거절했다. 이후 마음과 교제·관계는 미정.

## 윤서아

| 구분 | 설정 |
| --- | --- |
| 성별/나이 | 여성 / **27세** |
| 길드 | **청연** |
| 등급 | **A급 하위** |
| 역할 | 청연 작전팀 선임 |
| 능력 | **빛의 굴절** |
| 이명 | 없음 |
| 성격 | 침착·현실적·독립적·책임감, 업무에서는 직설적 |
| 전투 | 광학 은폐·시야 교란·위치 기만·정찰 지원 |
| 연애 | 주요 히로인 후보, 실제 관계 미정 |

광학 은폐는 시각 정보에 작용하며 완전한 전감각 은폐·진짜 실체 분신과 구별한다. 태현의 얼음 분신과 기만 협동 전투가 가능. 선호의 과거 인연과 달리 현재 청연 동료에서 출발하며, 실제 고백과 연애는 RP에서 결정.

## 미정

태현·선호 현재 나이, 아카데미 졸업 후 경과 연수, 청연·한울 길드장 및 팀원, 선호 현재 호감 여부, 윤서아의 연애 선택.
