# 07 — 주요 인물·능력·전투 기술

> 상태: [확정] D-006·D-012·D-013·D-017·D-018 / 관계 진전은 [RP 결정]

## 박태현

| 구분 | 설정 |
| --- | --- |
| 성별 | 남성 |
| 현재 길드 | **청연** |
| 시작 등급 | **B급 중상위**, 실제 B급 |
| 고유 능력 | 얼음·빙결 마법 |
| 분신 | B급 시작부터 보유, 일반 마법 각개전투 |
| 성장 | A급 중위에서 최고위 4종, 최종 세계 최강자 반열 |
| 이명 | 시작 시 없음, 최종 이명 미정 |
| 검 사용 | **기본 검술 훈련만 수행**하며 빙결 마법 주력, 별도 검사 경지나 검술 능력 등급은 만들지 않음 |
| 과거 | 김선호와 아카데미 동기, 태현이 고백했지만 거절당함 |

과묵·독립적 태도는 추천 방향이지만 구체 대사 규칙과 현재 정확한 나이는 [미정].

## 김선호 — 무희

| 구분 | 설정 |
| --- | --- |
| 성별 | 여성 |
| 길드 | **한울** |
| 등급 | **S급 최상위** |
| 이명 | **무희** |
| 무기 | 레이피어 |
| 고유 능력 | **초가속** |
| 전투 | 순간 가속·반응 강화·방향 전환·균형·연속 기동·정밀 찌르기 |

초가속은 단일 고유 능력을 극한까지 단련한 결과다. 별도의 순간이동·미래 예지·시간 정지는 없다. 선호는 독립적인 최상위 강자이지 태현을 돋보이게 하기 위해 수동적으로 약해지는 인물이 아니다.

### 선호 기술 6종 [확정]

| 이름 | 효과 |
| --- | --- |
| **유영보** | 부드러운 발놀림·초고속 접근 |
| **회선** | 공격선을 벗어난 측면 이동과 반격 |
| **연무삼침** | 서로 다른 급소를 향한 초고속 3연속 찌르기 |
| **수월반격** | 공격을 레이피어로 흘린 뒤 즉각 반격 |
| **원무** | 여러 각도에서 연속 고속 기동과 공격 |
| **종막·일점관통** | 초가속과 신체 제어를 단일 정밀 찌르기에 집중. 절대 관통·무조건 명중 아님 |

아카데미 재학 시절 선호는 태현을 연애 대상으로 보지 않아 고백을 거절했다. 이후 마음과 교제·관계는 미정.

## 윤서아

| 구분 | 설정 |
| --- | --- |
| 성별/나이 | 여성 / **27세** |
| 길드 | **청연** |
| 등급 | **A급 하위** |
| 역할 | 청연 작전팀 선임 |
| 능력 | **빛의 굴절** |
| 이명 | 없음 |
| 성격 | 침착·현실적·독립적·책임감, 업무에서는 직설적 |
| 전투 | 광학 은폐·시야 교란·위치 기만·정찰 지원 |
| 연애 | 주요 히로인 후보, 실제 관계 미정 |

광학 은폐는 시각 정보에 작용하며 완전한 전감각 은폐·진짜 실체 분신과 구별한다. 태현의 얼음 분신과 기만 협동 전투가 가능. 선호의 과거 인연과 달리 현재 청연 동료에서 출발하며, 실제 고백과 연애는 RP에서 결정.

## 청연·한울 주요 인물 추가 [확정 · D-018]

### 차도윤 — 철권 / 청연 길드장

| 항목 | 설정 |
| --- | --- |
| 성별 | 남성 |
| 소속·직책 | **청연 길드장** |
| 등급 | **S급 최상위** |
| 이명 | **철권** |
| 능력 | **신체·주먹 강화** |
| 위상 | 기존 세계 최상위 10인 중 한 명 |

- 기존 D-014의 차도윤이며, 이명·능력·세계 강자 위상은 그대로 유지한다.
- 청연의 소수 정예 실력을 대표하는 최상위 전력이다. **성격·지휘 철학·나이·태현과의 개인적 관계는 미정**이며 강무진의 과묵·냉정한 인물상을 차도윤에게 자동 승계하지 않는다.

### 이도겸 — 청연 정예 전투원

| 항목 | 설정 |
| --- | --- |
| 성별·나이 | 남성 · **30세** |
| 등급 | **A급 중위** |
| 능력 | **충격파** |
| 전투 역할 | 신체 움직임에 맞춰 근중거리 충격파를 내보내 돌파·공격·제압 |
| 성격 | 직설적·승부욕 강함·동료 의식 |

태현의 정밀한 분신 전술을 인정하지만 보다 직접적인 돌파를 선호한다. 훈련과 임무에서 경쟁·협력하는 선배 동료다. 태현에게 이유 없는 적개심이나 열등감을 강제하지 않는다.

### 정도하 — 한울 길드장

| 항목 | 설정 |
| --- | --- |
| 성별·나이 | 남성 · **45세** |
| 등급 | **A급 상위** |
| 능력 | **충격 흡수·방출** |
| 전투 역할 | 물리 충격을 받아들여 방어·반격·근접 제압에 활용 |
| 성격 | 대범·사교적·결단력 있음 |
| 역할 | 조직 운영·인재 육성·국제 교류 |

모든 공격을 자동으로 무효화하는 절대방어는 아니다. 선호가 자신보다 전투력이 높은 S급이라는 점을 인정하고 실전 판단권을 존중한다. 길드장 권한으로 선호의 사생활이나 연애를 통제하지 않는다.

### 류건우 — 한울 정예 전투원

| 항목 | 설정 |
| --- | --- |
| 성별·나이 | 남성 · **29세** |
| 등급 | **A급 중위** |
| 능력 | **수류 조작** |
| 전투 역할 | 물의 흐름을 조작한 원거리 공격·진형 제어·지원 |
| 성격 | 침착·친화적·분석적 |

선호의 초고속 돌파를 원거리에서 지원하는 동료이며, 두 사람의 관계는 전투적 신뢰를 중심으로 한다. **별도 연애 관계는 설정하지 않는다.**

### 채택하지 않은 기존 후보

- **강무진 [폐기]**: 최초 제안된 A급 상위 청연 길드장 후보. 사용자가 **차도윤을 청연 길드장으로 직접 지정**했으므로 채택하지 않는다.
- 새로운 전투 기술명·S급 인물·고유 경지 등은 이번 승인으로 추가하지 않는다.

## 미정

태현·선호 현재 나이, 아카데미 졸업 후 경과 연수, 청연·한울의 잔여 팀원, 선호 현재 호감 여부, 윤서아의 연애 선택.
