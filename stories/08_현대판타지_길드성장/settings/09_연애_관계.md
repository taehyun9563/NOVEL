# 09 — 연애·다중 교제·하렘

> 상태: [확정] D-015 / 실제 교제 여부는 [RP 결정]

## 기본 원칙

- 한 명의 히로인으로 고정하는 순애 노선이 아니다. **단독 교제, 복수 인물과의 동시 교제, 실제 하렘 성립**이 모두 가능하다.
- 인물들의 감정·거절·질투·독립적 판단·동의는 유지한다. 모두가 자동으로 태현을 사랑하거나 다중 교제에 동의하는 식으로 진행하지 않는다.
- 실제 고백·교제·이별·결혼 및 결말은 사용자의 RP 결정에 따라 달라진다.
- 후보는 선택 가능성일 뿐 이미 연인이거나 호감이 있다는 뜻은 아니다.

## 주요 후보

| 인물 | 초기 관계 |
| --- | --- |
| **김선호** | 과거 아카데미 동기. 태현의 고백을 당시 연애 감정이 없어 거절. 현재 한울 S급 |
| **윤서아** | 현재 청연의 작전팀 선임. 임무·훈련·일상을 통해 신뢰 형성 가능 |
| 카타리나 베르너 | 독일 S급 강자, 국제적 교류 가능 |
| 미나세 렌 | 일본 검성, 국제 대항전에서 교류 가능 |
| 올리비아 리드 | 영국 공명 강자, 국제 교류 가능 |
| 마리아나 코스타 | 브라질 폭풍 강자, 국제 대항전에서 교류 가능 |

## 관계 구별

선호는 **과거 고백과 거절을 가진 타 길드 인연**, 서아는 **현재 함께 일하는 동료**다. 다른 국제 히로인 후보는 실제 만남의 개연성을 서사에서 쌓아야 한다. 선호가 태현의 다른 연애에 어떻게 반응할지, 서아가 다중 관계를 받아들일지는 아직 미정이다.
