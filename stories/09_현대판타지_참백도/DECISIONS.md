### D-002 [확정]

### D-008 [확정]
- 결정 요약: 태현의 참백도는 원작 경화수월(鏡花水月); 시해는 원작의 완전최면, 해방 언령은 '부서져라, 경화수월'. 별도 만해를 창작하거나 사용하지 않고 시해 중심으로 진행. 영압·참술·순보·백타·귀도 등은 기존 블리치 체계 안에서 운용한다.
- 최초 제안자: 사용자 (경화수월 확정·만해 미창작), ChatGPT (원작 대응 정리)
- 상태: [확정]
- 본문 파일 위치: settings/03_주인공_경화수월_붕옥.md

### D-009 [확정]
- 결정 요약: 태현의 불사는 원작과 같은 붕옥(崩玉) 융합·진화에서 비롯된다. 붕옥은 우라하라 키스케가 개발했으며, 원작과 다른 신규 불사/진화 계열을 만들지 않는다.
- 최초 제안자: 사용자 (붕옥 지정·우라하라 개발안 승인)

### D-010 [확정]
- 결정 요약: 붕옥 존재를 2부 중반에 알게 되고 2부 후반 경화수월의 완전최면으로 우라하라 키스케를 속여 직접 탈취한다. 루키아의 혼백을 이용한 탈취 방식은 사용하지 않는다. 완전최면은 감각 기만이지 의지 직접 조종이 아니다.
- 최초 제안자: ChatGPT (발견·탈취 시기 구상), 사용자 (키스케 상대 직접 완전최면 탈취 지정·전체 확정)
- 상태: [확정]
- 본문 파일 위치: settings/03_주인공_경화수월_붕옥.md; settings/04_서사_구조.md

### D-011 [확정]
- 결정 요약: 태현은 3부 초반 웨코문드 진출, 3부 중후반 붕옥과 융합하며, 3부 최종 결전 무렵 불사의 성질을 완성한다. 4부에는 태평양 한가운데 감옥의 최심부·최하층에 감금되고 이후 RP를 지속한다. 봉인의 세부 실행 과정은 미정.
- 최초 제안자: 사용자 (웨코문드·불사·태평양 감옥·봉인 후 RP), ChatGPT (부별 시기 제안·사용자 일괄 승인)
- 상태: [확정]
- 본문 파일 위치: settings/03_주인공_경화수월_붕옥.md; settings/04_서사_구조.md

### D-012 [폐기]
- 결정 요약: 설계 중 제시된 태현의 독자 참백도 후보(천무·천령·흑칙·현영안 계열, 물질 상태 변화·영압 파장·허실 전환 등)는 채택하지 않고 경화수월로 대체한다.
- 최초 제안자: ChatGPT (초기 후보 제시), 사용자 (반복 거절·경화수월 선택)
- 상태: [폐기] (현재 작품의 능력 후보로 사용하지 않음)
- 본문 파일 위치: settings/03_주인공_경화수월_붕옥.md

## 남은 미정 및 검수 사항
- 국제 안보 조직 정식 명칭·세부 권한·13명 전체 대장 명단·해당 인물의 나이·생존·수명 문제
- 원작에 만해가 공개되지 않은 인물의 처리(사용자 승인 없는 신규 만해 금지)
- 태현 나이·성격 디테일·관계·히로인·정확한 학교·졸업 시점
- 우라하라에게 경화수월 해방을 목격시키는 과정·붕옥 보관 장소·탈취 장면 세부
- 붕옥 융합 장면·봉인 구체 원리·태평양 감옥의 운영 조직·봉인 이후 전개
- 호로와 아란칼의 관계·역사, 실제 등장인물 구체 구성
- RP 진행·집필 담당 및 상세 운영 지침: 사용자 별도 지정 전 미확정
