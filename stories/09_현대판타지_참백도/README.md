## 작품 개요
소울 소사이어티가 없는 **현대 지구**. 모든 인간은 선천적으로 참백도를 가지며 호로·웨코문드가 존재한다. **호정 13대**는 야마모토가 지휘하는 13개 부대의 독립적인 국제 안보 조직이다. 그 대장과 부대장에는 원작 《블리치》 인물들이 등장한다. 원작의 아이젠 소스케와 퀸시 계열은 이번 세계관에 등장하지 않는다.

**박태현(20)**은 서울의 **국제 참백도 아카데미 1학년**, 이미 시해를 쓸 수 있는 천재다. 참백도 **경화수월(鏡花水月)**의 진짜 능력은 **완전최면**이지만, 사람들에게는 제한적인 환각·착시 계열 능력으로 알려져 있다. 경화수월의 만해를 별도로 만들거나 사용하지 않는다. 태현은 점차 타락해 세계 질서에 도전하고, 2부 후반 **우라하라 키스케**를 완전최면으로 기만하여 **붕옥**을 탈취한다. 3부 웨코문드에서 붕옥과 융합해 원작과 같은 불사의 성질을 얻으며, 4부 태평양 중앙 해저 감옥의 최하층에 봉인된 뒤에도 RP가 계속된다.

히로인은 **김선호(뇌명 → 구천뇌명)**, **한서윤(쌍월 → 쌍월전륜)**, **쿠치키 루키아(수백설 → 백하벌)**의 세 명. **히나모리 모모는 히로인이 아닌 5번대 부대장**이다. 고백·연애·결별·배신 같은 실제 인물 선택은 RP에서만 결정한다.

## 운영 및 상태
- 확정된 세계관과 능력을 임의로 확장하지 않는다. 상세한 장면/성공 과정, NPC 반응, 전투 승패, 연애 결과는 실제 RP에서 결정한다.
- 집필·검수 담당은 NOVEL 저장소 `ai/README.md`의 **기본 역할**을 따르며, 사용자가 작품 09 담당을 별도로 지정하면 변경한다. 작품 06~08의 ChatGPT 집필 담당 예외를 09에 자동 적용하지 않는다.
- **별도의 본편/RP 시작 요청 전에는 본문을 시작하지 않는다.**
- 결정 변경 시 기존 D-번호를 덮어쓰지 않고 신규 D-번호를 발급한다. 예전 퀸시 보류 D-005는 D-013으로 대체되었다.
