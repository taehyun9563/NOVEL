# 09 — 현대 판타지 · 참백도 (가제 미정)

> 상태: **사용자 승인 설정 저장 완료 / 본문·RP 미시작**
> 기준일: 2026-11-23
> 원본: 이 작품의 `settings/` 및 `DECISIONS.md`; 다른 NOVEL 작품과 설정을 공유하지 않음.
> 원작 참조: 《블리치》. 본 작품은 **소울 소사이어티가 없는 현대 지구의 별도 세계선**.

## 핵심 콘셉트
모든 인간이 선천적으로 참백도를 지닌 현대 세계. 호로와 웨코문드가 실재하며, 아카데미는 참백도 사용자에게 호로 대응을 가르친다. 세계 안보를 담당하는 13개 부대 조직(가칭 '호정 13대')은 **야마모토 겐류사이**를 총대장으로 하며 원작 《블리치》 인물들을 사용한다. **퀸시는 현재 설계에서 제외·보류**한다.

주인공 **박태현**은 **경화수월**의 시해를 사용할 수 있는 아카데미 천재 학생으로 시작한다. 점차 타락해 인류의 적이 되고 세계 지배·재창조를 추구한다. 원작의 **아이젠 소스케는 존재하지 않으며**, 아이젠의 서사적 위치를 박태현이 맡지만 태현의 이름·인격·RP 선택권은 별개다. 태현의 **경화수월은 시해 '완전최면'만 사용**하며 독자 만해를 만들지 않는다. **우라하라 키스케가 개발한 붕옥**을 완전최면을 이용해 탈취하고, 3부에서 융합·진화하여 불사의 존재가 된다. 이후 태평양 한가운데 감옥의 가장 깊은 최하층에 봉인되지만 **그 뒤에도 RP를 계속한다**.

## 운영
- 본편·RP 담당 AI는 **아직 지정되지 않음**. 사용자의 별도 시작 지시 전에는 본문을 시작하지 않는다.
- 연애와 전략적 전투를 주요 재미 요소로 삼되, 특정 히로인·연애 결과·배신 실행·구체적 사건과 대사는 아직 정하지 않는다.
- 새로운 참백도 고유 능력, 만해, 퀸시 계통, 이세계·마법·각성 체계를 임의로 추가하지 않는다.
- 설정 변경은 새 D-번호로 관리하며 이전 결정은 보존한다.
