# 03 — 박태현 · 경화수월 · 붕옥 [확정]

관련 결정: D-006~D-012, D-022, D-024~D-026

## 박태현 — 출발 상태
- 이름 **박태현**, **20세**, 대한민국 서울 **국제 참백도 아카데미 1학년**. 김선호·한서윤과 같은 학년·같은 반.
- 입학 때부터 시해를 사용할 수 있는 천재 학생. **아카데미 학생 최상위권 재능**이지만 시작부터 세계 최상위 강자나 대장급은 아니다.
- 초기 성격: **차분하고 과묵함, 뛰어난 판단력, 강한 자존심과 자신감**, 기본 예의를 지키되 불합리한 명령에 쉽게 복종하지 않음. 가까운 사람에게는 인간적인 애정과 배려를 보일 수 있다.
- 점진적 타락의 방향: 자기 판단에 대한 확신이 지나치게 커지고, 타인의 선택보다 자신의 질서·통제를 우선하며 장차 **세계 지배·재창조**를 추구한다. 처음부터 악인의 대사/행동을 강제하지 않는다.
- 《블리치》 원작 **아이젠 소스케는 존재하지 않는다.** 아이젠의 강자·흑막·붕옥 융합이라는 서사적 위치를 태현이 맡지만 **아이젠의 인격·대사·개별 행동을 복제하지 않는다**.

## 초기 전투 역량
| 분야 | 시작 시점 |
| --- | --- |
| 영압 | 아카데미 동급생 최상위권 |
| 참술 | 아카데미 상위권 |
| 순보 | 아카데미 상위권 |
| 백타 | 우수 |
| 귀도 | 뛰어난 재능 |
| 시해 | **경화수월(鏡花水月) 사용 가능** |
| 만해 | 별도 설계·사용 없음 |
| 대장과의 실력 차이 | 아직 상당한 차이가 있음 |

수련과 실전으로 영압·참술·순보·귀도가 성장한다. 경화수월의 시해 성능이 강력하다는 사실을 태현의 대장급 근력·영압과 혼동하지 않는다.

## 경화수월(鏡花水月) — 오직 시해
- 해방 언령: **'부서져라, 경화수월'**. 시해의 고유 능력은 원작의 **완전최면**이다.
- **해방을 실제로 목격한 상대**를 감각의 완전최면 대상으로 삼을 수 있다. 실제로 보지 않은 인물을 '이미 걸렸다'고 처리하지 않는다.
- 현실을 바꾸거나 감정을 직접 주입·의지를 강제 조종하는 능력이 아니다. 원작의 전제·조건·한계를 유지한다.
- **대외 공개 [확정]:** 태현이 시해를 쓴다는 사실과 참백도 이름은 알려져 있으나, 능력은 **일반적인 환각·착시 계열**로 축소·위장되어 있다. **완전최면이라는 진정한 능력과 조건은 비공개**다. 공식 설명과 실제 능력을 구별한다.
- 김선호·한서윤·호정 13대 인물이 시작부터 진짜 능력을 알거나 최면에 걸려 있다고 간주하지 않는다. 누가 해방을 목격하고 어떤 기억·인식을 갖는지 **RP 진행 기록**에 추적한다.
- **경화수월의 만해는 창작하거나 사용하지 않는다.** 기존에 제안했던 독자 참백도 후보(D-012)는 폐기 상태를 유지한다.

## 붕옥(崩玉) — 원작의 성질 유지
- 개발자는 **우라하라 키스케**, 작품 시작 때 태현은 소유하지 않음. 신규 불사·변신·초월 능력 체계는 만들지 않는다.
- **2부 중반** 존재 발견 → **2부 후반** 경화수월 완전최면으로 우라하라를 기만해 **붕옥 직접 탈취**. 루키아 혼백을 매개로 탈취하지 않는다.
- 키스케가 **경화수월 해방을 실제로 목격하는 사건**이 선행해야 한다. 탈취의 세부 동선·대응·우라하라의 판단은 인물 성격과 RP 장면에서 자연스럽게 처리한다. 붕옥의 최종 탈취라는 승인된 큰 사건은 유지한다.
- **3부 중후반** 붕옥과 융합하여 원작의 성질대로 진화 시작 → **3부 최종 결전 무렵** 불사의 성질 완성.
- 처형이 통하지 않게 된 태현은 **태평양 중앙 해저 감옥의 최하층에 봉인**된다. 우라하라의 원작 봉인 귀도를 참고한다. 봉인 그 자체가 결말은 아니다.
- 실제 융합 과정에서의 선택·대사·전투 전술과 주변 인물들의 반응은 RP 진행에서 결정한다.
