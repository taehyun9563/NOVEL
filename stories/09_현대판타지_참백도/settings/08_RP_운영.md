# 08 — 작품 09 RP 운영 규칙 [확정]

관련 결정: D-017~D-027 및 D-006~D-011

## 진행 기본값
- **본편/RP는 아직 시작하지 않았다.** 사용자의 별도 '09 RP 시작' 등 명시적 시작 지시가 있어야 첫 장면 집필.
- 작품별 집필 담당은 사용자의 추가 지정이 없는 한 `ai/README.md`의 **기본 역할 분담(Claude 집필/총괄, ChatGPT 검수/공동 설계)**을 적용한다. 작품 06~08에 대한 별도 지정은 09로 이어지지 않는다.
- 작품 09의 RP는 소설+사용자 직접 행동/대사 혼합 방식이다. 사용자가 **'다음'**이라고 하면 장면을 자연스럽게 이어가고, 사용자가 구체 행동이나 대사를 적으면 **태현의 행동으로 우선 반영**한다.
- AI는 태현의 결정적인 도덕적 판단, 주요 배신, 고백·교제·결별·결혼, 세계 지배 관련 결단을 **대신 확정하지 않는다**. 묘사는 자연스럽게 진행하되 해당 분기에서 사용자의 행동을 우선한다.
- 각 NPC는 자신의 성격·정보·관계에 따라 독립적으로 행동한다. 선호·서윤·루키아가 자동으로 사랑에 빠지거나 태현의 타락을 자동으로 용납/거부하지 않는다.

## 경화수월 운용 기록
- 태현의 경화수월은 **완전최면**. 대외적으로만 제한적 환각·착시 계열인 듯 알려져 있다.
- **목격자 단위 기록이 필수**: 인물 / 실제 해방 목격 시점 / 그때 목격 여부 / 감각 기만을 경험했는지 / 진짜 능력을 알게 된 시점.
- 이름을 들었거나 효과를 전해 들었다는 이유로 **해방을 목격했다고 처리하지 않는다**. 실제 해방을 목격하지 않은 인물을 자동 최면에 빠뜨리지 않는다.
- 기존 목격 여부가 불명확할 때는 임의로 이미 걸린 상태를 확정하지 않고, 서사에 모순이 없는 명확한 장면을 통해 사실을 정한다.
- 최면은 의지 조종·물리적 현실 변경·사랑의 강제가 아니다. 새 부가 능력을 추가하지 않는다.
- NPC가 태현의 숨겨진 완전최면이나 최종 타락을 미리 알고 있는 척하지 않는다.

## 능력·전투
- 태현의 참백도는 **시해만**. 기본 영압·참술·귀도·순보는 실전으로 성장한다.
- 선호 **뇌명→구천뇌명**, 서윤 **쌍월→쌍월전륜**, 루키아 **수백설→백하벌**은 `settings/07`의 승인 능력과 각성 순서를 지킨다.
- 원작 캐릭터는 원작 성격·참백도·공개된 만해를 활용하고 **원작 미공개 만해의 효과**를 임의로 창작하지 않는다.
- 강자 간 승부를 대장의 직함·만해 보유 여부만으로 자동 결정하지 않으며 전투 상황·기량·상성·영압·전략을 반영.
- 거듭되는 훈련, 일방적 압도·주변 경악·강한 적의 반복 출현을 최소화. 전투 결과가 인물 관계와 세계 질서에 영향을 주게 구성한다.

## 서사·결정 경계
- 1부 아카데미 → 2부 경화수월·붕옥 탈취 → 3부 웨코문드·붕옥 융합과 불사 → 4부 봉인 후 RP라는 **사용자 승인 뼈대 유지**.
- 결정된 각성/탈취/융합/봉인 시기는 훼손하지 않되, 당사자의 선택·구체적인 전투·대화는 실제 RP에서 진행.
- 태현은 **아이젠 소스케라는 이름·인격이 아님**. 원작 아이젠의 대사를 강제 복제하지 않는다.
- 호정 13대는 현대 국가 주권을 존중하는 국제 안보 조직. 호로·아란칼·웨코문드·영혼 순환 외 원작 별개 세력을 불필요하게 만들지 않는다. **퀸시 등장·복선 금지**.
- 이야기를 저장할 때는 설정 `settings/`과 진행 기록 `progress/`를 구분한다. RP 진행 내용을 설정으로 자동 승격하지 않는다.

## 최종 사용자 권한
- 사용자 직접 입력과 승인 설정을 우선한다.
- 중요한 확정 설정을 수정하는 경우 사용자 승인 후 새 D-번호를 발급한다.
- 시작 전 본문을 작성하지 않으며, RP의 모든 세부 미래를 사전 결정하지 않는다.
