# 작품 10 — DECISIONS

> 이 문서에는 결정 요약·최초 제안자·상태·본문 위치만 기록한다. 상세 설정은 `settings/` 파일이 기준이다.

- 결정 요약: 신규 차원전쟁·이세계 귀환 작품을 NOVEL의 **10번 독립 작품**으로 저장한다. 본편·RP는 아직 시작하지 않는다.
- 최초 제안자: 사용자
- 상태: [확정]
- 본문 파일 위치: README.md; settings/03_RP_운영.md

### D-001 [확정]
- 결정 요약: **중앙 차원의 토착 인간은 전원이 초월자**다. 타 차원 인간까지 동일하게 초월자로 취급하지는 않는다.
- 최초 제안자: 사용자
- 상태: [확정]
- 본문 파일 위치: settings/01_중앙차원_세계관.md

### D-002 [확정]
- 결정 요약: 사전 국가·인물 설정은 최소화한다. 국가는 우선 명칭과 특징 정도만 정하고, 해당 국가의 이름 있는 인물이 본편/RP에 실제 등장할 때 필요한 최소 설정을 기록·갱신한다. 공통 운영지침에는 적용하지 않는다.
- 최초 제안자: 사용자
- 상태: [확정]
- 본문 파일 위치: settings/03_RP_운영.md

### D-003 [확정]
- 결정 요약: 박태현의 이명은 **군신(軍神)**, 전투 유형은 검술과 마법을 병용하는 **마검사형**이다.
- 최초 제안자: 사용자 (이명 군신), ChatGPT (마검사 유형 후보)
- 상태: [확정]

### D-004 [확정]

- 최초 제안자: ChatGPT (후보), 사용자 (선택)

- 본문 파일 위치: settings/04_주인공_귀환_히로인.md
