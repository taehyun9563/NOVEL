# 10 — 차원전쟁 · 이세계 귀환 (정식 제목 미정)

> 상태: **초기 세계관 설계 중 · RP 미시작** (2026-11-23)
> 저장소 내 독립 작품. 기존 01~09 작품과 설정을 공유하지 않는다.

## 핵심 콘셉트
지구에서 중앙 차원으로 넘어간 박태현은 신계·마계의 전쟁에 휘말린다. 여러 차원이 참전한 전쟁을 끝내고 중앙 차원의 지배자가 된다. 이후 신계와 마계는 지구를 새로운 차원전쟁의 전장으로 삼고, 여러 게이트에서 타 차원의 종족과 문명이 출현한다. 귀환·전쟁·성인 로맨스를 다루는 작품이다. **현재 줄거리와 세부 메커니즘은 [제안]**.

## 확정된 사항
- 작품 10으로 분리해 보관한다.
- **중앙 차원 토착 인간은 전원이 초월자**다.
- 본문과 RP는 사용자의 별도 시작 지시 전까지 시작하지 않는다.
