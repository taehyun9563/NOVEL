# 02 — 주요 국가·세력 최소 목록

> 모두 **[제안]**. 국가명·특징 외의 왕실·역사·군대·인물은 사전 설계하지 않는다.

## [제안] 중앙 차원 국가
| 명칭 | 중심 종족 | 한 줄 특징 |
| --- | --- | --- |
| 아르데인 제국 | 인간 초월자 | 강한 군사력을 가진 주요 인간 국가 |
| 실바린 왕국 | 엘프 | 마법과 자연을 중시하는 왕국 |
| 바르칸 연맹 | 수인 | 여러 수인 집단의 연맹 |
| 카르테라 자유도시 | 다종족 | 주요 게이트가 모인 교역도시 |
| 드라코니아 | 드래곤 | 드래곤들의 독립 영역 |

## [제안] 외부 차원과 지구 세력
| 명칭 | 기본 성격 |
| --- | --- |
| 신계 | 신과 그 휘하 세력. 지구 인간에게 축복을 내리며 영향력을 넓힘 |
| 마계 | 여러 마왕과 군대. 지구에 직접 침공 |
| 천족 | 신과 구분되는 종족. 소속·정치적 입장은 별도 |
| 지구 인류 | 각국 정부와 축복받은 각성자를 중심으로 대응 |
| 타 차원 세력 | 게이트를 통해 출현하는 여러 독립 국가·종족 |
| 중앙 차원 | 제1차 차원대전 후 태현의 통치 아래 놓이는 세계 |

세부 명칭과 정치 체계는 실제 인물 등장 또는 중요 서사에 필요할 때만 추가한다.
