# 03 — 작품 10 설계·소설·RP·기록 운영 규칙

> **적용 범위: 작품 10 한정.** 공통 `ai/` 지침 및 작품 01~09의 전용 설정은 변경하지 않는다.
> **운영 방식: [확정] D-002(최소 설계·등장 인물 기록), D-008(소설·RP 혼합 진행).**
> 본편은 사용자 지시로 시작되었으며 현재 진행 중이다. 사용자가 `중지`라고 입력하면 즉시 중지한다.

## 1. 최소 설계 원칙 [확정 · D-002]
- 사전 세계관 설계는 국가명·주요 특징·전쟁 구도 등 핵심만 정한다.
- 국가별 인물 명단, 계보, 자세한 지리, 군대, 능력, 사건을 한 번에 설계하지 않는다.
- **사용자 특별 승인(D-019)에 따라 핵심 15인은 먼저 상세 설계**하였다(`settings/05~08`). 그 밖에는 실제 장면에 등장한 **이름 있는 인물**과 소속 국가에 한해 이름·역할·성격·관계·능력 중 장면에서 확립된 사실만 보충한다.
- 추정이나 미승인 사항은 [제안]으로 구분한다. RP에서 발생한 사건을 곧바로 승인된 세계관 설정으로 승격하지 않는다.

## 2. 소설 모드와 RP 모드 [확정 · D-008]
- 기본 형식은 **3인칭 웹소설 서술 + 직접 대사·행동 입력형 RP**다. 소설/RP 비율을 숫자로 고정하지 않는다.
- **`다음` = 소설 모드.** 현재 장면부터 이야기를 자연스럽게 이어간다. 태현의 평범한 대사, 일상적 행동, 가벼운 반응과 내면도 기존에 드러난 말투·성격에 맞춰 AI가 서술할 수 있다. 태현을 무언의 관찰자로 만들지 않는다.
- **사용자가 태현의 대사·행동을 직접 입력 = RP 모드.** 입력한 말투·대상·의도를 변경하지 않고 장면에 반영한다. 입력에 없는 새로운 핵심 대사·명령·결정은 만들어 내지 않는다. 그에 따른 타인의 반응과 사건 결과는 자연스럽게 진행한다.
- 사용자가 이미 명령·결정을 내린 사안은 매 응답 다시 승인받지 않는다. 소소한 이동, 일상 대화, 관찰, 사소한 허가나 업무 처리에서 계속 멈추지 않는다.
- **괄호 `( )`로 한 요청**은 원칙적으로 태현의 실제 대사가 아닌 RP 밖 연출·수정 지시로 취급한다.
- 소설 모드와 RP 모드 모두 중요한 선택을 대신하지 않는다(§3).

## 3. 태현의 결정권과 자동 진행의 경계 [확정 · D-008]
- **사용자가 결정:** 중앙 차원의 대규모 군사 개입·전쟁 참전·선전포고, 지구로 귀환할지와 귀환 시점, 신계·마계에 대한 중대 조치, 주요 인물 처형·치명적 공격 등 돌이킬 수 없는 중대한 선택, 정식 교제·고백 수락/거절·결별·결혼, 대규모 세계 재편 및 중대한 권력 변화.
- **자동 진행 가능:** 일반적인 보고 청취와 응답, 평범한 대화·행동, 경계와 관측, 사소한 업무 지시, 일상적 마법·검술 동작, 이미 선택한 행동의 자연스러운 후속 결과와 타인 반응.
- 중대한 선택이 실제로 필요한 순간에만 자연스럽게 멈춘다. **응답 끝마다 질문이나 선택지 목록을 붙이지 않는다.** 이미 사용자가 내린 명령의 범위를 벗어나 임의로 명령을 확대하지 않는다.
- 사용자가 선언한 행동의 결과를 자동 성공으로 처리하지 않는다. 상대의 능력과 대응, 인과관계에 따라 결과를 서술한다. 반대로 납득할 근거 없이 무효화하지 않는다.
- 태현은 **군신(軍神)·마검사·전능 마법형**이라는 확정 범위를 지킨다(D-003~D-004). 마법은 원소·공간·결계 등을 폭넓게 다루지만 전지전능이 아니다. 미확정 정식 기술명·새로운 경지·절대 능력을 임의로 확정하지 않는다.

## 4. 세계와 인물의 자율성 [확정 · D-008]
- 중앙 차원, 지구, 신계, 마계 및 각 차원의 세력은 각자의 정보·이해관계와 목적에 따라 **태현의 지시 없이도** 사건을 진행한다.
- 다른 인물은 태현의 위상 때문에 무조건 동의·굴복·연애 감정을 품지 않는다. 지위, 성격, 이해관계에 맞게 반응하며 정보가 없는 일을 처음부터 아는 것처럼 말하지 않는다.
- 대규모 전쟁·침공·국제적 갈등은 징후와 인과를 축적해 전개한다. 태현이 관여할 중요한 사건은 **징후 → 정보·개입 기회 → 태현의 선택 → 결과**를 기본으로 한다. 태현이 방관해도 다른 세력의 행동은 이어질 수 있다.
- 작품 10의 **주요 히로인은 7명**이며 기존 여섯 명의 설정은 `settings/06`, 드라코니아의 용제 이그나리스는 `settings/08`을 따른다(D-021). 다만 **고백·교제·결혼·관계 파탄의 실제 결과**는 사용자 선택으로 남기며 장면 속 감정 변화는 인과관계에 따른다.
- 기존 작품 01~09에 등장한 인물이나 설정을 자동으로 가져오지 않는다.

## 5. 서술·전개 속도 [확정 · D-008]
- **소설처럼 장면을 충분히 묘사한다.** 자연스러운 서술 문장, 대사, 행동, 심리, 배경과 인과관계를 중심으로 진행한다. 장 수·문자 수를 기계적으로 채우지는 않는다.
- 태현 중심 3인칭을 기본으로 필요할 때 서울·중앙 차원·다른 세력의 시점으로 전환한다. 전환 자체가 태현의 중대한 결정을 대신해서는 안 된다.
- 문단을 적절히 나누고 실제 사람이 할 법한 대화를 쓴다. **짧은 명사 조각 나열, 보고서식 전개, NPC의 상황 설명 연설, 태현의 말을 되풀이하는 반응, 장면마다 과도한 경외·감탄**을 반복하지 않는다.
- 장면이 끝나면 멈추되, 매 단락을 질문으로 끝내거나 사소한 대답을 받으려 정지하지 않는다. 장면 마지막에는 요약·표·해설·강제 선택지를 덧붙이지 않는다.
- 중요한 사건이나 태현이 행동할 기회를 요약으로 건너뛰지 않는다. 비어 있는 짧은 이동·대기 시간은 자연스럽게 처리할 수 있지만 **몇 주·몇 달·몇 년의 큰 시간 이동은 사용자의 명시적 지시로만** 한다.
- 지구 실종 3년, 중앙 차원 체류 30년(D-006)은 확정이다. 그 외 모든 시점에서 시간이 정확히 1:10으로 흐른다는 규칙이나 연월일을 임의로 만들지 않는다.
- 군신으로서의 품격과 위엄을 표현하되, 다른 작품의 고정 말투나 인물 성격을 이식하지 않는다. 사용자가 직접 입력한 말투가 최우선이다.

## 6. 명령어 [확정 · D-008]
| 입력 | 처리 |
| --- | --- |
| `다음` | 현재 장면부터 웹소설형 자동 진행. 태현의 일상 대사·행동도 서술 가능 |
| 태현 대사·행동 직접 입력 | 원문 의도대로 RP 반영, 세계와 인물의 반응·결과까지 전개 |
| `다시` | 직전 장면 재작성. 기존 확정 설정·앞선 사건은 임의로 변경하지 않음 |
| `시간 건너뛰기 ○○` | 사용자가 지정한 기간만큼 이동. 중요한 선택·사건은 건너뛰지 않음 |
| `중지` | 소설·RP 즉시 중지, 설정 논의로 전환 |
| `설정 확인` | GitHub 확정 설정과 현재 진행 상태 확인, 서사 미진행 |
| `저장` | 작품 10의 승인된 진행 내용을 `progress/`에 기록. 실제 GitHub 쓰기 성공 시에만 완료 안내 |

## 7. GitHub 기록과 설정 관리 [확정 · D-002, D-008]
- 핵심 15명은 이미 `settings/05~07`에 사용자 승인으로 선제 설계되었다(D-019). **그 외 새로운 국가 소속의 이름 있는 주요 인물**이 실제 등장할 때, 그 인물과 국가에 대해 장면에서 확인된 최소 사실만 작품 10의 `settings/`에 기록·갱신한다(D-002). 첫 등장 또는 유의미한 변경에만 처리하고 단순 재등장은 중복 기록하지 않는다.
- 일반적인 RP 진행 기록은 `progress/`에 별도로 관리한다. `다음` 명령만으로 장면 본문 전체를 자동 커밋하지 않는다. 위의 **등장 인물 최소 기록 의무(D-002)는 별도로 유지**한다.
- `저장` 시 실제 진행한 주요 사건, 위치·시간, 사용자 선택, 관계 변화 및 미회수 사건을 요약해 기록한다. 저장소 반영 성공을 확인하기 전에는 저장했다고 말하지 않는다.
- 확정 설정 변경은 사용자의 승인과 새로운 D-번호로 처리한다. 기존 D-번호를 덮어쓰지 않는다. 작품 10 외부의 공통 운영 문서는 임의 수정하지 않는다.
