# 05 — 지구 각성자 등급과 차원 간 상대 전투력

> 상태: [확정] D-018·D-020. 기준: 사용자 지정 F~S 등급, 김선호·한서윤 S급 및 사용자 위임 종합 설계.
> **전투력 지수는 작가용 비교 지표**다. 작품 속에 숫자가 떠오르는 능력치 시스템은 없다.

## 1. 지구 각성자 등급 [확정 · D-018]

| 등급 | 전투 능력의 일반적 기준 | 주된 역할 |
| --- | --- | --- |
| F급 | 각성 직후 또는 극히 낮은 전투 능력 | 보조, 기초 훈련 |
| E급 | 일반인보다 강한 신체·마력 | 저위험 게이트 지원 |
| D급 | 기본적인 마물 단독 처치 가능 | 일반 공략대원 |
| C급 | 전문 전투원 수준 | 중급 게이트 공략 |
| B급 | 강력한 마물과 정면 교전 가능 | 상위 공략대 핵심 |
| A급 | 대규모 공략의 주축 | 고위험 게이트·지역 방위 |
| S급 | 지구 각성자 체계 내 최정상급 강자 | 국가전략급 전력·최고난도 공략 |

- 공식 등급은 **F·E·D·C·B·A·S의 일곱 단계**만 둔다. EX, SS, SSS, S+는 없다.
- 대한각성자협회가 마력·실전 능력·공략 성과 등을 종합하여 등급을 관리한다. 신계의 축복을 받았더라도 지구 소속 각성자라면 같은 등급 체계다.
- S급 내부에도 실력 차이가 있지만 공식 세부 등급으로 세분하지 않는다.
- **김선호 S급, 한서윤 S급, 백재성 S급**이다. 한서윤은 조사 특화 S급이나 S급에 걸맞은 직접 교전 능력을 갖춘다.
- 지구 각성자 등급을 중앙 차원의 초월자, 신격, 마왕에게 공식적으로 적용하지 않는다.

## 2. 작가용 상대 전투력 지수 [확정 · D-020]

**평균적인 S급 = 지수 100**을 기준으로 한 비교치. 숫자만으로 전투 승패가 고정되지는 않으며 상성·환경·전술·숫자·상황에 따라 달라진다.

| 인물 | 등급·전투 위상 | 상대 전투력 지수 | 전문 분야 |
| --- | --- | ---: | --- |
| 박태현 | 군신 · 현재 등장 인물 중 최강 | **2,000** | 마검사, 압도적 마력량·제어, 검술, 원소·공간·결계 마법 |
| 김선호 | 지구 S급 | **145** | 뇌전 강화, 초고속 기동, 전격 검술 |
| 한서윤 | 지구 S급 | **118** | 마력 감응, 공간 분석, 마력 봉쇄·결계 |
| 엘리시아 | 최상위 인간 초월자 | **610** | 공간·결계·광역 방어 |
| 레아 | 최상위 엘프 마궁사 | **670** | 초월 궁술, 바람·자연 마법 |
| 세라피나 | 천상회의 고위 신격 | **980** | 신성 광휘·심판·가호 |
| 리제트 | 마계 칠좌 마왕 | **1,050** | 흑염·심연 침식·영역 제압 |
| **이그나리스** | **드라코니아의 용제** | **1,250** | 용의 마력·육체, 원소 마법·용의 숨결, 언어 해석 |
| 카이론 벨하르트 | 인간 초월자 · 총사령관 | **720** | 초월 검술, 방어 오러, 마력 강화 |
| 이사벨 로엔 | 인간 초월자 · 관측 마법사 | **240** | 마력 분석, 공간 감지, 방어 결계 |
| 정도현 | 비각성자 | 해당 없음 | 협회 상황·정보·행정 대응 |
| 윤재경 | 비각성자 | 해당 없음 | 국가 위기관리·군사 행정 지휘 |
| 백재성 | 지구 S급 | **155** | 마력 검술, 신체 강화 |
| 오르디엘 | 천상회의 고위 신격 | **930** | 신성 광휘, 신성 공격·결계 |
| 발타르 | 마계 칠좌 마왕 | **900** | 암흑 마력, 마력 강화, 대형 전투 도끼 |

- 숫자는 **대표적인 개인 전투 상황에서의 상대 비교치**이지 정확한 피해량·마력 총량·상성 무시 승률이 아니다.
- 비각성자 정도현·윤재경에게 전투력 지수를 임의로 배정하지 않는다.
- 중앙 차원 **토착 인간 전원 초월자**(D-001)는 유지한다. 그러나 모든 초월자가 카이론·엘리시아와 동급이라는 뜻은 아니다.
- 박태현의 강함은 현 등장인물 가운데 독보적이지만 **전지전능**이 아니다. 먼 곳의 사건·정치·동시다발적 전장을 자동으로 모두 해결하지 않는다.
- 신계·마계의 고위 신격 및 마왕은 통상 지구 S급보다 훨씬 강력하다. 지구 S급이 다수 협력해도 단독 마왕을 반드시 이기는 것은 아니다.
- 각 인물의 지수는 **일반적 교전 비교**다. 전쟁 상황, 숫자와 진형, 지형, 사전 준비, 제압·정찰 등 비전투 임무의 성과는 별도 판단한다.

## 3. 지구 게이트와 사건의 연대기 [확정 D-006·D-007·D-010·D-014, 그 외 진행 방향]

1. 박태현 실종 당시 지구에는 게이트가 없었다.
2. 실종 이후 지구에서 여러 차원 게이트가 생기기 시작했고, 각성자·길드·대응 기관이 형성되었다. 실종 이후 지구 경과 시간은 3년, 태현의 중앙 차원 체류 기간은 30년이다. **상시 1:10 고정 시간비는 아님.**
3. 이미 기존 게이트가 존재하는 서울에 일반 게이트와 **동일한 크기의 자연 발생 게이트**가 새로 나타났다. 특정 신·마·제3세력이 열지 않았다. 필요시 군신의 명령에 따라 **이 게이트를 확장할 수 있으나 현재는 일반 크기**다(D-022). 특정 신·마·제3세력이 열지 않았다.
4. 중앙 차원에서도 이를 관측했고 태현은 처음에는 **조사만 허락**하며 지구로 가지 않는다(실제 RP 지시 포함).
5. 신계·마계가 이 환경을 이용하려고 독립적으로 움직일 가능성과 실제 전쟁 전개는 본편 인과 및 RP 선택을 따른다. **자연 발생한 게이트의 배후를 임의로 만들지 않는다.**
