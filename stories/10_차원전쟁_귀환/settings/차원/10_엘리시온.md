# 10 — 엘리시온 (중앙 차원)

> 구분: 중심
> 상태: **설계 진행 중** (완료: 1~9)
> 기존 확정 출처 (설계 시 이 파일로 병합): D-001 토착 인간 전원 초월자; D-023 이름; D-024 군신의 권위와 동맹국 주권 구분; D-025 구조; 아르데인 제국·카르테라 자유도시(02); 박태현(04); 엘리시아(06); 카이론·이사벨(07)
> 표기: [확정] 사용자 승인 / [추천] 제안 / [미정] 미결정

## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | 엘리시온 / 중앙 차원 |
| 한 줄 정체성 | [확정] **모든 세계의 교차점이자, 군신이 다스리는 통일 제국.** 모든 차원의 관문이 모이는 요충지라 대전의 전장이 됐고, 대전 이후 군신 아래 하나로 통일됐다. **엘리시온 안의 국가는 하나뿐**이다 |
| 분위기·톤 | [확정] **활기와 상흔이 함께 있는 재건의 시대.** 다종족이 오가는 교역과 모험의 세계인데, 대전의 흔적이 곳곳에 남아 있다. 본편의 기본 무대 |
| 참고 모티프 | [확정] **엘리시움**(그리스 신화에서 영웅들이 머무는 낙원, 차원 이름의 어원) + **콘스탄티노플**(동서 교역의 중심, 카르테라의 모델) + 정통 판타지 대륙 |
| 국가 | [확정] **엘리시온 제국** — 엘리시온 유일의 국가. 차원 이름을 국호로 쓴다. 대전 전의 **아르데인**은 옛 왕국 이름으로 남아 지금은 제국의 **아르데인 지방**이다(엘리시아·카이론의 출신). **카르테라**는 자유도시가 아니라 **제국 직할 교역 도시** |
| 군주의 칭호 | [확정] **"군신"이 곧 황제의 칭호**다. 따로 "황제"를 쓰지 않으며, 제국 사람들은 "군신이시여" 또는 "주군"이라 부른다 |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] 하나의 거대한 대륙과 주변의 바다·섬들. 대륙 한가운데에 게이트가 모인 거대한 분지(관문의 분지)가 있고 그 중심에 카르테라가 있다 |
| 하늘·빛·기후 | [확정] 해와 달이 뜨는 평범한 하늘. **밤이면 수백 개 게이트의 빛이 별처럼 박혀 보인다.** 사계절이 있고 지역마다 다양하다(북쪽 설원, 남쪽 바다와 섬, 동쪽 사막과 초원) |
| 시간 흐름 (지구 대비) | [확정] 서울 게이트 이전: 엘리시온의 시간이 지구보다 훨씬 빠르게 흘렀다(태현 기준 지구 3년 = 엘리시온 30년, 비율은 일정하지 않음). **서울 게이트로 두 세계가 직접 이어진 순간부터 시간이 같은 속도로 맞춰졌다** — 본편에서 엘리시온의 하루는 지구의 하루 |
| 특산 자원 | [확정] **마석**(마력이 굳은 결정)과 **교역 그 자체** — 모든 차원의 물자가 카르테라를 거쳐 흐른다 |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **엘리시온 인간(초월자).** 겉보기에는 보통 인간과 같으나 힘을 쓸 때 **눈동자가 마력의 빛으로 물든다**(마력광). **엘리시온에서 태어난 인간은 모두 처음부터 마력을 지니고 태어난다** — "토착 인간은 전원 초월자"의 원리. 수명 약 300년, 노화가 아주 느려 오래 전성기 외모를 유지한다. 마력 수련으로 경지를 올린다. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] 엘프·수인·용족은 각자 자기 차원에 속하며 엘리시온에서는 **이주민·교역자**로 산다(주로 카르테라, 용족은 드물게 인간 모습). 드물게 망명자(셀레스티아의 하위 신·반신, 에덴의 흑익, 판데모니움의 떠돌이 마족). 혼혈(하프엘프, 인간과 수인의 혼혈). **지구인은 태현 한 명뿐** — 지구 인간은 마력 없이 태어나 초월자가 아니며, 태현은 30년 동안 스스로 힘을 쌓아 올린 유일한 예외다("마력 없이 태어난 이방인이 초월자들 위에 선 존재") |
| 동식물·괴수 | [확정] 지구와 비슷한 일반 동식물, 마수(마력을 지닌 짐승, 사냥감이자 탈것), **잔재수**(대전 뒤 잿빛 전장에 남은 신계 신수·마계 마수가 변이한 괴물), 카르테라의 게이트로 흘러든 이계 생물 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **마력** — 엘리시온의 대지와 대기에 가득한 힘. 초월자는 심장 가까이의 **마력심**에 마력을 모아 쓴다. **가장 자유로운 힘**: 원소·공간·결계·강화 등 무엇이든 될 수 있지만, 한 계열만 파고든 다른 힘(신력·마기·성력)보다 전문성이 낮다. 계열은 **기사**(오러로 몸과 무기 강화), **마법사**, **마검사**(둘 다, 극히 드묾). **태현은 예외 — 마력심이 없고, 혈관 자체가 마력 회로다**(30년 동안 엘리시온의 마력이 몸에 스며 혈관이 회로로 바뀜, 상세는 9. 주인공) |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): **견습** 10~60(엘리시온 사람 대부분 — "전원이 초월자"는 전원이 마력을 가졌다는 뜻) / **익스퍼트** 60~200(지구 S급이 이 경지 위쪽과 맞먹음) / **마스터** 200~450(이사벨 240) / **그랜드마스터** 450~800(엘리시아 610, 카이론 720 — 제국 최상위권) / **초월경** 800~1,300(역사에 손에 꼽을 만큼) / **군신** 2,000(태현 단 한 명, 어떤 경지에도 들지 않는 예외) |
| 고유 능력·마법 계열 | [확정] 마력의 범용성. 태현의 "전능 마법형"은 이 범용성을 끝까지 끌어낸 것 |
| 약점·제약 | [확정] ① 마력이 고갈되면 힘을 못 씀 ② 마력심이 다치면 힘을 잃음(목숨까지는 아님) ③ 전문성이 낮아 한 계열만 극한까지 판 상대에게는 그 계열로 밀림. **본거지 밖:** 출력은 그대로지만 **대기 중 마력이 옅은 차원에서는 회복이 아주 느리다** — 지구는 마력이 희박해 엘리시온 초월자가 오래 싸우면 바닥을 드러낸다. 태현도 이 제약에서 예외가 아니다(마력량이 압도적이라 바로 티가 나지 않을 뿐). 태현의 회로 구조에 따른 차이는 9. 주인공에서 정한다 |
| 타 차원 힘과의 상성 | [확정] 신력: 정면 열세, 공간 마법으로 법칙 우회 / 마기: 침식당하지만 결계·공간 마법으로 막음 / 성력: 중립 |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] **군신 = 황제**, 제국의 모든 권위가 그에게서 나온다. 군신은 말수가 적고 큰 결정만 내리며 실제 통치는 **두 기둥**이 맡는다 — **정무는 엘리시아**(재상 격), **군무는 카이론**(군 총사령관). **제국 평의회**(지방 총독·대귀족의 자문 기구, 결정권 없음). **수도 카르테라**, 옆 고원에 카멜롯. 지방: 카르테라 직할구, 아르데인 지방(옛 왕국), 북부 설원령, 남부 군도령, 동부 사막령 — 각각 군신이 임명한 총독이 다스린다 |
| 계급 | [확정] 황제(군신) / 귀족(옛 아르데인 귀족과 대전 공훈의 전공 귀족 — 은근한 갈등) / 기사·마법사(마스터 이상이면 명예 신분과 칭호, **경지가 곧 지위의 일부**) / 평민(대부분, 견습~익스퍼트) / 이주민(다른 차원 출신, 카르테라에서 자유). **노예 없음 — 군신이 통일하며 노예제를 폐지**(지구 출신의 가치관이 남긴 흔적) |
| 경제·화폐 | [확정] 금화·은화·동화, 큰 거래에는 마석. 제국 최대 수입은 **카르테라 게이트의 통행세와 관세** |
| 종교·신앙·가치관 | [확정] 대전 뒤 셀레스티아의 신들에 대한 신앙이 크게 줄었다. 민간에서 **군신을 신처럼 받드는 "군신 신앙"**이 생겨나는 중이며 태현 본인은 이를 싫어한다. 강함과 명예를 중시하고, 전쟁을 겪은 세대라 평화의 가치도 높게 친다 |
| 법·관습·금기 | [확정] 군신의 칙령과 옛 아르데인 법전을 합친 **제국법**. 중죄: ① 허가 없이 게이트를 열거나 통과(특히 판데모니움 쪽) ② **다른 차원 세력의 힘을 받는 것**(셀레스티아의 축복, 판데모니움의 계약 등) — 반역에 준한다 |
| 언어·이름 짓기 규칙 | [확정] 엘리시온 공용어(카르테라의 교역어로 다종족 간에도 통함). 이름은 서양 판타지풍 "이름 + 성", 귀족은 가문명 |
| 호칭·존칭 | [확정] 군신: "군신이시여" 또는 "주군" / 귀족·기사: "경" / 마스터 이상의 마법사: "현자" / 엘리시아: "재상 각하" |
| 의복·건축·음식·일상 | [확정] 중세 판타지에 비잔틴풍이 섞임 — 카르테라는 돔과 모자이크의 다종족 도시, 아르데인은 석조 성채와 기사단. 모든 차원의 식재료가 모여 카르테라의 음식 문화가 가장 다양하다. 일상은 기사 수련, 시장, 잔재수 사냥, 게이트로 오가는 상인들 |

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 신화 | [확정] 아득한 옛날부터 모든 차원의 관문이 모이는 교차점이었고, 인간 왕국 여럿과 카르테라 자유도시가 있었다. 오랜 세월 셀레스티아가 "질서 관리자"를 자처하며 감독했고 인간 왕국들은 신을 섬겼다. 대전 직전에는 아르데인 왕국이 가장 강했다 |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] 엘리시온 자체가 전장. 판데모니움의 침공과 셀레스티아의 개입으로 인간 왕국들이 무너졌고, **태현이 두 세력을 모두 몰아내며** 끝났다. **태현이 온 경위:** 신계와 마계가 정면으로 부딪힌 충격에 차원의 벽이 찢어졌고 그 균열이 지구까지 닿아 태현이 휩쓸려 왔다(우연한 사고). **이 균열로 지구와 다른 차원 사이의 벽이 약해져 태현 실종 뒤 지구에 게이트가 생기기 시작했고, 서울 게이트도 약해진 벽에서 자연스럽게 열린 것이다.** **셀레스티아와의 휴전 조건(베리타스의 「맹약」):** ① 셀레스티아는 엘리시온에 군대도 화신도 보내지 않는다 ② 군신은 셀레스티아를 침공하지 않는다 ③ 비프로스트의 엘리시온 쪽 출구는 군신 측이 감시한다 — **지구에 대한 조항이 없으므로** 셀레스티아는 맹약을 어기지 않고 지구에 축복·화신을 보낼 수 있다. 판데모니움과는 협정 없이 엘리시온 쪽 지옥문 봉쇄가 이어진다 |
| 전후 현재 상황 | [확정] 종전 직후 남은 인간 세력이 군신 아래 모여 엘리시온 제국을 세웠고, 10년의 재건을 거쳤다. 서울 게이트가 열리며 지구와 시간이 같은 속도로 맞춰졌다 |

#### 9-2a 궁정 세 사람 상세 프로필 (기존 06·07에서 이관)
> 직책·소속은 위 표(엘리시온 제국 체제)가 우선한다. 기존 문서의 "아르데인 제국 출신"은 "아르데인 지방(옛 왕국) 출신"으로 읽는다.

###### 엘리시아 — 엘리시온 · 군신의 궁정

- 나이: **58세**(젊은 외형 유지); 종족: 엘리시온 토착 인간 **초월자**; 출신: 아르데인 제국; 소속: **군신의 궁정**.
- 지위: 군신의 최측근 **정무·외교 총괄 보좌관**. 레아·카이론의 군사 지휘권과 구분된다.
- 전투: **최상위 초월자, 지수 610**; 무기보다 공간·결계 마법 중심.
- 외형: 은발, 보라색 눈, 우아한 분위기.
- 성격: 지적·침착·헌신적, 가까운 관계에서는 은근한 독점욕. 감정은 겉으로 절제.
- 기술 계열: **공간 결계**(지역 방어·격리), **공간 간섭**(이동 경로·마법 궤도 교란), **마력 분산**(광역 공격의 충격을 결계로 나누어 흡수).
- 강점: 광역 방어, 공간 방어, 정무 판단. 약점: 근접전·장시간 공격전, 결계 범위 확대에 따른 정밀도 저하.
- 과거 **[확정 · D-017]**: 군신 이전부터 태현을 알고 함께한 오래된 이해자. 30년 성장·전쟁·통치를 가까이서 지켜보았다.
- 관계 출발: 깊은 애정은 있으나 공식 연인 관계는 아님. 태현이 지구를 향할 가능성에 불안을 느끼면서도 그의 의사를 존중한다.
- 서사 기능: 엘리시온 통치·정무·오래된 신뢰와 사랑.

###### 카이론 벨하르트 — 군신 휘하 군사 총사령관

- 나이: **69세**, 종족: 엘리시온 토착 인간 **초월자**, 출신: 아르데인 제국.
- 지위·소속: **군신 휘하 군세의 총사령관**. 왕국 동맹군 지휘관인 레아와 상하관계가 아니다.
- 전력: **지수 720**, 최상위 초월자급 기사. 장검, **초월 검술·마력 강화·방어 오러**.
- 외형: 검은 머리와 은회색 눈, 검은 망토와 중갑.
- 성격: 과묵·냉철·현실적·충직. 태현에 대한 존경은 깊지만 군사적 위험에는 직언함.
- 강점: 공격·방어가 균형 잡힌 근접전, 전장 지휘와 대규모 병력 운용. 약점: 정밀 차원 관측 등 기술 연구는 전문 분야가 아니며 신·마왕급과는 개인 전력 차가 있음.
- 과거: 제1차 차원대전에서 태현과 함께 싸운 전우이자 주요 지휘관.
- 현재 기능: 태현이 직접 전장에 나서지 않을 때 엘리시온 군세의 대응을 책임진다. 군주의 지시를 대신 창작하거나 임의로 전면전을 선포하지 않는다.

###### 이사벨 로엔 — 궁정 차원 관측 책임자

- 나이: **49세**, 종족: 엘리시온 토착 인간 **초월자**, 출신: 카르테라 자유도시.
- 지위·소속: 군신의 궁정 **차원 관측 책임 마법사**.
- 전력: **지수 240**, 마법사. **마력 분석·공간 감지·차원 관측·방어 결계**, 전투 전문가는 아님.
- 외형: 진보라색 머리, 푸른 눈, 마법사 복장.
- 성격: 호기심이 많고 논리적·직설적. 자료가 불충분하면 군신 앞에서도 불확실성을 숨기지 않는다.
- 강점: 게이트 공간층·마력 특성의 분석, 안전한 원격 탐사. 약점: 최상위 개인 전투원에 비해 정면 교전 능력이 부족하고 관측 정보에 한계가 있음.
- 과거: 제1차 차원대전 당시 공간·차원 이동 현상을 연구해 군신 진영을 지원.
- 현재 기능: 서울 초대형 게이트 조사 실무. 앞 장에서 등장한 **이름 없는 관측 마법사 역할을 가능한 범위에서 계승**해 신규 인물 증식을 줄인다.
- 유의: 관측만으로 모든 정보를 알 수 있는 것은 아니며 **서울 게이트가 신계·마계의 인위적 작품이라고 오판하여 정사화하지 않는다(D-010)**.
