> 구분: 세력 차원

> 기존 확정 출처 (설계 시 이 파일로 병합): D-012 판테온·신위대; D-025; 세라피나(06); 오르디엘(07); 신의 축복을 지구 인간에게 내림(01·02)

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] 끝없는 하늘에 거대한 부유 대륙들이 층층이 떠 있다. **층이 곧 서열**이며, 높은 층일수록 지위가 높은 신의 영역이다 |
| 하늘·빛·기후 | [확정] 해도 밤도 없다. 차원 전체가 판테온에서 퍼지는 질서의 빛에 잠겨 있고, 위계가 흐트러지면 빛도 흔들린다 |
| 시간 흐름 (엘리시온 대비) | [확정] 엘리시온과 거의 같다. 신들은 수명이 길어 시간을 느긋하게 체감한다 |
| 특산 자원 | [확정] **암브로시아** — 판테온의 정원에서만 열리는 불멸의 양식. 서열에 따라 배분되므로 배분 자체가 권력이다 |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **신족.** 인간형이지만 더 크고 완벽에 가까운 모습, 몸에서 은은한 빛(신위)이 흐르고 **금빛 눈**이 공통 징표. 늙지 않는 사실상의 불멸이나 **신핵(神核)**이 부서지면 소멸한다. 탄생은 신들 사이의 **혈통신**과 판테온 질서의 빛에서 저절로 태어나는 **현현신** 두 갈래. 태어날 때부터 고유 권능 하나를 가지며, 세월과 서열에 따라 커진다. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] (높은 순) **주신**(판테온의 정점, 단 한 명) → **고위 신격**(판테온에 자리를 가진 신, 세라피나·오르디엘) → **하위 신격**(자리 없는 신, 고위 신격을 섬기거나 영역을 다스림) → **반신**(신과 타 종족의 혼혈, 신족 대우를 못 받는 경계의 존재) → **사도**(신을 섬기는 비신 존재. 다른 차원에서 뽑혀 온 영웅·전사로 신위대의 주력, 에인헤랴르 모티프). 날개 달린 천사형 종족은 없다(에덴 몫) |
| 동식물·괴수 | [확정] **신수**(빛의 말, 천둥새, 황금 늑대 — 신위대의 탈것·전투 짐승), **암브로시아 나무**(판테온 정원에만 자람), 타르타로스에 봉인된 **옛 거신들**(신족 이전의 지배자, 숨겨진 역사·떡밥, 티탄 모티프) |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **신력(神力)** — 신핵에서 만들어지며 세계에 정해진 법칙을 강제하는 성질. 사도·반신은 신에게서 나눠 받은 신력을 쓴다. **지구의 축복**은 신이 자기 신력을 조금 떼어 인간에게 나눠 주는 것이며, 축복받은 각성자는 사실상 그 신의 지구 쪽 대리인이 된다 |
| 경지·등급 | [확정] 신핵의 크기로 정해지며 서열과 직결된다. 작가용 지수(지구 S급=100, 태현=2,000): 주신 1,600~1,800 / 고위 신격 850~1,200(세라피나 980, 오르디엘 930) / 하위 신격 300~700 / 반신 150~400 / 사도 100~500 / 축복받은 지구 각성자 = 원래 등급 + 축복 크기만큼 |
| 고유 능력·마법 계열 | [확정] 공통: **신성 광휘**(빛의 공격·정화), **신역 전개**(주변에 자기 권능의 법칙을 잠시 강제), **가호**(신력 분여). 고유: 신마다 하나의 권능 영역(빛·천둥·전쟁·심판·지혜 등) |
| 약점·제약 | [확정] ① 신핵이 부서지면 소멸 ② **셀레스티아를 벗어나면 출력이 크게 떨어짐**(판테온 질서의 빛에서 멀어짐) — 신들이 지구를 직접 침공하지 않고 축복을 택한 이유 ③ 법칙을 강제하는 힘이라 공간 자체를 비트는 마법에 약함 |
| 타 차원 힘과의 상성 | [확정] 마기(판데모니움)와 상극 — 부딪히면 서로 깎아 먹음. 마력(엘리시온)에는 정면 우세지만 공간 마법으로 우회당함. 정령력(에테리아)·천족의 힘(에덴)과의 상성은 해당 차원 설계 때 정함 |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] 주신을 정점으로 한 위계 사회. **판테온은 고위 신격 12석**(주신 별도)이며 주요 결정은 12석 의결, 주신은 거부권을 가진다(올림포스 12신). 서열은 판테온 의결로 오르거나, 상위 신에게 **신판(神判) 결투**를 걸어 이기면 그 자리를 빼앗는다(아스가르드 전사 문화) |
| 계급 | [확정] 주신 → 고위 신격 → 하위 신격 → 반신 → 사도 (3. 종족·생태) |
| 경제·화폐 | [확정] 화폐 없음. 암브로시아 배분이 곧 경제이며, 하위 신은 공적·공물(신수, 사도의 전공)로 배분량을 늘린다 |
| 종교·신앙·가치관 | [확정] 신들이 섬기는 것은 **원초의 질서** 자체 — "모든 차원은 위계 안에 있어야 한다". 명예·서열·형식을 가장 중시한다 |
| 법·관습·금기 | [확정] 판테온이 정하는 질서 율법, 위반 시 타르타로스 유배. 금기: ① 상위 신에 대한 반역 ② **신살(神殺)** — 신이 신핵을 부수는 일 ③ **판테온 허락 없이 하계에 신력을 쓰는 일**(지구 축복은 판테온 의결로 승인된 공식 행동이며, 무단 개입은 내부 반역이 된다) |
| 언어·이름 짓기 규칙 | [확정] 신족 고유어 천상어. 이름은 라틴·그리스·북유럽풍. 고위 신격은 이름 뒤에 권능 칭호를 붙인다(예: 심판의 세라피나) |
| 호칭·존칭 | [확정] 주신 "주신이시여" / 고위 신격 "○○ 신" / 하위가 상위를 부를 때 "존귀하신 ○○" / 사도는 섬기는 신을 "나의 주인" |
| 의복·건축·음식·일상 | [확정] 의복은 흰색·금색, 고위일수록 장식과 빛이 강함. 판테온·신역은 대리석과 황금의 신전(올림포스), 발할라는 거대한 목조·석조 홀(아스가르드). 음식은 암브로시아와 넥타르. 일상은 연회·결투, 그리고 **천상의 거울**로 하계를 내려다보며 개입할 때를 고르는 일 |

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 신화 | [확정] 태초의 셀레스티아는 혼돈이었고 옛 거신들이 힘으로 다스렸다. 원초의 질서에서 첫 신(주신)이 현현했고, 주신과 신들이 거신 전쟁에서 이겨 거신들을 타르타로스에 봉인했다. 이로써 "질서의 시대"가 시작됐다(티타노마키아 모티프) |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] 판데모니움과 정면으로 맞선 한 축. 처음엔 태현을 하계의 한 인간으로만 봤으나 결국 그에게 쫓겨났다. 오르디엘의 원정군 저지, 세라피나 패배, **전대 전쟁의 신이 태현과의 결전에서 쓰러짐**(3석 승계). 종전과 함께 엘리시온 감독권 상실, 신위대 전력 절반 상실. 신살 금기는 신이 신을 죽이는 경우이므로 태현에게는 해당하지 않는다 |
| 전후 현재 상황 | [확정] 위신이 추락해 판테온이 강경파·신중파로 갈라졌다. 신들은 군신을 두려워하면서도 증오하며, 지구를 위신 회복의 마지막 기회로 본다 |

### 연표
> 기준: 태현이 엘리시온에 온 해 = T+0. 전쟁 기간 숫자는 엘리시온 설계 때 전체 연표와 다시 맞춘다.

| 시기 | 사건 |

| 태초 | 거신 전쟁. 거신 봉인, 판테온 수립 |

| 오랜 세월 | 판데모니움과의 끝없는 대립 (신력·마기 상극) |
| 대전 발발 (T 이전) | 판데모니움의 엘리시온 장악 시도에 판테온이 신위대를 보내 맞섬. 엘리시온이 전장이 되고 다른 차원들도 참전 |
| T+0 | 태현이 엘리시온에 떨어짐. 셀레스티아는 알아채지 못함 |
| 대전 후반 | 태현이 전장에 이름을 떨침. 오르디엘의 원정군이 엘리시온 장악을 노리다 저지당함. 세라피나도 태현과 맞섰다가 패함 |
| 대전 막바지 | 전대 전쟁의 신이 태현과의 결전에서 쓰러짐. 지금의 전쟁의 신이 3석을 이음 |
| 종전 (약 T+20) | 신위대가 엘리시온에서 쫓겨남. 엘리시온 감독권 상실, 신위대 전력 절반 |
