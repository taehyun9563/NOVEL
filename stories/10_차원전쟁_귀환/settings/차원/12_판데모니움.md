# 12 — 판데모니움 (마계)

## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | 판데모니움 / 마계 |
| 한 줄 정체성 | [확정] **순수 혼돈형.** 힘이 곧 법인 혼돈의 차원. 마족은 본성이 호전적이며 침략과 정복 자체를 추구한다. 지구 침공은 생존이 아니라 정복욕, 대전 패배의 설욕, 칠좌 사이의 경쟁에서 나온다 |
| 분위기·톤 | [확정] 겉은 공포스러운 지옥이지만, 속은 오히려 솔직한 사회. 강하면 출신과 상관없이 누구든 올라간다 (셀레스티아의 "겉은 찬란, 속은 위선"과 거울 대비) |
| 참고 모티프 | [확정] 단테 《신곡》 지옥편(아래로 내려가는 여러 층의 지옥) + 《실낙원》의 판데모니움(마왕들의 수도) + **칠죄종** — 칠좌를 일곱 대죄(교만·탐욕·색욕·분노·폭식·질투·나태)와 하나씩 짝짓는다 |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] **아래로 파고드는 거대한 깔때기 모양의 지옥.** 깊을수록 마기가 짙어 강한 자일수록 더 깊이 내려가 산다. 서열은 **힘으로 빼앗는 유동 서열** — 더 강한 마왕이 나타나면 영지 층이 뒤바뀐다 (셀레스티아의 고정 서열과 대비) |
| 하늘·빛·기후 | [확정] 해가 없고 하늘은 늘 핏빛 구름으로 붉다. 빛은 용암과 흑염에서 나온다. 기후는 층마다 극단적이다(불타는 층, 얼어붙은 층, 폭풍이 그치지 않는 층) |
| 시간 흐름 (엘리시온 대비) | [확정] 엘리시온과 거의 같다. 다만 깊이 내려갈수록 시간 감각이 뒤틀린다 |
| 특산 자원 | [확정] **마정석** — 마기가 굳은 검붉은 결정. 힘의 원천이자 화폐 |

### 주요 지역·도시·명소
| 이름 | 종류 | 특징 |
| --- | --- | --- |
| 만마전(판데모니움) | 수도 | [확정] 깔때기 맨 위, 입구 근처의 거대한 성채 도시. 칠좌의 회합 장소이자 싸움이 금지된 유일한 중립 지대 (《실낙원》) |
| 칠좌의 영지 | 일곱 층 | [확정] 마왕마다 하나씩 다스리는 층. 풍경이 그 마왕의 대죄를 닮는다 (예: 분노의 층은 불타는 전장, 나태의 층은 끝없는 잿빛 늪) |
| 피의 투기장 | 결투장 | [확정] 서열을 다투는 공식 결투장. 하급 마족이 이름을 알리는 곳 |
| 지옥문 | 게이트 집결지 | [확정] 판데모니움의 차원 관문들이 모인 곳. **지구로 바로 이어지는 게이트가 여럿 있다** — 마계가 군대째로 지구를 직접 침공할 수 있는 이유 |
| 무법 황야 | 변경 | [확정] 칠좌 어디에도 속하지 않은 떠돌이 마족들의 땅 |
| 코키토스 | 최하층 | [확정] 깔때기 맨 밑의 얼어붙은 호수. 아무도 끝까지 내려가 본 적 없는 바닥 (단테 지옥의 최하층) |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **마족.** 공통 징표는 **뿔과 붉은 눈**. 강할수록 인간형에 가깝고 아름다워지며 뿔이 커지고, 약할수록 괴물 형상. 수명은 수백~수천 년이나 싸움으로 죽는 일이 잦아 오래 사는 마족은 드물다. **마핵(魔核)**이 부서지면 죽는다(신핵과 짝). 탄생은 마기의 혼돈에서 저절로 태어나는 **심연생**(대부분 하급·괴물형)과 마족끼리 낳은 **혈족**(상위로 태어나는 경우가 많음) 두 갈래. **성장: 쓰러뜨린 강자의 핵(마족의 마핵, 신의 신핵, 다른 종족은 심장에 깃든 힘)을 먹어 그 힘을 흡수한다** — 약육강식이 사회 원리이자 생물학적 본능. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] (힘이 기준이며 언제든 뒤집힘) **마왕**(칠좌, 일곱 자리) → **마공(魔公)**(마왕 아래 대귀족, 마왕 자리 후보) → **상위 마족**(인간형, 고지능, 군 지휘) → **중위 마족**(반인반수, 군 주력) → **하위 마족**(괴물형, 본능). 별도로 **반마(半魔)**(마족과 타 종족의 혼혈, 반신과 짝을 이루는 경계의 존재), **타락자**(타 차원 존재가 마기에 물들어 변한 것 — 지구 검은 성배회 숭배자들의 끝) |
| 동식물·괴수 | [확정] 마수(지옥견, 핏빛 까마귀, 용암 속을 헤엄치는 거대한 벌레 — 탈것이자 사냥감), 식물(피의 가시덤불, 흑염 속에서만 피는 검은 꽃), 코키토스 깊은 곳은 미지 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **마기(魔氣)** — 마핵에서 만들어지는 혼돈의 힘. **자기 대죄의 감정을 느낄수록 커진다**(분노의 마왕은 분노할수록, 탐욕의 마왕은 욕심낼수록). 지구에 힘을 주는 방식은 **계약** — 마기를 빌려주고 충성이나 목숨을 대가로 받으며, 오래 쓴 인간은 타락자가 된다(셀레스티아의 축복과 짝) |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): 마왕 1,000~1,500 / 마공 500~850 / 상위 마족 200~500 / 중위 마족 80~200 / 하위 마족 10~80 / 반마 100~400 / 타락자 = 원래 등급 + 계약한 마기. 주신 같은 단독 정점은 없고 일곱 마왕이 비슷한 힘으로 서로 견제한다. **강점은 양** — 하위·중위 마족이 수백만 |
| 고유 능력·마법 계열 | [확정] 공통: 「마기 방출」 / **「마역 전개」** 주변을 마계 환경으로 침식(신역 전개와 짝, 리제트의 「심연 침식」은 상위판) / 「계약」 / 「핵 포식」. 고유: 마왕은 자기 대죄의 권능, 그 아래는 개체 특성 |
| 약점·제약 | [확정] ① 마핵이 부서지면 죽음 ② 대죄의 감정에 휘둘리면 판단이 흐려짐 ③ 마계 밖에서는 마기 회복이 느림 — 지구 침공군에게 마정석 보급선이 생명줄. **게이트의 격 제한**: 게이트 크기에 따라 통과 가능한 존재의 격이 정해지며, 지구의 지옥문 게이트는 대부분 작아 **상위 마족까지만** 넘어간다. 마왕이 지구에 가려면 대형 게이트를 새로 열거나 억지로 넓혀야 하므로, 마왕 강림은 신의 본체 강림과 맞먹는 큰 사건이다. 마계 밖에서도 출력 자체는 떨어지지 않는다 |
| 타 차원 힘과의 상성 | [확정] 신력(셀레스티아)과 상극. 마력(엘리시온)은 침식해서 우세하나 **결계·공간 마법에는 침식이 막힌다**. 정령력·천족의 힘과의 상성은 해당 차원 설계 때 정함 |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] 중앙 정부 없음. **칠좌가 각자 자기 층을 다스리고**, 모두에게 관련된 일만 만마전 회합에서 다룬다(합의가 드물고, 합의돼도 깨지기 일쑤). 누구든 마왕에게 **도전 결투**를 걸 수 있고, 이기면 그 자리·영지를 차지하고 진 마왕의 마핵을 먹는다 |
| 계급 | [확정] 3. 종족·생태의 계급 그대로. 출신이 아니라 힘으로만 정해진다 |
| 경제·화폐 | [확정] 마정석이 화폐. 약탈이 경제의 중심이며 포로와 하위 마족이 노역을 한다 |
| 종교·신앙·가치관 | [확정] 섬기는 신은 없고 자기 욕망과 힘만 믿는다. **대죄가 곧 미덕** — 욕망에 솔직한 것이 존중받고, 욕망을 숨기는 것은 약함으로 여겨진다 |
| 법·관습·금기 | [확정] 전체에 통하는 법은 단 하나, **만마전 협약**("만마전 안에서는 싸우지 않는다"). 그 밖은 영지마다 마왕의 법. 금기: ① 만마전 협약 파기 ② 결투에 제3자 개입 ③ **셀레스티아와 손잡는 것** — 마족 전체에 대한 최대의 배신 |
| 언어·이름 짓기 규칙 | [확정] 마족 고유어 마계어. 이름은 악마학풍(리제트, 발타르). 마왕은 이름 앞에 대죄 칭호를 붙인다(예: 분노의 발타르) |
| 호칭·존칭 | [확정] 마왕은 "○○의 군주"(분노의 군주 등). 부하는 섬기는 마왕을 "나의 왕". 동격끼리는 반말과 도발이 기본 |
| 의복·건축·음식·일상 | [확정] 의복은 검붉은 갑옷과 화려한 장식(힘 과시 문화라 강할수록 요란). 건축은 흑요석·뼈·용암의 성채. 음식은 마수 고기와 핏빛 술, 강자의 핵을 먹는 일은 최고의 의식. 일상은 투기장 관람, 약탈, 하극상 음모, 연회 |
