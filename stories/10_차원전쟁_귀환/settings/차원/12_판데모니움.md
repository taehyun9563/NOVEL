## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **마족.** 공통 징표는 **뿔과 붉은 눈**. 강할수록 인간형에 가깝고 아름다워지며 뿔이 커지고, 약할수록 괴물 형상. 수명은 수백~수천 년이나 싸움으로 죽는 일이 잦아 오래 사는 마족은 드물다. **마핵(魔核)**이 부서지면 죽는다(신핵과 짝). 탄생은 마기의 혼돈에서 저절로 태어나는 **심연생**(대부분 하급·괴물형)과 마족끼리 낳은 **혈족**(상위로 태어나는 경우가 많음) 두 갈래. **성장: 쓰러뜨린 강자의 핵(마족의 마핵, 신의 신핵, 다른 종족은 심장에 깃든 힘)을 먹어 그 힘을 흡수한다** — 약육강식이 사회 원리이자 생물학적 본능. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] (힘이 기준이며 언제든 뒤집힘) **마왕**(칠좌, 일곱 자리) → **마공(魔公)**(마왕 아래 대귀족, 마왕 자리 후보) → **상위 마족**(인간형, 고지능, 군 지휘) → **중위 마족**(반인반수, 군 주력) → **하위 마족**(괴물형, 본능). 별도로 **반마(半魔)**(마족과 타 종족의 혼혈, 반신과 짝을 이루는 경계의 존재), **타락자**(타 차원 존재가 마기에 물들어 변한 것 — 지구 검은 성배회 숭배자들의 끝) |
| 동식물·괴수 | [확정] 마수(지옥견, 핏빛 까마귀, 용암 속을 헤엄치는 거대한 벌레 — 탈것이자 사냥감), 식물(피의 가시덤불, 흑염 속에서만 피는 검은 꽃), 코키토스 깊은 곳은 미지 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **마기(魔氣)** — 마핵에서 만들어지는 혼돈의 힘. **자기 대죄의 감정을 느낄수록 커진다**(분노의 마왕은 분노할수록, 탐욕의 마왕은 욕심낼수록). 지구에 힘을 주는 방식은 **계약** — 마기를 빌려주고 충성이나 목숨을 대가로 받으며, 오래 쓴 인간은 타락자가 된다(셀레스티아의 축복과 짝) |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): 마왕 1,000~1,500 / 마공 500~850 / 상위 마족 200~500 / 중위 마족 80~200 / 하위 마족 10~80 / 반마 100~400 / 타락자 = 원래 등급 + 계약한 마기. 주신 같은 단독 정점은 없고 일곱 마왕이 비슷한 힘으로 서로 견제한다. **강점은 양** — 하위·중위 마족이 수백만 |
| 고유 능력·마법 계열 | [확정] 공통: 「마기 방출」 / **「마역 전개」** 주변을 마계 환경으로 침식(신역 전개와 짝, 리제트의 「심연 침식」은 상위판) / 「계약」 / 「핵 포식」. 고유: 마왕은 자기 대죄의 권능, 그 아래는 개체 특성 |
| 약점·제약 | [확정] ① 마핵이 부서지면 죽음 ② 대죄의 감정에 휘둘리면 판단이 흐려짐 ③ 마계 밖에서는 마기 회복이 느림 — 지구 침공군에게 마정석 보급선이 생명줄. **게이트의 격 제한**: 게이트 크기에 따라 통과 가능한 존재의 격이 정해지며, 지구의 지옥문 게이트는 대부분 작아 **상위 마족까지만** 넘어간다. 마왕이 지구에 가려면 대형 게이트를 새로 열거나 억지로 넓혀야 하므로, 마왕 강림은 신의 본체 강림과 맞먹는 큰 사건이다. 마계 밖에서도 출력 자체는 떨어지지 않는다 |
| 타 차원 힘과의 상성 | [확정] 신력(셀레스티아)과 상극. 마력(엘리시온)은 침식해서 우세하나 **결계·공간 마법에는 침식이 막힌다**. 정령력·천족의 힘과의 상성은 해당 차원 설계 때 정함 |

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 신화 | [확정] 태초의 판데모니움은 끝없는 혼돈이었고, 그 혼돈에서 태어난 마족이 서로를 먹으며 싸웠다. 모든 층을 힘으로 통일한 **원초의 마왕 루시페르**가 죽던 날 그의 마핵이 **일곱 조각**으로 갈라졌고, 조각을 하나씩 먹은 일곱 마족이 첫 칠좌가 됐다. 시신은 코키토스 아래로 가라앉았다. **칠좌의 자리 = 마핵 조각 보유** — 도전 결투에서 이겨 진 마왕의 마핵을 먹으면 조각도 넘어오므로 칠좌는 언제나 정확히 일곱이다. 일곱 조각을 모두 모으면 원초의 마왕에 가까운 힘을 얻는다는 전설이 있다(마왕끼리 노리는 궁극적 이유). 코키토스 바닥의 루시페르는 장기 떡밥(셀레스티아의 크로노드와 짝) |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] 엘리시온을 먼저 노린 침략자. 칠좌가 드물게 손을 잡고, 교차점인 엘리시온을 먹어 모든 차원으로 쳐들어가려 했다. 셀레스티아와 정면으로 부딪혔고 결국 태현에게 둘 다 쫓겨났다. 발타르의 군세 패배, 리제트가 태현과 직접 싸워 패배, **전대 질투의 마왕이 태현에게 쓰러짐** — 태현은 마핵을 먹지 않았고 흩어진 조각을 부하 마공이 먹어 지금의 질투의 마왕이 됐다(마족에게 "군신은 우리와 다른 존재"라는 인식을 남김) |
| 전후 현재 상황 | [확정] 패배의 굴욕과 하극상이 겹쳐 불안정하다. 지구 침공은 마왕들이 실력을 증명하고 몫을 챙기는 무대가 됐다 |

#### 9-3 리제트·발타르 상세 프로필 (기존 06·07에서 이관) [확정]
> 지수는 9-1의 값(리제트 1,300, 발타르 1,100)이 우선한다.

##### 리제트 — 마계 · 칠좌 / 붉은 왕좌

- 나이: **약 400세**; 종족: **상위 마족**; 소속: 마계 **칠좌**, **붉은 왕좌**의 지배자인 마왕.
- 전투: **지수 1,300(9-1에서 조정)**, 강력한 흑염과 심연 계열 마법.
- 외형: 흑발·적안·검은 뿔, 적·흑색 왕좌 복장.
- 성격: 냉혹·오만·집착·소유욕·승부욕. 강한 정치적 야망과 독립적인 목적을 가짐.
- 기술 계열: **흑염**(적의 마력 방어에 간섭하는 화염), **심연 침식**(주변 마력 교란), **전장 제압**(광역 흑염과 진로 봉쇄).
- 강점: 광역 제압·지속 화력·마력 침식. 약점: 정밀 공간·결계 마법에 대한 대응과 과도한 공격 성향. 상대 제어 능력에 따라 침식 저항 가능.
- 과거 **[확정 · D-017]**: 제1차 차원대전에서 태현과 직접 싸워 패배한 마왕. 패배 후에도 굴복하지 않았다.
- 관계 출발: 패배의 굴욕, 숙적 의식, 복수욕과 집착이 뒤섞임. 호감이 생겨도 마왕으로서 지위·영토·야망을 자동으로 버리지 않는다.
- 서사 기능: 마계의 정치·전쟁, 위험한 경쟁과 애정.

##### 발타르 — 칠좌 마왕·심연 군단 지휘자

- 나이: **약 600세**, 종족: **상위 마족**.
- 소속·지위: 마계 **칠좌의 마왕**, **심연 군단 지구 침공 지휘자**. 붉은 왕좌의 지배자인 리제트와는 별개의 칠좌.
- 전력: **지수 1,100(9-1에서 조정)**, 대형 전투 도끼·**암흑 마력·육체 강화·마력 충격파**.
- 외형: 검붉은 머리와 붉은 눈, 검은 갑옷과 뿔.
- 성격: 호전적·잔혹·교활·권력욕이 강함.
- 강점: 전면전, 돌파전, 부대 지휘. 약점: 고도의 공간 제어·원거리 정보전, 군신과의 전력 차.
- 과거: 제1차 차원대전에서 태현의 세력에 패배한 마계 지휘관.
- 현재 기능: 지구를 차지해 세력을 확대하려는 주요 전쟁 적대자. 리제트와 경쟁하며 서로 자동 협력하지 않음.
