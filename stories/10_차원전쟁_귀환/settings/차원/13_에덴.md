## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **천족.** 인간형에 깃털 날개, 머리 위에 빛의 고리 **헤일로**. **날개의 수가 곧 품계.** 헤일로가 핵 역할을 하며 **깨지면 죽는다**. 타락하면 날개가 검게 물들고 헤일로가 검은 고리(**흑륜**)로 변해 한눈에 드러난다. 늙지 않고 수천 년을 산다. **생명의 나무 열매에서만 태어나며** 나무는 몇 년에 한 번 열매를 몇 개만 맺으므로 천족의 수는 거의 늘지 않는다 — 한 명이 타락해 추방될 때마다 종족 전체가 그만큼 줄어든다(순결 강박과 타락 공포의 생존적 이유). 두 장의 날개로 태어나 무거운 맹세를 세우고 지켜 낼 때마다 날개가 늘어난다. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] **세라핌**(6장, 최고 품계 — 씨족장·장로) → **케루빔**(4장, 수호자·전사 — 불타는 검의 문과 성역 수호) → **엔젤**(2장, 일반 천족). 별도로 **흑익**(검게 물든 날개의 타락 천족, 추방된 자 — 날개가 꺾인 채 판데모니움으로 가는 경우가 많다, 사마엘) |
| 동식물·괴수 | [확정] 낙원의 짐승(순백의 사자, 빛의 사슴, 공작 — 모두 온순), 경계 수호수 **불의 뱀**(대륙 가장자리 불의 경계를 지킴, "불타는 뱀" 세라핌 어원 모티프), **금단의 정원의 뱀**(선악의 나무 주변에 사는 뱀, 어디서 왔는지 아무도 모름 — 판데모니움과 이어져 있다는 의심, 떡밥) |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **성력(聖力)** — 헤일로에서 나오며 **맹세를 세우고 지킬수록 강해지고, 어기면 줄어든다**. 지구에 힘을 주는 방식은 **수호 맹세** — 천족이 인간 한 명을 지키겠다고 맹세하면 그 인간에게 성력의 보호가 생긴다(수호천사 모티프, 축복·계약과 함께 세 번째 방식). 천족은 폐쇄적이라 거의 쓰지 않는다 |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): 세라핌 900~1,250 / 케루빔 400~800 / 엔젤 120~350 / 흑익 = 원래 지수 + 마기(타락 직후 잠깐 강해지지만 불안정). 단독 정점 없음. 천족 전체가 수천 명뿐이라 **수는 가장 적고 개체는 고르게 강한** 세력 |
| 고유 능력·마법 계열 | [확정] 공통: 「성광」 정화·치유가 강한 빛 / 「날개 방패」 / 「맹세 각인」 맹세를 성력으로 새겨 지키는 동안 강화 / 「비상」 고속 비행. 고유: 맹세의 내용에 따라 다름(지키는 맹세는 방어, 벌하는 맹세는 공격) |
| 약점·제약 | [확정] ① 헤일로가 깨지면 죽음 ② 맹세를 어기면 힘이 급감하고 흑륜으로 변하기 시작 ③ 마기 오염에 약함. **본거지 밖 제약:** 출력은 유지되지만 **에덴 밖에 오래 머물수록 타락 위험이 커진다**(다른 차원의 욕망과 마기에 노출) — 천족이 에덴을 잘 떠나지 않는 이유 |
| 타 차원 힘과의 상성 | [확정] 마기: 정화하는 힘이라 우세하지만 오염되면 곧 타락(양날의 검). 신력: **천족의 맹세는 신이 강제하는 법칙에 저항한다** — 자기 맹세가 신의 법칙보다 우선하므로 신들이 천족을 사도로 부리지 못했다. 마력(엘리시온): 중립. / 숲의 마력(알프헤임): 친화 — 성력의 정화가 숲을 되살리는 데 도움. / 용력(드라코니아): 중립. |

## 5. 사회·문화
| 항목 | 내용 |

| 정치 체제·지배 구조 | [확정] **천익 연합** — 아홉 씨족의 연합(천사의 아홉 품계 모티프). 각 씨족의 세라핌 씨족장이 맹세의 전당에 모이고, 그중 한 명이 **대세라핌**으로 연합을 대표한다. **의결은 만장일치** — 모두가 맹세해야 구속력이 생기므로 결정이 아주 느리고 결정하지 않는 쪽으로 기울기 쉽다 |
| 계급 | [확정] 날개의 품계. 무거운 맹세를 지켜 내야만 날개가 늘어 올라가고, 타락하면 단번에 추락한다 |
| 경제·화폐 | [확정] 화폐 없음(낙원은 모든 것이 넉넉함). 다만 **생명의 나무 열매(새 천족)를 어느 씨족이 받느냐**가 유일하고 가장 날카로운 정치 문제다 |
| 종교·신앙·가치관 | [확정] 섬기는 신은 없고 **맹세가 곧 신앙**. 가장 높이 치는 것은 순결, 맹세, 누구도 섬기지 않는 자유 |
| 법·관습·금기 | [확정] 맹세의 전당이 정하며 금기를 어기면 추방의 절벽으로 간다. 금기: ① 선악의 나무 열매 ② 맹세를 깨는 것 ③ **신이든 마족이든 누군가를 섬기는 것**(자유를 버리는 일). **추방되면 이름을 빼앗긴다** — 사마엘은 마계에서 새로 받은 이름이며 에덴에서의 본명은 따로 있다 |
| 언어·이름 짓기 규칙 | [확정] 노래하듯 말하는 **성가어**. 이름은 히브리 천사풍으로 "-엘", "-엘라"로 끝난다 |
| 호칭·존칭 | [확정] 세라핌에게 "고귀한 날개여" / 동료끼리 "형제", "자매" / 흑익은 이름 대신 "날개 잃은 자" |
| 의복·건축·음식·일상 | [확정] 의복은 날개가 나오도록 등이 트인 흰 천. 건축은 살아 있는 나무와 수정으로 지은 성채, 덩굴이 벽을 감쌈(셀레스티아의 대리석·황금과 대비). 음식은 과일과 이슬. 일상은 성가, 맹세 의식, 정원 가꾸기, 비행 |

### 아홉 씨족 [확정]
**씨족 이름 = 씨족장 이름.** 각 씨족장은 잘 알려진 대천사의 이름을 그대로 쓴다(미카엘 씨족의 씨족장은 미카엘). 각 씨족은 씨족장의 맹세를 이어 지킨다. 씨족장 상세는 9. 인물.

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 신화 | [확정] 생명의 나무가 처음 열매를 맺었을 때 **최초의 천족 아홉**이 태어나 각자 맹세를 세웠고, 그것이 아홉 씨족의 시작이다. **지금의 씨족장 아홉이 바로 그 최초의 천족들**이며, 늙지 않으므로 태초부터 씨족을 직접 이끌어 왔다(씨족 이름 = 씨족장 이름인 이유) |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] 맹세의 전당이 참전을 논의했으나 만장일치가 안 돼 **공식 중립**. 그러나 **개방파 천족 일부가 개인 자격으로 군신 편에서 싸웠고**, 그중 몇은 전장에서 타락해 돌아오지 못했다 |
| 전후 현재 상황 | [확정] 군신에게 빚이 있다는 개방파와 군신 때문에 동족을 잃었다는 순결파가 갈라져 있고, 만장일치 구조 때문에 어느 쪽도 움직이지 못한다. 대전에서 타락한 천족들(사마엘 외의 흑익)은 판데모니움 쪽 인물로 재등장할 수 있다 |

## 11. 서사 활용
| 항목 | 내용 |

| 이야기에서의 역할 | [확정] ① 태현의 과거를 비추는 거울 — 대전 때 무엇을 청했고 무엇을 잃었는지(타미엘·아바돈이 증인) ② 타락의 서사 — 판데모니움과 이어짐 ③ 교착을 깨는 정치극 ④ 지구 쪽 개인 이야기 — 아리엘라의 수호 맹세. 히로인이 없어 연애 축 없이 빚과 구원의 이야기로 움직인다 |
| 갈등의 씨앗·떡밥 | [확정] 만장일치의 교착(미카엘의 결단, 한 씨족의 이탈, 혹은 태현이 다시 문 앞에 서는 것) / 아리엘라의 수호 맹세(연합의 허락 없이 지구 인간을 지키기로 맹세, 순결파는 타락의 시작으로 봄) / 아바돈과의 재회 / 타락은 되돌릴 수 있나(라파엘은 막 시작된 타락만 가능, 완전 타락자를 되돌리면 에덴의 상식이 뒤집힘) / 사마엘의 본명 "아즈라엘" / 레미엘의 타락 위험 / 우리엘 대 개방파 / 열매 배분 / 금단의 정원의 뱀 |
| 본편 등장 시기 | [확정] 지구 초반: 거의 등장하지 않음 → 서울 게이트 직후: 맹세의 전당 소집, 결정 못함(짧은 장면) → 중반: 아리엘라의 수호 맹세 사건, 판데모니움 쪽 사건 중 아바돈과 재회 → 중후반: **태현이 다시 에덴의 문 앞에 섬**(교착을 깨는 사건) → 후반: 뱀의 정체가 드러나 루시페르와 이어짐 |
| 이 차원의 지켜야 할 규칙 | [확정] 천족은 약 6,000명이고 거의 늘지 않는다 / 에덴 밖에 오래 머물수록 타락 위험 증가 / 천익 연합의 결정은 만장일치 / 완전히 타락한 천족은 원칙적으로 되돌릴 수 없다 / 지구 직결 게이트 없음(엘리시온 경유) / 에덴에는 히로인이 없다 |
| 작가만 아는 진실 | [확정] **금단의 정원의 뱀 = 루시페르가 죽기 직전 자기 마핵에서 떼어 낸 의지의 조각.** 일곱 조각이 칠좌에게 간 것과 별개로 그의 의지는 선악의 나무에 숨어들었고, 천족을 하나씩 타락시켜 루시페르가 깨어날 때 쓸 군대를 만드는 것이 목적이다. 본편에서 천천히 드러낸다 |
