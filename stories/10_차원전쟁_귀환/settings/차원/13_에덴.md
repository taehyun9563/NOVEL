# 13 — 에덴 (천족 차원)

> 구분: 세력 차원
> 상태: **설계 진행 중** (완료: 1~4 — 기본 정보, 환경, 종족·생태, 힘의 체계)

> 표기: [확정] 사용자 승인 / [추천] 제안 / [미정] 미결정

## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | 에덴 / 천족 차원 |
| 한 줄 정체성 | [확정] **누구도 섬기지 않는 천사들의 낙원.** 천족은 신의 종이 아니라 스스로의 맹세로 날개를 지키는 종족이다. 셀레스티아의 사도 제안을 거절한 이유가 곧 종족의 정체성이다 |
| 분위기·톤 | [확정] 고결하고 아름답지만 그 밑에 **순결에 대한 강박**이 있다. 타락을 극도로 두려워해 폐쇄적이고 경직돼 있으며, 마족의 유혹이 통하는 틈도 이 경직에서 나온다 (셀레스티아의 위선, 판데모니움의 욕망과 다른 세 번째 결) |
| 참고 모티프 | [확정] **에덴동산**(낙원) + **천사의 위계**(세라핌·케루빔 같은 품계) + **《실낙원》의 타락 천사** — 판데모니움과 "타락"이라는 주제로 이어진다 |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] 하나의 거대한 낙원 대륙. 사방이 정원이고 가장자리는 높은 벽과 불의 경계로 닫혀 있다. 천족은 높은 산봉우리마다 씨족 성채를 짓고 산다 (셀레스티아의 위로 쌓인 하늘, 판데모니움의 아래로 파고드는 지옥과 다른 "땅 위의 닫힌 낙원") |
| 하늘·빛·기후 | [확정] 영원히 저물지 않는 금빛 오후. 계절이 없고 비 대신 새벽마다 이슬이 내린다 |
| 시간 흐름 (엘리시온 대비) | [확정] 엘리시온과 거의 같다 |
| 특산 자원 | [확정] **두 그루의 나무** — 생명의 나무 열매는 천족이 태어나는 근원, 선악의 나무 열매는 먹으면 타락한다 (에덴동산의 두 나무) |

### 주요 지역·도시·명소
| 이름 | 종류 | 특징 |
| --- | --- | --- |
| 생명의 나무 | 중심 성역 | [확정] 대륙 한가운데의 거대한 나무. 새 천족이 이 나무의 열매에서 태어난다 |
| 금단의 정원 | 봉인 구역 | [확정] 선악의 나무가 있는 출입 금지 구역. 순결 강박의 상징 |
| 불타는 검의 문 | 게이트 | [확정] 에덴의 유일한 관문. 케루빔 품계의 수호자가 불타는 검을 들고 지킨다 (창세기 모티프) |
| 맹세의 전당 | 회의장 | [확정] 천익 연합의 씨족장들이 모이는 곳 |
| 씨족 성채 | 거주지 | [확정] 높은 산봉우리마다 있는 씨족의 성 |
| 추방의 절벽 | 처형장 | [확정] 타락한 천족의 날개를 꺾어 에덴 밖으로 던지는 곳. 쫓겨난 천족을 마족이 거둬들인다(사마엘이 판데모니움으로 간 경로) |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **천족.** 인간형에 깃털 날개, 머리 위에 빛의 고리 **헤일로**. **날개의 수가 곧 품계.** 헤일로가 핵 역할을 하며 **깨지면 죽는다**. 타락하면 날개가 검게 물들고 헤일로가 검은 고리(**흑륜**)로 변해 한눈에 드러난다. 늙지 않고 수천 년을 산다. **생명의 나무 열매에서만 태어나며** 나무는 몇 년에 한 번 열매를 몇 개만 맺으므로 천족의 수는 거의 늘지 않는다 — 한 명이 타락해 추방될 때마다 종족 전체가 그만큼 줄어든다(순결 강박과 타락 공포의 생존적 이유). 두 장의 날개로 태어나 무거운 맹세를 세우고 지켜 낼 때마다 날개가 늘어난다. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] **세라핌**(6장, 최고 품계 — 씨족장·장로) → **케루빔**(4장, 수호자·전사 — 불타는 검의 문과 성역 수호) → **엔젤**(2장, 일반 천족). 별도로 **흑익**(검게 물든 날개의 타락 천족, 추방된 자 — 날개가 꺾인 채 판데모니움으로 가는 경우가 많다, 사마엘) |
| 동식물·괴수 | [확정] 낙원의 짐승(순백의 사자, 빛의 사슴, 공작 — 모두 온순), 경계 수호수 **불의 뱀**(대륙 가장자리 불의 경계를 지킴, "불타는 뱀" 세라핌 어원 모티프), **금단의 정원의 뱀**(선악의 나무 주변에 사는 뱀, 어디서 왔는지 아무도 모름 — 판데모니움과 이어져 있다는 의심, 떡밥) |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **성력(聖力)** — 헤일로에서 나오며 **맹세를 세우고 지킬수록 강해지고, 어기면 줄어든다**. 지구에 힘을 주는 방식은 **수호 맹세** — 천족이 인간 한 명을 지키겠다고 맹세하면 그 인간에게 성력의 보호가 생긴다(수호천사 모티프, 축복·계약과 함께 세 번째 방식). 천족은 폐쇄적이라 거의 쓰지 않는다 |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): 세라핌 900~1,250 / 케루빔 400~800 / 엔젤 120~350 / 흑익 = 원래 지수 + 마기(타락 직후 잠깐 강해지지만 불안정). 단독 정점 없음. 천족 전체가 수천 명뿐이라 **수는 가장 적고 개체는 고르게 강한** 세력 |
| 고유 능력·마법 계열 | [확정] 공통: 「성광」 정화·치유가 강한 빛 / 「날개 방패」 / 「맹세 각인」 맹세를 성력으로 새겨 지키는 동안 강화 / 「비상」 고속 비행. 고유: 맹세의 내용에 따라 다름(지키는 맹세는 방어, 벌하는 맹세는 공격) |
| 약점·제약 | [확정] ① 헤일로가 깨지면 죽음 ② 맹세를 어기면 힘이 급감하고 흑륜으로 변하기 시작 ③ 마기 오염에 약함. **본거지 밖 제약:** 출력은 유지되지만 **에덴 밖에 오래 머물수록 타락 위험이 커진다**(다른 차원의 욕망과 마기에 노출) — 천족이 에덴을 잘 떠나지 않는 이유 |
| 타 차원 힘과의 상성 | [확정] 마기: 정화하는 힘이라 우세하지만 오염되면 곧 타락(양날의 검). 신력: **천족의 맹세는 신이 강제하는 법칙에 저항한다** — 자기 맹세가 신의 법칙보다 우선하므로 신들이 천족을 사도로 부리지 못했다. 마력(엘리시온): 중립. 정령력: 에테리아 설계 때 정함 |
