## 1. 기본 정보

| 고유 이름 / 일반 명칭 | 알프헤임 / 엘프 차원 |
| 한 줄 정체성 | [확정] **끝없는 숲 위에 세워진 오래된 엘프 문명.** 수명이 긴 만큼 모든 것을 기억하는 종족. 한때 차원에서 가장 찬란한 마법 문명이었으나 지금은 서서히 저물어 가는 중(대전 참전으로 많은 동족을 잃은 것도 쇠락의 한 원인) |
| 분위기·톤 | [확정] **아름답고 고요하지만 황혼 같은 쓸쓸함.** 오래된 것을 지키려는 장로들과 바깥으로 나아가려는 젊은 세대(레아)가 부딪힌다. 변하기 싫어하는 것이 아니라, 사라져 가는 것을 알면서 붙잡고 있는 쪽 |
| 참고 모티프 | [확정] **북유럽 신화의 알프헤임**(빛의 엘프의 세계, 이름의 어원) + **톨킨의 엘프**(저물어 가는 오래된 종족, 숲의 왕국) + **켈트의 요정 나라**(시간이 다르게 흐르는 숲) |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] 차원 전체가 **하나의 끝없는 숲.** 높이 수백 미터의 거목 위에 엘프의 도시가 있고 숲 바닥은 어둡고 깊다. **숲의 가장자리부터 서서히 시들어 간다** — 중심은 아직 빛나지만 바깥은 잿빛으로 말라 가는 중(엘프가 저물어 가는 모습이 숲으로 보임) |
| 하늘·빛·기후 | [확정] 숲 사이로 내리는 은은한 빛줄기, 밤에는 다른 차원보다 별이 유난히 밝다(톨킨 엘프의 별빛). 온화하고 계절이 아주 느리게 바뀐다 |
| 시간 흐름 (엘리시온 대비) | [확정] 대체로 엘리시온과 같다. **숲 깊은 성역 안에서만 시간이 느리게 흐른다** — 성역에서 하루를 보내면 바깥에서는 며칠이 지나 있다(켈트 요정 나라) |
| 특산 자원 | [확정] **은목(銀木)** — 마력이 가장 잘 흐르는 은빛 목재, 최고급 활과 지팡이의 재료. 레아의 장궁도 은목 |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **엘프.** 뾰족한 귀, 키가 크고 가냘픈 몸, 늙지 않는 얼굴, 별빛이 비치는 눈동자. 수명 1,000~2,000년, 150세 무렵 성인(레아 180세는 젊은 세대). **아이가 거의 태어나지 않는다** — 한 부부가 수백 년에 한 명을 낳을까 말까 하며, 이것이 쇠락의 가장 큰 이유. 늙어 죽지 않고, 쌓인 기억이 너무 무거워지면 기억의 호수에 기억을 남기고 **숲으로 돌아가 한 그루 나무가 된다** — 알프헤임의 거목은 모두 옛 엘프이고, **잿빛 숲은 조상들이 시들어 가는 것**이다. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] **하이엘프**(왕족과 장로, 별의 숲에 살며 가장 오래 삶) / **숲엘프**(일반 엘프, 레아) / **다크엘프**(그늘 아래에 사는 엘프, 아득한 옛날 빛을 떠나 숲 바닥으로 내려간 분파로 왕국과 오래 반목) / **하프엘프**(엘리시온 인간과의 혼혈, 알프헤임에서는 낮게 대우) |
| 동식물·괴수 | [확정] 숲의 짐승(은빛 사슴, 숲 늑대, 거대한 부엉이), **나무 거인**(오래된 거목이 깨어나 걷는 숲의 수호자, 엘프 조상의 나무가 깨어난 것이라는 말이 있음 — 엔트 모티프), 위험한 존재(그늘 아래의 거대한 거미 떼, 잿빛 숲에서 생겨난 메마른 짐승) |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **숲의 마력** — 엘프는 숲(조상의 나무)에서 힘을 끌어온다. 엘리시온의 마력과 뿌리는 같지만 숲을 거쳐 들어온다. **숲이 시들수록 엘프도 약해진다**(잿빛 숲이 넓어질 때마다 끌어올 힘이 줄어드는 악순환). **다크엘프의 그늘 마법**은 숲 위의 나무가 아니라 **땅속 뿌리에서 직접** 힘을 끌어와(어둠·독·그림자 속 이동) 숲이 시들어도 거의 약해지지 않는다 |
| 경지·등급 | [확정] 나무에 빗댄 경지, 작가용 지수(지구 S급=100, 태현=2,000): **잎** 20~100(갓 성인) / **가지** 100~300(숙련된 전사·마법사) / **줄기** 300~600(왕국의 정예) / **뿌리** 600~1,000(장로와 왕, 레아 670 — 젊은 나이에 뿌리에 이른 드문 경우) |
| 고유 능력·마법 계열 | [확정] 공통: 자연 마법(나무·뿌리·덩굴), 바람 마법, 은목 활 궁술(엘프의 전통), 숲 은신. 장로: **기억 읽기**(기억의 호수에 남은 옛 엘프의 기억을 꺼내 봄). 레아: 초월 궁술, 바람·자연 마법 |
| 약점·제약 | [확정] ① 숲이 시들면 함께 약해짐 ② 근접전에 약함 ③ 수가 적어 잃은 전력을 채우기 어려움. **본거지 밖:** 나무·식물이 있는 곳에서는 힘을 끌어올 수 있지만 식물이 없는 곳에서는 자연 마법 효율이 떨어진다. 바람 마법과 궁술은 어디서든 그대로 |
| 타 차원 힘과의 상성 | [확정] 마기: 약함 — 식물을 썩게 해 힘을 끌어올 곳 자체를 망가뜨림(판데모니움과 적대하는 이유) / 신력: 중립 / 성력: 친화 — 정화의 힘이 숲을 되살리는 데 도움(에덴과 호감인 이유) / 마력: 뿌리가 같아 서로 잘 섞임 |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] **실바린 왕국 하나.** 하이엘프 여왕이 다스리고 별의 숲의 **장로회**가 실권을 쥔다(보수적, 바깥과의 교류를 꺼림). 다크엘프는 왕국에 속하지 않고 그늘 아래에서 무리를 지어 사는, 왕국이 인정하지 않는 집단 |
| 계급 | [확정] 하이엘프 → 숲엘프 → 하프엘프. 다크엘프는 계급 밖 |
| 경제·화폐 | [확정] 엘프끼리는 화폐 없이 나눠 쓴다. 바깥과는 **은목과 약초를 교역**하며 이것이 왕국의 주요 수입 — 엘리시온과의 동맹이 경제적으로도 중요한 이유 |
| 종교·신앙·가치관 | [확정] **조상 숭배** — 숲의 나무가 된 조상을 섬긴다. **"잊히는 것이 진짜 죽음"** — 나무가 되는 것은 끝이 아니며 기억이 사라질 때 비로소 죽는다고 믿어 기억과 전통을 가장 중시한다. 종족이 사라지면 조상을 기억해 줄 이도 사라지므로 쇠락을 그토록 두려워한다 |
| 법·관습·금기 | [확정] 금기: ① **거목을 베는 것**(조상을 죽이는 일, 가장 큰 죄) ② 기억의 호수를 더럽히는 것 ③ 그늘 아래로 내려가 다크엘프와 어울리는 것 |
| 언어·이름 짓기 규칙 | [확정] 바람 소리 같은 속삭임의 엘프어. 이름은 길고 부드러운 소리이며 친한 사이에서는 짧게 줄여 부른다(레아도 긴 본명을 줄인 이름) |
| 호칭·존칭 | [확정] 여왕: "숲의 어머니" / 장로: "장로님" / 장로들이 젊은 엘프를 부를 때: "잎새"(경지 이름과 이어짐) |
| 의복·건축·음식·일상 | [확정] 은빛과 녹색의 옷, 나뭇잎 문양. 거목과 하나가 된 집들을 다리로 잇고, 나무를 자르지 않고 길러서 짓는 것이 원칙(금기 ①과 이어짐). 음식은 과일·꿀·숲 버섯·꽃잎 차. 일상은 노래, 활쏘기, 기억의 호수 참배, 별 보기 |
