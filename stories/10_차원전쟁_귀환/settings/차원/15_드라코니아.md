## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | 드라코니아 / 드래곤 차원 |
| 한 줄 정체성 | [확정] **세상에서 가장 오래된 존재들의 차원.** 신보다, 거신보다, 생명의 나무보다 먼저 있었던 용들이 사는 곳. 너무 강하고 오래 살아서 다른 세계의 다툼에 거의 관심이 없는 절대자들 — 누구에게도 속할 필요가 없어 "독립 동맹"으로 남는다 |
| 분위기·톤 | [확정] **웅장하고 고요하면서 묘하게 느긋한 곳.** 용들은 수천 년을 자고, 보물을 쌓고, 귀찮은 일은 미룬다. 하지만 건드리면 세상이 뒤집힌다(이그나리스의 기질이 용족 전체의 기질) |
| 참고 모티프 | [확정] **서양의 드래곤**(보물을 쌓는 둥지, 화염, 거대한 날개) + **동양의 용**(용궁, 용의 황제 — "용제") |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] **하늘·땅·바다의 세 층.** 하늘을 찌르는 산맥과 화산이 끝없이 이어지고, 위로는 구름바다, 아래로는 깊은 바다. 모든 것이 거대해 인간 크기의 존재가 살 만한 땅은 거의 없다 — 도시나 나라라기보다 **거대한 개인 영역들이 모인 차원**. 화룡은 화산, 천룡은 구름바다, 해룡은 깊은 바다에 산다 |
| 하늘·빛·기후 | [확정] 끝없이 높고 넓은 하늘, 유난히 큰 해, 밤에는 두 개의 달. 기후는 지역마다 극단적이지만 용에게는 문제가 되지 않는다 |
| 시간 흐름 (엘리시온 대비) | [확정] 엘리시온과 같다. 용들은 수천 년을 살아 시간을 아주 느리게 체감한다 |
| 특산 자원 | [확정] **용의 보물** — 수천 년 동안 쌓인 마석·황금·다른 차원의 유물. 판데모니움 탐욕의 마왕(마몬)이 노리는 것 |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **용족.** 세 갈래 — **화룡**(날개 달린 서양 드래곤, 화산), **천룡**(긴 몸으로 하늘을 나는 동양의 용, 구름바다), **해룡**(바다의 용, 용궁). 핵은 **드래곤 하트** — 용마다 하나씩 품은 힘의 심장, 부서지면 죽는다(신핵·마핵·헤일로·마력심과 짝). 마족은 강자의 핵을 먹어 강해지므로 **드래곤 하트는 마족 최고의 먹잇감**이다. 알에서 태어나며 아주 드물어 드라코니아 전체의 용이 수백 마리뿐. **오래 살수록 강해진다**(나이가 곧 힘). 천 년을 넘긴 고룡부터 인간형으로 변할 수 있다. 남녀 모두 있다. 단계: **유룡**(수백 년 미만) → **성룡**(수백~1,000년) → **고룡**(1,000년 이상, 인간형 가능 — 이그나리스 약 1,800세) → **태고룡**(수만 년, 거의 깨어 있지 않은 세상에서 가장 오래된 존재) |
| 하위 종족·계급 | [확정] **용인(龍人)** — 용의 피가 섞인 인간형 종족, 용들을 섬기며 용제산 아래 마을에 모여 산다(드라코니아에서 인간 크기의 장면을 만드는 사람들) / **비룡** — 지능이 낮은 용의 친척, 용인의 탈것 / **드레이크** — 날개 없는 작은 용, 사나운 짐승 |
| 동식물·괴수 | [확정] 거대한 짐승(산만 한 짐승, 구름바다를 헤엄치는 하늘 고래), 해룡의 영역에 사는 거대한 해수들 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **용력(龍力)** — 드래곤 하트가 스스로 만들어 내는 힘, 바깥에서 끌어올 필요가 없다. 신력·마기·마력보다 먼저 있었던 **가장 원초적인 힘**이라 거칠지만 순수하게 강하다 |
| 경지·등급 | [확정] 나이 단계와 같다. 작가용 지수(지구 S급=100, 태현=2,000): **유룡 200~500**(갓 태어나도 지구 S급의 2~5배) / **성룡 500~1,000**(마공·하위 신보다 위) / **고룡 1,000~1,600**(고위 신격·마왕보다 위, 이그나리스 1,500) / **태고룡 2,000~2,500**(주신·벨제부스 위, **태현과 대등하거나 그 이상** — 셋뿐이며 잠들어 있고 세상일에 끼지 않는다) / 용인 50~300 |
| 고유 능력·마법 계열 | [확정] **용의 숨결**(화룡은 불, 천룡은 번개·바람, 해룡은 물·얼음), **용린**(비늘 방어, 마법 저항), 비행, 변신(고룡 이상). **용언(龍言)** — 용이 하는 말 자체가 마법이 된다(고룡이 "타올라라"라고 말하면 그대로 타오름). 이그나리스의 언어 해석 마법도 고룡의 언어 지식에서 나왔다 |
| 약점·제약 | [확정] ① 드래곤 하트가 부서지면 죽음 ② 몸이 커서 좁은 곳에서 불리 ③ 오래 잠들어 반응이 느림 ④ 보물에 대한 집착. **본거지 밖:** 드래곤 하트가 스스로 힘을 만들어 **어디서든 출력이 그대로**다. 대신 용형은 너무 커서 일반 게이트를 지나지 못해 **다른 차원에서는 인간형으로 다녀야 하고**, 인간형에서는 용의 숨결 같은 광역 공격이 크게 줄어든다 |
| 타 차원 힘과의 상성 | [확정] 신력: **신의 법칙에 덜 얽매인다** — 신보다 오래된 힘이라 신역 전개의 영향을 적게 받는다(셀레스티아가 함부로 못 건드리는 이유) / 마기: 드래곤 하트가 침식에 강하지만 마족은 그 하트를 먹으려 노린다 / 성력: 중립 / 마력: 용력이 더 원초적이라 우세 / 숲의 마력: 중립 / 야성(페럴리아): 수인은 용 앞에서 본능적으로 위축된다. |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] **용제** — 용들은 저마다 독립적이라 누구의 지배도 받지 않으므로, 용제는 다스린다기보다 **용들 사이의 분쟁을 중재하고 바깥에 드라코니아를 대표하는 자리**다. 태고룡들이 인정한 고룡이 맡는다(이그나리스는 1,800세로 아주 젊은 용제). **용회(龍會)** — 수백 년에 한 번 열리는 용들의 회의(모이는 것 자체가 귀찮아 잘 열리지 않음). **용인 사회** — 용제산 아래 마을에 모여 살며 외교·교역 같은 실무를 맡는다 |
| 계급 | [확정] **나이가 곧 지위** — 태고룡 → 고룡 → 성룡 → 유룡 → 용인 |
| 경제·화폐 | [확정] **보물이 곧 위신** — 보물을 쌓을수록 존경받는다. 바깥과의 교역은 용인이 맡고, 엘리시온과는 마석·희귀 광물을 거래한다 |
| 종교·신앙·가치관 | [확정] 섬기는 신이 없다(신보다 오래된 존재). 자유와 긍지. **"용언으로 한 말은 되돌릴 수 없다"** — 말이 곧 마법이라 용은 함부로 약속하지 않고, 한번 약속하면 반드시 지킨다 |
| 법·관습·금기 | [확정] 금기: ① 다른 용의 보물 동굴에 들어가는 것 ② **동족의 드래곤 하트를 사냥하는 것** ③ 잠든 태고룡을 깨우는 것 |
| 언어·이름 짓기 규칙 | [확정] 용언(고대 용의 언어). 이름은 원소의 뜻을 담은 라틴풍(이그나리스는 라틴어 "불"에서 온 이름) |
| 호칭·존칭 | [확정] 용제: "용제 폐하" / 태고룡: "어르신" / 용인이 섬기는 용에게: "주인" |
| 의복·건축·음식·일상 | [확정] 용형일 땐 옷이 없고, 인간형일 때는 화려하고 비싼 옷을 즐긴다. 용인 마을은 화산석과 용 비늘로 장식한 건물. 용은 드래곤 하트의 힘으로 살아 거의 먹을 필요가 없으므로 **먹는 것은 순전히 즐거움**(이그나리스가 과자와 차를 좋아하는 이유). 일상은 잠, 보물 감상, 비행, 수집 |

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 신화 | [확정] 세상에 아무것도 없던 혼돈 속에서 **태고룡들이 가장 먼저 눈을 떴다** — 거신보다, 신보다, 생명의 나무보다 먼저. 용들은 자신들을 "세상이 생겨나는 걸 지켜본 자들"이라 믿는다 |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] 판데모니움이 엘리시온을 침공하며 드라코니아에도 손을 뻗었다(그을린 계곡). 전대 용제와 태고룡들은 깨어나지 않았고, **젊은 고룡 이그나리스가 혼자 나서서 드라코니아를 지켜 냈으며** T+8~12에 태현과 손잡았다. 공식적으로는 이그나리스 개인이 이끈 방어전과 동맹이었고 대부분의 용은 끝까지 잠들어 있었다. **이그나리스의 용언: "네가 부르면, 나는 단 한 번 무엇이든 응한다."** — 용언이라 절대 되돌릴 수 없고, 용제가 된 지금은 드라코니아 전체가 이 약속에 묶여 있다. **태현은 아직 이 약속을 쓰지 않았다** |
| 전후 현재 상황 | [확정] T+20 종전 때 잠깐 깨어난 태고룡들이 이그나리스를 새 용제로 인정했고, 전대 용제는 용의 무덤으로 떠나 잠들었다(용왕은 반발). 엘리시온과 독립 동맹을 맺고 이그나리스가 엘리시온 별궁에 머물기 시작했다. 젊은 용제와 반발하는 용왕, 지구에 눈독 들이는 탐욕파로 오랜만에 시끄러워지는 중 |

##### 2. 외형

- **인간형:** 붉은빛이 도는 긴 머리카락, 황금빛 눈, 우아하고 늘씬한 체형. 평소에는 활동하기 편하면서도 고급스러운 옷을 즐겨 입는다. 굳이 용제의 위엄을 과시하지 않아도 존재감이 강하다.
- **본래 용형:** 거대한 몸체에 **진홍빛 비늘**, 황금빛 눈과 날개, 날카로운 발톱. 비늘은 단단하고 마력 저항이 높다. 세부 뿔 개수나 체장 같은 숫자는 본편에서 불필요하게 고정하지 않는다.
- **변신:** 평소에는 인간형으로 활동한다. 인간형에서도 높은 수준의 마력과 신체 강화를 쓸 수 있으며, 본래 용형은 비행·내구·광역전에서 더 유리하다.
- **게이트 통행:** 일반 크기의 서울 게이트에는 인간형으로 이동 가능하며, 거대한 용형을 억지로 통과시키는 연출을 하지 않는다(D-022).

##### 3. 성격과 말투

- **평소:** 게으르고 느긋하다. 독서, 과자, 차, 낮잠을 즐기며 중요하지 않은 업무는 귀찮아한다. 장난과 농담을 좋아하고 가까운 사람을 놀리기도 한다.
- **군주로서:** 드라코니아의 안전과 독립이 걸리면 태도가 급변한다. 냉정하고 계산적이며, 필요하면 동맹에게도 반대한다.
- **자존심:** 자신이 용제임을 정확히 인식하지만 사적인 자리에서는 직위로 거리를 두려 하지 않는다. 존중받기를 바라되 맹목적 복종을 요구하지 않는다.
- **태현 앞에서:** 군신을 "꼬마"라 부르는 오랜 친구(이름은 엘리시아만 부른다). 농담으로 보상을 요구하거나 투덜거리면서도 부탁의 중요성은 판단한다. 진지한 장면에서 무조건 가볍게 굴지는 않는다.
- **말투:** 가깝고 여유로운 반말, 장난스러운 질문이 많다. 외교·군사적으로 중요한 자리에선 권위 있고 단호해진다. 단순한 개그 캐릭터로 축소하지 않는다.

##### 4. 전투 능력 상세

**전력 위상:** 신계 고위 신격·칠좌 마왕보다 높은 개인 전투력이나, 주신과 군신 박태현보다 약하다. 지수는 승패 자동 판정이 아닌 작가용 상대 척도(D-020).

### ① 고룡의 육체·마력
- 태생적인 근력·내구력·비행 능력과 막대한 마력을 갖추었다.
- 인간형에서는 힘을 절제하여 정밀하게 싸우며, 용형에서는 신체전·넓은 전장을 활용한다.
- 자동 불사·무한 재생·상대 공격 완전 무효 같은 절대 효과는 없다.

### ② 고위 원소 마법
- **화염 중심**, 상황에 따라 번개·바람 등 여러 원소 마법을 응용한다.
- 넓은 지역에 높은 출력을 지속할 수 있어 다수전·장기전에 강하다.
- 태현의 전능 마법형처럼 모든 계통을 동일한 숙련도로 자유자재 구사하지는 않는다.
- **리제트와 차별점:** 고룡의 원소 화염을 사용하며, 리제트의 흑염·심연 침식 능력을 공유하지 않는다.

### ③ 용의 숨결
- 본래 용형에서 대량의 마력을 집중해 방출하는 고화력 광역 공격이다.
- 거대 마물과 병력 밀집지역, 견고한 방어진 등 넓은 전장에 특히 강하다.
- 선행 동작과 피해 범위가 뚜렷하여 민간인·아군이 섞인 구역에서는 무턱대고 사용하지 않는다.
- 인간형에서도 고화력 마법은 가능하지만 본래 용형과 같은 광역 제압이 언제나 가능한 것은 아니다.

### ④ 용린 방어·마력 저항
- 강인한 비늘과 마력으로 물리 공격과 상당수 마법을 견뎌 낸다.
- 복잡한 공간 간섭, 상위권의 특수 공격, 압도적인 출력 등에는 피해를 입을 수 있다.
- 마법 완전 면역이나 무적의 방어막은 아니다.

### ⑤ 언어 해석 마법 — 비전투 전문성
- **고룡의 광범위한 언어 지식**과 **발화·문자의 문법 및 의미를 분석하는 마법**을 결합한다.
- 말소리·문장·상황 맥락의 표본이 늘어날수록 이해와 실제 통역의 정확도가 높아진다.
- **제한:** 마음 읽기·기억 열람·거짓말 자동 감별·문화 지식 즉시 완벽 습득은 불가능하다. 정치·법률·기술 용어는 추가 확인이 필요할 수 있다.
- 특정 신분만 통역 가능한 것도 아니고, 신규 초월 등급이나 별도 능력 체계를 만드는 마법도 아니다.

##### 6. 태현과의 과거

- **첫 인연:** 엘리시온으로 넘어온 지구 인간 태현을 흥미로운 존재로 보았다. 처음부터 그가 군신이 될 것이라고 확신한 것은 아니었다.
- **제1차 차원대전:** 드라코니아를 지키려는 이해관계 아래 태현과 협력했다. 전쟁을 거치며 태현이 신계·마계의 군세를 물리치는 모습을 목격하고 강자로 인정했다.
- **전쟁 종결 이후:** 드라코니아와 태현의 군신 진영은 **독립된 우호 동맹**이 되었다. 정치적 지위를 떠나 서로의 사적인 모습까지 아는 관계로 발전했다.
- **신뢰:** 태현에게 친근하게 농담할 수 있는 몇 안 되는 존재이며, 태현 또한 장난에 가려진 용제의 판단력과 실력을 알고 있다.
- **감정선 시작:** 오랜 친밀감·호감과 특별한 관심이 있으나 사랑을 공식적으로 표현하거나 교제한 적은 없다. 태현을 지나치게 소유하려 하기보다 **서로 자유로운 독립 군주라는 관계**를 존중한다. 사랑으로 발전할지는 본편과 RP에 따른다.

##### 7. 현재의 관계와 서사 기능

- **태현:** 오랜 동맹이자 친한 친구. 군신으로서의 태현을 존중하지만 사적으로는 "꼬마"라 부르며 장난친다.
- **엘리시아:** 군신 궁정의 실무 책임자와 외부 독립 군주의 관계. 실무에선 서로의 유능함을 인정하고, 평소 이그나리스의 게으름에 엘리시아가 잔소리할 수 있다.
- **레아:** 오래 알고 지낸 엘프 지휘관과 용제. 편하게 농담하며, 각자의 국가와 종족을 대표한다는 공통점이 있다.
- **정치적 역할:** 드라코니아의 자치와 안전을 대표한다. 군신의 결정에 무조건 따라가거나 전쟁에 자동 참전하지 않는다.
- **전투 서사:** 용족 최상위 강자이자 대규모 전장 전력으로 활용한다. 본격적인 개입·군세 파견과 지구 이동 등 중요 선택은 사용자 RP와 사건 인과를 따른다.
- **관계 서사:** 엘리시아의 오래된 헌신, 레아의 전우애, 세라피나의 신계 소속, 리제트의 숙적 구도와 구별되는 **군주 사이의 오래된 친밀감과 유쾌한 애정**.
