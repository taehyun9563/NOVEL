| 한 줄 정체성 | [확정] **수많은 부족이 살아가는 야생의 차원.** 개개인은 강하지만 하나로 뭉치지 못해, 오랫동안 다른 차원들에 사도로(셀레스티아), 용병으로(판데모니움·엘리시온), 신도로(드라코니아) 이용당해 왔다. 페럴리아가 하나로 뭉치는 순간이 차원 전쟁의 판을 바꾸는 사건이 될 수 있다 |
| 분위기·톤 | [확정] **거칠고 생명력 넘치는 야생** — 사냥과 축제, 부족끼리의 결투와 우정. 그 밑에 "왜 우리는 늘 남의 전쟁에서 피를 흘리는가"라는 분노가 깔려 있다. 고귀하거나 오래된 존재들의 다른 차원과 달리 땅에 발을 딛고 사는 생생한 종족 |
| 참고 모티프 | [확정] **초원의 유목 부족 연맹**(칸을 중심으로 뭉치는 부족들) + **짐승의 왕 전설**(가장 강한 짐승이 왕이 됨) + 판타지의 수인 부족 |

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **수인.** 평소에는 인간의 몸에 짐승의 귀·꼬리·눈·발톱. 강한 전사는 **수화(獸化)**해 짐승에 가까운 모습으로 바뀌며, 보름달 밤에 가장 강해진다. 핵은 **수혼(獸魂)** — 짐승의 영혼이 깃든 심장, 강한 전사일수록 짙다(헬리아가 사도로 거두는 것, 마족이 먹고 싶어 하는 것). 수명 약 100년, 강한 전사는 200년. **아이가 많이 태어난다**(엘프·용과 정반대 — 다른 차원들이 "얼마든지 데려다 써도 되는 종족"으로 취급해 온 이유이자 페럴리아의 분노). 사냥과 결투로 강해지며 **성인식은 혼자서 거대한 짐승을 사냥하는 것**. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] **부족:** 늑대족(북부 설원, 무리 전투·충성) / 곰족(북부 설원, 힘과 맷집) / 사자족·호랑이족(밀림, 자존심·싸움을 좋아함, 칸을 가장 많이 배출) / 뱀족·도마뱀족(밀림, 독과 은신) / 여우족(남부 사막, 꾀·장사, 바깥과의 교역) / 하이에나족(남부 사막, 거칠고 뒤끝, 용병으로 가장 많이 나감) / 독수리족·매족(하늘 산맥, 날개, 정찰·공중전) / 사슴족·토끼족(대초원, 약하지만 수가 가장 많고 빠름, 연맹의 살림). **계급:** 칸 → 부족장 → 전사(성인식 통과) → 사냥꾼(성인식 전). **반수(半獸)** — 다른 종족과의 혼혈, 네르가(마족과의 혼혈)처럼 부족에서 밀려나는 경우가 많다 |
| 동식물·괴수 | [확정] 거대한 짐승(매머드, 거대한 들소 떼, 검치호 — 성인식의 사냥감), 하늘 산맥의 거대 독수리, 사막의 거대 전갈 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **야성(野性)** — 수혼에서 나오는 짐승의 힘. 마법이 아니라 **몸 그 자체가 무기**라 어느 차원에서든 바로 쓸 수 있는 전력이 된다(용병으로 쓰기 좋은 이유). **보름달**: 모든 수인이 약 30% 강해지고 수화가 가장 쉬워진다. 달이 뜨는 엘리시온·지구에서도 같으나, **달이 없는 셀레스티아와 판데모니움에서는 수화가 약해진다** |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): **사냥꾼** 20~80(성인식 전) / **전사** 80~250(웬만한 전사가 지구 S급과 비슷) / **용사** 250~500(부족의 이름난 전사) / **대족장** 500~900(강한 부족의 우두머리) / **짐승의 왕** 900~1,300(역대 칸 중 손꼽히는 자들) |
| 고유 능력·마법 계열 | [확정] 공통: 신체 강화(근력·속도·재생), 짐승의 감각(후각·청각·어둠 속 시야), **수화**(짐승에 가까운 모습, 힘이 크게 오름), **포효**(아군 고양·적 위축). 부족 고유: 늑대족은 무리 지어 싸울수록 강해지고, 독수리족은 날고, 뱀족은 독, 여우족은 눈속임. **주술사**: 드물게 조상 짐승의 영혼을 부르는 자들(용의 제단 사제 포함), 페럴리아에서 마법에 가장 가까운 힘 |
| 약점·제약 | [확정] ① 수혼이 부서지면 죽음 ② 마법과 원거리 공격에 약함 ③ **수화하는 동안 이성이 흐려져 폭주할 위험** ④ 부족끼리 뭉치지 못함. **본거지 밖:** 몸의 힘이라 어디서든 출력이 그대로, 달의 영향만 받는다 |
| 타 차원 힘과의 상성 | [확정] 신력: 중립 / 마기: **수혼이 마기에 쉽게 물든다**(반마·타락한 수인이 생기기 쉽고, 판데모니움이 수인을 고용하는 이유) / 성력: 중립 / 마력: 마법에 약해 열세 / 숲의 마력: 중립(사냥 문제로 엘프와 부딪힘) / 용력: **본능적으로 위축된다**(일부 부족이 용을 신처럼 섬기는 이유) |

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] **바르칸 연맹** — 부족마다 자치하고 연맹 전체의 우두머리로 **칸**을 둔다. 칸은 칸의 언덕에서 부족장들이 뽑고, 뜻이 갈리면 **결투로 정한다**. 전쟁 때는 절대적이지만 평소에는 약해 연맹은 지금 느슨하게 흩어져 있다 |
| 계급 | [확정] 칸 → 부족장 → 전사 → 사냥꾼. 강함이 먼저지만 출신 부족의 자존심도 크다. 반수는 차별받는다 |
| 경제·화폐 | [확정] 물물교환과 전리품. 여우족이 엘리시온과 교역(가죽·뼈 ↔ 금속·곡물). **젊은 전사를 용병으로 내보내고 돈을 받는 부족도 있으며**, 연맹 안에서 가장 논쟁이 되는 일이다 |
| 종교·신앙·가치관 | [확정] 조상 짐승의 영혼(토템)과 **달의 어머니**를 섬기며, 일부 부족은 용을 신처럼 섬긴다. 힘, 명예, 그리고 **"무리를 버리지 않는다"** — 돈을 받고 남의 전쟁에 나간 용병은 "무리를 버린 자"라는 손가락질을 받기도 한다 |
| 법·관습·금기 | [확정] 금기: ① 같은 부족의 등에 칼을 꽂는 것 ② 성인식을 치르지 않고 전사를 자처하는 것 ③ **죽은 전사의 수혼을 남에게 넘기는 것**. **불의 장례** — 죽은 전사의 시신을 태워 수혼을 하늘로 보낸다. 헬리아가 영혼을 거둬 사도로 끌고 가지 못하게 하려는 것(셀레스티아에 대한 원한이 풍습이 됨) |
| 언어·이름 짓기 규칙 | [확정] 부족어와 수인 공용어. 이름은 짧고 강하며 뒤에 부족 이름이 붙고(예: 늑대족의 가룸), 큰 사냥을 하면 업적이 별명으로 붙는다(예: 검치호를 쓰러뜨린 자) |
| 호칭·존칭 | [확정] 칸: "대칸" / 부족장: "족장" / 존중하는 전사: "용사여" / 같은 부족끼리: "무리" |
| 의복·건축·음식·일상 | [확정] 가죽과 뼈로 만든 옷, 사냥한 짐승의 이빨·뼈를 몸에 걸쳐 업적을 드러낸다. 대초원은 천막, 설원은 얼음과 가죽의 집, 밀림은 나무 위의 집. 고기 위주, 큰 사냥이 끝나면 부족 전체의 축제. 일상은 사냥, 결투, 축제, 모닥불 앞의 노래 |

## 7. 역사

## 10. 태현과의 연결
| 항목 | 내용 |
| --- | --- |
| 30년 동안 얽힌 사건 | [확정] T+3 태현이 처음 들어간 용병단에 사자족 전사 사르한(과 로빈)이 있었고, **마력도 없던 태현을 사르한이 전장에서 지켜 줬다** / T+5 무렵 힘을 얻기 시작한 태현이 반대로 사르한의 목숨을 구하며 대등한 전우가 됨 / T+8 무렵 태현이 이름을 떨치며 용병단을 떠나고 사르한은 용병으로 남음 / 대전 중 **판데모니움 쪽 수인 용병들과 맞닥뜨렸을 때 태현이 그들을 죽이지 않고 돌려보냄**(수인끼리 죽이는 걸 보고 싶지 않았다) / T+22 사르한이 칸이 되자 태현이 직접 칸의 언덕을 찾아가 축하 |
| 이 차원이 군신을 보는 시선 | [확정] **"용병에서 황제가 된 자"**, 그리고 적이던 수인 용병까지 살려 보낸 일로 **"용병을 버리지 않은 자"**("무리를 버리지 않는다"는 가치관과 이어짐, 판데모니움의 "핵을 버린 자"와 짝). 사르한: 옛 친구, 지금도 용병 시절 별명 **"이방인"**으로 부름(이름은 부르지 않음) / 가룸과 통합파: 수인이 갈 수 있는 가장 높은 곳까지 간 사람으로 존경 / 펜릴과 고립파: 결국 엘리시온의 왕일 뿐이라는 경계 / 라쉬카와 용병파: 군신의 땅을 지나야 지구로 갈 수 있으니 기회 / 베로스와 용 신앙파: 용제의 동맹이라 존중 / 하이에나족: 대전 때 살려 보내 준 은혜로 복잡 / 아라: 아버지 이야기 속 영웅을 동경 |

## 11. 서사 활용
| 항목 | 내용 |
| --- | --- |
| 이야기에서의 역할 | [확정] ① 숨은 최대 전력 — 뭉치면 어느 차원보다 많은 전사, 어느 편에 서느냐가 판을 바꿈 ② 태현의 과거를 비추는 거울 — 마력 없던 용병 시절을 아는 곳 ③ 지구와의 연결 — 수인 용병, 지구에 가고 싶어 하는 아라 ④ 내부 정치 — 통합·용병·고립·용 신앙파. 히로인이 없으며 사르한과의 **우정**이 감정의 중심 |
| 갈등의 씨앗·떡밥 | [확정] **연맹의 통합**(사르한이 해낼까, 무엇이 계기인가) / **우정과 원칙**(태현이 차원 전쟁에서 수인의 힘을 빌려야 할 때, "남의 전쟁에서 피 흘리지 않겠다"고 맹세한 칸에게 옛 친구가 도움을 청하는 순간) / 펜릴의 도전(칸의 언덕에서 결투) / 라쉬카의 배신(검은 관문·마몬·지구 흑월 길드와 손잡고 수인 용병을 몰래 지구로) / 아라의 지구행(**드라코니아의 칼로르와 지구에서 마주침** — 바깥으로 나간 두 젊은 세대) / **사도가 된 옛 전우들**(헬리아가 거둔 수인 전사들이 셀레스티아 사도로 나타나 사르한의 옛 동료가 적으로 섬 — 분노가 셀레스티아로 향하고 연맹을 묶는 계기가 될 수 있음) / 타락한 수인 |
| 본편 등장 시기 | [확정] 초반: 카르테라의 수인 상인과 용병들(미호·라쉬카의 사람들) → 중반: 사르한 등장, 아라의 지구행, 라쉬카의 배신 → 후반: 연맹의 통합, 페럴리아가 어느 편에 서느냐 |
| 이 차원의 지켜야 할 규칙 | [확정] 수인의 힘은 몸의 힘, 달이 없는 차원에서는 수화가 약해진다 / 죽은 전사는 불의 장례로 보낸다 / 사르한은 태현을 "이방인"이라 부른다 / 페럴리아의 관문은 엘리시온으로만 이어진다 / 페럴리아에는 히로인이 없다 |
