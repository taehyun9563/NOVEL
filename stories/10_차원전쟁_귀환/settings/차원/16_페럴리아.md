## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | 페럴리아 / 수인 차원 |
| 한 줄 정체성 | [확정] **수많은 부족이 살아가는 야생의 차원.** 개개인은 강하지만 하나로 뭉치지 못해, 오랫동안 다른 차원들에 사도로(셀레스티아), 용병으로(판데모니움·엘리시온), 신도로(드라코니아) 이용당해 왔다. 페럴리아가 하나로 뭉치는 순간이 차원 전쟁의 판을 바꾸는 사건이 될 수 있다 |
| 분위기·톤 | [확정] **거칠고 생명력 넘치는 야생** — 사냥과 축제, 부족끼리의 결투와 우정. 그 밑에 "왜 우리는 늘 남의 전쟁에서 피를 흘리는가"라는 분노가 깔려 있다. 고귀하거나 오래된 존재들의 다른 차원과 달리 땅에 발을 딛고 사는 생생한 종족 |
| 참고 모티프 | [확정] **초원의 유목 부족 연맹**(칸을 중심으로 뭉치는 부족들) + **짐승의 왕 전설**(가장 강한 짐승이 왕이 됨) + 판타지의 수인 부족 |

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] **문명의 손이 닿지 않은 끝없는 야생 대륙.** 가운데 대초원, 둘레로 밀림·설원·사막·산맥이 펼쳐지고 지형마다 그 땅에 맞는 부족이 산다 |
| 하늘·빛·기후 | [확정] 해와 달이 뜨는 하늘. **달이 유난히 크고, 보름달 밤에는 수인의 힘이 가장 세진다**(늑대인간 모티프). 기후는 지역마다 거칠고 극단적 |
| 시간 흐름 (엘리시온 대비) | [확정] 엘리시온과 같다 |

| 야수의 관문 | 게이트 | [확정] 엘리시온으로 이어지는 관문 |

- **수인이 다른 차원에 쓰이는 경로**(모든 관문은 엘리시온 경유): 엘리시온·판데모니움 — 야수의 관문으로 엘리시온에 나가 용병이 되며, 판데모니움은 엘리시온의 밀수 조직(검은 관문)을 거쳐 고용한다 / 셀레스티아 — 전장에서 죽은 강한 수인 전사의 영혼을 헬리아가 거둬 사도로 만든다("죽어서도 남의 전쟁에 끌려간다"는 원한) / 알프헤임 — 수인 사냥꾼들이 엘리시온을 거쳐 알프헤임 숲까지 원정 사냥을 가 엘프와 마찰

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **수인.** 평소에는 인간의 몸에 짐승의 귀·꼬리·눈·발톱. 강한 전사는 **수화(獸化)**해 짐승에 가까운 모습으로 바뀌며, 보름달 밤에 가장 강해진다. 핵은 **수혼(獸魂)** — 짐승의 영혼이 깃든 심장, 강한 전사일수록 짙다(헬리아가 사도로 거두는 것, 마족이 먹고 싶어 하는 것). 수명 약 100년, 강한 전사는 200년. **아이가 많이 태어난다**(엘프·용과 정반대 — 다른 차원들이 "얼마든지 데려다 써도 되는 종족"으로 취급해 온 이유이자 페럴리아의 분노). 사냥과 결투로 강해지며 **성인식은 혼자서 거대한 짐승을 사냥하는 것**. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] **부족:** 늑대족(북부 설원, 무리 전투·충성) / 곰족(북부 설원, 힘과 맷집) / 사자족·호랑이족(밀림, 자존심·싸움을 좋아함, 칸을 가장 많이 배출) / 뱀족·도마뱀족(밀림, 독과 은신) / 여우족(남부 사막, 꾀·장사, 바깥과의 교역) / 하이에나족(남부 사막, 거칠고 뒤끝, 용병으로 가장 많이 나감) / 독수리족·매족(하늘 산맥, 날개, 정찰·공중전) / 사슴족·토끼족(대초원, 약하지만 수가 가장 많고 빠름, 연맹의 살림). **계급:** 칸 → 부족장 → 전사(성인식 통과) → 사냥꾼(성인식 전). **반수(半獸)** — 다른 종족과의 혼혈, 네르가(마족과의 혼혈)처럼 부족에서 밀려나는 경우가 많다 |
| 동식물·괴수 | [확정] 거대한 짐승(매머드, 거대한 들소 떼, 검치호 — 성인식의 사냥감), 하늘 산맥의 거대 독수리, 사막의 거대 전갈 |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **야성(野性)** — 수혼에서 나오는 짐승의 힘. 마법이 아니라 **몸 그 자체가 무기**라 어느 차원에서든 바로 쓸 수 있는 전력이 된다(용병으로 쓰기 좋은 이유). **보름달**: 모든 수인이 약 30% 강해지고 수화가 가장 쉬워진다. 달이 뜨는 엘리시온·지구에서도 같으나, **달이 없는 셀레스티아와 판데모니움에서는 수화가 약해진다** |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): **사냥꾼** 20~80(성인식 전) / **전사** 80~250(웬만한 전사가 지구 S급과 비슷) / **용사** 250~500(부족의 이름난 전사) / **대족장** 500~900(강한 부족의 우두머리) / **짐승의 왕** 900~1,300(역대 칸 중 손꼽히는 자들) |
| 고유 능력·마법 계열 | [확정] 공통: 신체 강화(근력·속도·재생), 짐승의 감각(후각·청각·어둠 속 시야), **수화**(짐승에 가까운 모습, 힘이 크게 오름), **포효**(아군 고양·적 위축). 부족 고유: 늑대족은 무리 지어 싸울수록 강해지고, 독수리족은 날고, 뱀족은 독, 여우족은 눈속임. **주술사**: 드물게 조상 짐승의 영혼을 부르는 자들(용의 제단 사제 포함), 페럴리아에서 마법에 가장 가까운 힘 |
| 약점·제약 | [확정] ① 수혼이 부서지면 죽음 ② 마법과 원거리 공격에 약함 ③ **수화하는 동안 이성이 흐려져 폭주할 위험** ④ 부족끼리 뭉치지 못함. **본거지 밖:** 몸의 힘이라 어디서든 출력이 그대로, 달의 영향만 받는다 |
| 타 차원 힘과의 상성 | [확정] 신력: 중립 / 마기: **수혼이 마기에 쉽게 물든다**(반마·타락한 수인이 생기기 쉽고, 판데모니움이 수인을 고용하는 이유) / 성력: 중립 / 마력: 마법에 약해 열세 / 숲의 마력: 중립(사냥 문제로 엘프와 부딪힘) / 용력: **본능적으로 위축된다**(일부 부족이 용을 신처럼 섬기는 이유) |
