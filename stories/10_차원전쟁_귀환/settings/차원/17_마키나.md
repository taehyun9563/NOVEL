# 17 — 마키나 (기계 차원)

> 구분: 적대 차원 (연결망 바깥)
> 상태: **설계 중** — 카테고리 하나씩 진행
> 표기: [확정] 사용자 승인 / [추천] 제안 / [미정] 미결정

## 1. 기본 정보
| 항목 | 내용 |
| --- | --- |
| 고유 이름 / 일반 명칭 | [확정] 마키나 / 기계 차원 |
| 한 줄 정체성 | [확정] **마력을 다 퍼 써서 말라 버린 세계 위에 선 강철 제국.** 한때 마도 공학으로 연결망 바깥에서 가장 번성했지만, 제 세계의 마력을 바닥까지 긁어 쓰고 지금은 다른 세계의 마력을 퍼 올리려 한다 |
| 분위기·톤 | [확정] **차갑고 거대한 산업의 위압감, 그 아래의 절박함.** 매연과 강철, 쉬지 않는 공장의 소리. 악당이 아니라 죽어 가는 세계를 살리려는 쪽이라 침공에 망설임이 없다 |
| 참고 모티프 | [확정] **디젤펑크·스팀펑크**(거대 기계, 증기와 매연) + **바벨탑**(하늘에 닿으려다 무너진 오만) + **자원 고갈과 식민지 수탈**(제 땅이 마르자 남의 땅으로 가는 제국) |

- 연결망 일곱 차원은 모두 마력이 있는 세계다. 마키나는 **마력이 없어 마력을 빼앗으러 오는** 첫 적이다. 엘리시온(대기 마력이 가장 짙음)이 1순위 표적이고, 지구는 그 길목이다.
- 태현도 이 세계를 모른다.

## 2. 환경
| 항목 | 내용 |
| --- | --- |
| 구조 (행성·대륙·층·부유섬 등) | [확정] 행성 하나. 지표는 마력이 빠져나가 회색 결정처럼 굳은 **백화(白化) 대지**. 사람들은 매연 위로 솟은 **탑도시**에 모여 산다 — 아래층일수록 가난하고 죽은 땅에 가깝다(바벨탑 모티프) |
| 하늘·빛·기후 | [확정] 하늘은 늘 매연층에 덮여 해는 탑 꼭대기에서나 보인다. 춥고 산성비가 내린다 |
| 시간 흐름 (엘리시온 대비) | [확정] 지구와 이어진 순간부터 엘리시온과 같은 속도(지구 규칙과 동일) |
| 특산 자원 | [확정] **흑강(黑鋼)** — 마력을 튕겨 내는 강철. 마법은 잘 먹히지 않지만 칼·물리 공격에는 보통 강철과 같다. 엘리시온의 마법 전력에 대한 위협 |

### 주요 지역·도시·명소
| 이름 | 종류 | 특징 |
| --- | --- | --- |
| 탑도시 바벨 | 수도 | [확정] 가장 높은 탑. 꼭대기에 지배층이 있다 |
| 백화 지대 | 죽은 땅 | [확정] 마력이 다 빠진 지표. 해마다 탑도시 쪽으로 넓어진다 |
| 흡마갱(吸魔坑) | 채굴장 | [확정] 땅에서 마력을 빨아올리던 거대한 구덩이들, 이제는 거의 말랐다. **이것을 엘리시온에 세우는 것이 마키나의 목표** — 세운 땅은 백화된다 |
| 지구행 게이트 | 게이트 | [확정] 지구의 **안정 이세계 게이트** 중 하나. 3년 동안 지구와 교역해 온 통로 |

### 지구와의 관계 (환경 단계에서 확정)
- [확정] 지구는 3년 동안 마키나를 **기술이 뛰어난 우호적인 교역 상대**로 알고 거래해 왔다. 마키나가 지구에서 사 가는 것은 **마석**(지구 던전의 마력 결정) — 말라 버린 세계의 연료다.
- [확정] 서울 게이트로 연결망과 엘리시온(대기 마력이 가장 짙은 세계)의 존재가 알려지자 마키나가 본색을 드러낸다. 지구는 모르는 사이 적을 키운 셈이다.

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **인간.** 수명 70~80년(지구인과 비슷). 세계에 마력이 없어 마법을 타고나지 못하고, 모든 힘을 기계로 대신한다. 몸이 약한 만큼 **기계를 몸에 이식**하는 것이 당연한 문화. 남녀 모두 있다 |
| 하위 종족·계급 | [확정] 탑의 높이가 곧 계급 — **상층**(지배 가문·관리) / **중층**(기술자·장교) / **하층**(노동자, 백화 지대와 맞닿은 곳). 개조 정도에 따라 **부분 개조인**(팔다리·눈)과 **전신 개조인**(뇌 말고는 전부 기계, 하층 출신 병사가 많다) |
| 기계 생명 | [확정] **오토마톤** — 사람이 타지 않는 자동 병기. 마석으로 움직이며 물량의 핵심. 지휘는 개조인 장교가 맡는다 |
| 동식물·괴수 | [확정] 자연 생물은 거의 멸종, 탑 안 배양 시설에서 식량을 기른다. 백화 지대에는 **백화수** — 마력이 빠지며 결정으로 굳어 버린 옛 짐승들. **마력을 가진 존재에게 달라붙어 마력을 빨아들인다** |

- 적군 구성은 **개조인 장교 + 오토마톤 물량** — 감정 없는 기계 군대를 사람이 지휘한다(판데모니움의 마족 물량과 다른 색).
- 전신 개조인은 대부분 하층 출신이라 기계 몸 안에 사연이 있다.
- 백화수는 마력을 빨아들여, 초월자가 많은 엘리시온이 오히려 상대하기 까다롭다.

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **마석과 추출한 마력을 기관에서 태워** 기계를 움직인다. 개인은 마력을 타고나지 않으므로 강함은 곧 **장비의 강함** |
| 경지·등급 | [확정] 작가용 지수(지구 S급=100, 태현=2,000): 보병형 오토마톤 20~50 / 부분 개조인 병사 30~80 / 중장 오토마톤 80~150 / 전신 개조인 정예 120~300 / 거대 병기(보행 요새·공중 전함) 400~800, 느리고 크다 / **전략 병기**는 지수 없음 — 특정 조건에서만 쓰는 비장의 카드(내용은 6·11에서 정함) |
| 고유 능력·기술 계열 | [확정] ① **흑강 장갑** — 마법(마력)이 잘 먹히지 않는다 ② **흡마 장치** — 주변 마력을 빨아들여 동력으로 쓴다, 상대가 마력을 쓸수록 강해짐 ③ 총포·증기 병기·장거리 포격 ④ 공장에서 찍어 내는 대량 생산 |
| 약점·제약 | [확정] ① **연료** — 마석 보급이 끊기면 멈춘다, 보급선은 곧 게이트 ② **회복** — 마법 치유가 없어 부서지면 고쳐야 하고 전장 회복이 느리다 ③ **격 제한** — 거대 병기는 작은 게이트를 못 지나간다(서울 게이트·지구행 게이트 모두 작아 처음엔 작은 부대만 넘어옴) ④ **물리** — 흑강도 칼에는 보통 강철, 원탁의 검술에 약하다 ⑤ **흡마 상한** — 초월경(800) 이상의 출력은 넘쳐서 장치가 터진다. 그랜드마스터(엘리시아 610·카이론 720)는 고전하지만 버티고, 태현의 힘은 아예 빨아들이지 못한다 |
| 타 차원 힘과의 상성 | [확정] 엘리시온 마법: **마키나 약간 우세**(마법끼리만 놓고 볼 때, 전체 전력은 엘리시온이 위) / 엘리시온 검술(원탁): 마키나 불리 / 셀레스티아 신력: **마키나 불리** — 흑강은 마력만 튕겨 내고 믿음에서 나오는 신력은 못 막는다, 믿음이 없어 축복도 못 받는다 / 판데모니움 마기: **마키나 불리** — 마기를 빨아들이면 기관이 오염돼 폭주·부식, 마족은 마키나 기계의 천적 / 지구 각성자: 마키나 우세(지구는 마키나 기술에 기대 온 쪽) / 태현: 마키나 절대 불리(흡마 상한 초과, 엑스칼리버는 흑강도 벤다) |

- 마키나는 마력에 기대는 상대(엘리시온·지구)에게만 강하고 신·마족에게는 약하다 — 연결망의 두 강대 세력과 정면으로 부딪치지 않고 **틈을 노리는 적**.
- 선택 ④(엑스칼리버로 게이트 확장)와 맞물린다: 넓히면 엘리시온 군대가 지구로 가기 쉬워지지만 **마키나의 거대 병기도 지나올 수 있게 된다**.

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] **탑주(塔主) 한 명이 다스리는 기술 관료 제국.** 바벨 꼭대기의 탑주 아래로 공장을 가진 가문들이 각 탑을 맡는다. **내분은 없다** — "세계가 죽어 가니 살아남는다"는 목표 하나로 움직인다 |
| 계급 | [확정] 탑의 층이 곧 신분 — 상층(지배 가문·관리) → 중층(기술자·장교) → 하층(노동자). 하층민은 **전신 개조를 받고 병사가 되면 한 층 올라갈 수 있다** — 거의 유일한 출세길 |
| 경제·화폐 | [확정] **연료권** — 마석 연료 배급표가 곧 화폐. 식량·전기·온기를 모두 연료권으로 산다 |
| 종교·신앙·가치관 | [확정] 신이 없다. **생존과 효율**이 가치의 전부. 격언 "기계는 배신하지 않는다". 마력이 흐르던 옛날을 **"푸른 시대"**라 부르며 그리워한다 |
| 법·관습·금기 | [확정] 가장 무거운 죄는 **연료 낭비와 마석 은닉**. 탑주의 명은 법보다 위 |
| 언어·이름 짓기 규칙 | [확정] 독일어풍의 딱딱한 어감(예: 카를, 리젤, 베르크). 성 대신 소속 탑과 층을 붙이기도 한다 |
| 호칭·존칭 | [확정] 탑주: "탑주 각하" / 장교: 계급명 / 하층민끼리: 층 번호("17층 녀석") |
| 의복·건축·음식·일상 | [확정] 방독면과 두꺼운 코트, 리벳 박힌 강철 건물, 쉬지 않는 증기 소리. 주식은 배양 단백질 반죽. 하층에는 늘 산성비가 샌다 |

- 엘리시온의 하늘과 숲은 마키나 사람들에게 곧 "푸른 시대" — 침공에 집착과 동경이 함께 섞인다.

| 내부 파벌·갈등 | [확정] 없음. 교역청이 지구와의 거래를 오래 끌고 싶어 하는 정도의 의견 차이만 있다 |

- 플롯의 축: **「바벨의 심장」이 넘어오느냐 막느냐.**
- 서울 공관의 교역청은 1부부터 지구 안에 숨어 있는 적의 눈이다. 지구 던전의 마석 시장이 그대로 마키나의 보급선이다.

## 7. 역사
| 항목 | 내용 |
| --- | --- |
| 기원 | [확정] 마력이 풍부하던 **"푸른 시대"**에 인간이 마도 공학을 꽃피웠다. 타고난 마법은 약했지만 기계로 마력을 다루는 기술은 어느 세계보다 앞섰다 |
| 쇠락 | [확정] 더 많이 만들려고 땅에서 마력을 퍼 올리는 **흡마갱**을 세웠고 수백 년 동안 멈추지 않았다. 땅이 백화되기 시작했고 사람들은 매연 위의 탑으로 올라갔다 |
| 제1차 차원대전 (참전 여부·역할·결과) | [확정] **불참.** 연결망 바깥이라 대전의 존재조차 몰랐다 |
| 전후 현재 상황 | [확정] 남은 연료는 **약 10년 치.** 그 안에 새 마력원을 찾지 못하면 탑도시가 멈춘다 — 마키나가 망설이지 않는 이유 |

| 수천 년 전 | 푸른 시대, 마도 공학의 시작 |
| 약 800년 전 | 흡마갱 시대 시작, 제국의 최전성기 |
| 약 300년 전 | 백화가 시작됨 |
| 약 100년 전 | 지표에서 살 수 없게 되어 탑도시로 이주. 바벨 완공, 탑주 체제 시작 |
| 지구 기준 3년 전 | 지구에 게이트가 열리며 마키나와 지구 사이에 안정 게이트가 생김. 교역 시작, 마석 대량 구매 |
| 지구 기준 1년 전 | **「바벨의 심장」 완성 — 지구에서 사 간 마석으로 만들었다** |
| 2026년 3월 14일 | 서울 게이트 개방. 교역청이 엘리시온의 존재를 알게 됨(이후는 본편 사건) |

- 연료 10년이라는 **시한** 때문에 마키나는 기다리지 않는다.
- 지구가 팔아 온 마석으로 「바벨의 심장」이 만들어졌다 — 진실이 드러나면 지구 쪽 정치가 크게 흔들린다.
