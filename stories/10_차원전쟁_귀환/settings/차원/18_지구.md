**게이트의 종류**

| --- | --- | --- |

| 불안정 이세계 게이트 | 연결망 바깥의 아무 세계 | 잠깐 열렸다 닫힘, 표류자나 낯선 생물이 넘어옴 |

- 서울 게이트가 특별한 이유: 지구는 "이세계는 이미 몇 개 안다"고 여겼지만, 그 너머에 신·마왕·용이 있는 거대한 연결망이 있었다.

## 3. 종족·생태
| 항목 | 내용 |
| --- | --- |
| 주 종족 (외형·수명·성장·번식·성별 구성) | [확정] **지구 인간.** 마력 없이 태어난다. **각성의 원리:** 지구에 퍼진 마력이 몸에 스며들다 **각성핵**으로 맺히면 그때부터 마력을 쓸 수 있다(엘리시온의 마력심과 비슷하나 나중에 생김). 인구의 약 0.1%가 각성하며, 게이트 가까이 사는 사람·게이트 사고를 겪은 사람에게서 더 자주, 대개 10대 후반~30대에 일어난다. **각성 현상:** 며칠 동안 고열로 쓰러졌다 깨어나면 몸이 바뀌어 있고, 협회에 신고해 등급 판정을 받는다. **등급**은 F~S, 각성핵의 크기로 정해지며 수련·실전으로 조금씩 오르지만 한 등급을 넘기는 건 아주 드물다(김선호·한서윤의 S급은 이례적). 각성핵이 부서지면 힘을 잃고 일반인으로 돌아간다. 지구의 마력이 짙어질수록 각성자와 강한 각성자가 늘어난다 |
| 하위 종족·계급 | [확정] **각성자의 계열:** 전투형(신체 강화·검술·원소) / 지원형(치유·강화·결계) / 감각형(탐지·분석·정찰, 한서윤) / 생산형(마석 가공·장비 제작, 아이언홀드 드워프 기술). **내부의 힘(마력)과 바깥에서 받은 힘은 각각 별개로 겹친다:** 축복받은 자(셀레스티아 신력, 백야 길드·여명 교단에 많음, 루키엔이 축복을 빼앗을 수 있음) / 계약자(판데모니움 마기, 오래 쓰면 타락자, 검은 성배회) / 수호받은 자(에덴 천족의 수호 맹세, 거의 없음). 지구 사람들은 축복을 "하늘이 내린 힘", 계약을 "금지된 힘"이라고만 안다. **함께 사는 존재:** 이세계인(로덴·마린델·아이언홀드·그롬가르의 상인·유학생·용병, 협회 등록 의무), 표류자(돌아가지 못한 사람들, 차별을 받기도 함) |
| 동식물·괴수 | [확정] **게이트 괴수**(차원 사이 틈의 괴수, 각성자의 사냥감이자 마석의 원천), **마수와 하위 마족**(지옥문 게이트, 훨씬 위험), **게이트 브레이크**(제때 공략하지 못하면 괴수가 밖으로 쏟아져 나옴, 지구 사람들이 가장 두려워하는 재난) |

## 4. 힘의 체계
| 항목 | 내용 |
| --- | --- |
| 힘의 원천 | [확정] **내부: 마력**(각성핵에 모인 각성자 자신의 힘, 엘리시온의 마력과 같은 계열) + **외부: 축복(신력)·계약(마기)·수호(성력)**이 각각 별개로 겹친다. 한 사람이 마력과 축복을 함께 가질 수 있으나 **축복과 계약은 한 몸에 같이 담을 수 없다**(신력·마기 상극) |
| 경지·등급 | [확정] 작가용 지수(지구 S급 평균=100, 태현=2,000): F 1~5 / E 5~10 / D 10~20(게이트 괴수를 혼자 잡음) / C 20~35 / B 35~55 / A 55~80(대형 길드의 주력) / **S 80~160**(국가 전략급 — 김선호 145, 한서윤 118, 백재성 155). 지구 S급은 엘리시온 익스퍼트 위쪽, 페럴리아 전사, 알프헤임 잎~가지 정도 — 연결망의 정점들과는 비교가 안 된다. **등급 규칙:** 공식 등급은 F~S 7단계뿐(SS·SSS·EX·S+ 없음), S급 내부를 공식적으로 나누지 않는다. 축복받은 자도 같은 등급 체계를 쓴다. 지구 등급을 다른 차원 존재(초월자·신·마왕 등)에 붙이지 않는다 |
| 고유 능력·마법 계열 | [확정] 각성자 계열(전투형·지원형·감각형·생산형)에 따른 마력 능력. **외부 힘의 효과:** 축복 — 원래 지수의 20~50% 상승, 대가는 신의 뜻을 따라야 하며 어기면 빼앗김 / 계약 — 50~100% 상승, 오래 쓸수록 타락자에 가까워짐(S급이 되지 못한 각성자들이 검은 성배회에 넘어가는 이유) / 수호 — 방어가 크게 오르고 공격력은 그대로, 수호한 천족이 떠나면 사라짐 |
| 약점·제약 | [확정] ① 각성핵이 부서지면 일반인으로 돌아감 ② 마력이 바닥나면 힘을 못 씀 ③ 외부 힘은 빼앗기거나 타락할 위험. **엘리시온에 가면** 대기 마력이 짙어 마력 회복이 확실히 빨라지고, 수련 효율도 조금 오른다. 다만 성장은 완만해서 몇 년 단위로 머물러야 차이가 드러나며, 며칠·몇 주 머무는 것으로는 등급이 거의 달라지지 않는다(급격한 강화 없음) — 지구 각성자들이 엘리시온에 장기 체류(유학)를 원하는 이유이자 엘리시온 쪽 협상 카드 |
| 타 차원 힘과의 상성 | [확정] 마력 계열이라 엘리시온과 같다 — 신력에 정면 열세, 마기에 침식당함, 성력과 중립, 용력에 열세, 숲의 마력과 잘 섞임 |

### 엘리시온 수련 시 성장 [확정]
지구 최상급 각성자(지수 150~160)가 엘리시온에서 스승(원탁 기사·마탑 등)과 실전(잔재수 사냥 등)을 갖추고 수련할 때의 기준. 혼자 수련하면 속도가 절반쯤, 개인차 ±10%.

| 체류 기간 | 지수 (160 기준) | 엘리시온 경지 |
| --- | --- | --- |
| 1년 | 약 170 | 익스퍼트 상위 |
| 3년 | 약 200 | 익스퍼트 최상위 ~ 마스터 문턱 |
| 5년 | 약 230 | 마스터 하위 |
| 10년 | 약 260 | 마스터 하위~중위 |
| 상한 | 약 300 | 마스터 중위. 그랜드마스터(450 이상)는 불가 |

- 각성핵 크기에 한계가 있고 지구인은 수명이 보통이라 그랜드마스터에 닿지 못한다. 태현(혈관 회로)은 이 표의 예외.
- 지구로 돌아가면 성장은 멈추지만 오른 지수는 유지된다.

## 5. 사회·문화
| 항목 | 내용 |
| --- | --- |
| 정치 체제·지배 구조 | [확정] 현실 국가 체제 그대로, 각국 정부가 게이트에 대응. 한국은 3자 견제 구조 — **국가게이트대응본부**(정부: 봉쇄·대피·군 투입) / **대한각성자협회**(각성자 등록·등급 판정·게이트 공략 허가) / **길드**(민간 기업: 게이트 공략). 국제 조율은 **국제각성자연맹**(각국 협회 조율 + 이세계 외교) |
| 계급 | [확정] 각성자와 일반인의 격차가 큼. 등급 = 연봉 = 사회적 지위. S급은 연예인보다 유명. 축복자는 여명 교단 덕에 우대, 계약자는 범죄자 취급, 이세계인·표류자는 차별을 겪기도 함 |
| 경제·화폐 | [확정] 기존 화폐 + **마석 경제**. 길드가 게이트를 공략해 마석을 팔고, 아이언홀드에서 들여온 드워프 기술로 마석 가공 산업이 성장 |
| 종교·신앙·가치관 | [확정] 기존 종교는 그대로이나 게이트 이후 지형이 흔들림. **여명 교단** — 실제 축복이 내리자 "하늘의 신은 실재한다"며 3년 만에 급성장(축복의 근원이 판테온이라는 것도, 그 의도도 모름). **은빛 신전** — 치유·정화 축복. **심판의 성소** — 계약자 사냥 강경파, 법 밖 처단으로 사회 문제. **검은 성배회** — 마계를 섬기는 비밀 결사, 계약을 퍼뜨림 |

| 본편 등장 시기 | [확정] 첫날: 엘리시온의 노아 목격과 같은 날 지구에서는 본부 봉쇄·서윤 투입 / 초반: 서울 게이트 조사, 태현의 첫 지구 방문(시점은 사용자가 정함), 측정 불가 사건 / 중반: 국제 압박, 여명 교단 충돌, 성배회 사건, 칼로르·아라 / 후반: 그레모리의 대침공, 지구 전면전 |
| 이 차원의 지켜야 할 규칙 | [확정] 서울 게이트는 일반 크기·자연 발생·배후 없음 / 지구 3년 = 엘리시온 30년, 서울 게이트 이후 같은 속도 / 지구 인물이 군신과 대등하게 싸우는 장면을 만들지 않음 / 축복과 계약은 한 몸에 공존 불가 / 신 본체는 지구 직행 불가(화신 약 30%), 마왕은 소형 게이트 통과 불가 / 지구 인물은 대전·연결망을 모르는 상태로 쓴다 / 선호와의 관계 결과는 미리 정하지 않음 / 바깥 세계 4곳은 단순 처리 |
| 작가만 아는 진실 | [확정] **검은 성배회 수장 = 국제각성자연맹 의장 아드리안 뮐러.** "인류 공동 관리"로 서울 게이트를 손에 넣으려는 것은 마몬을 위해서 |
