# 작품 10 — 차원별 상세 설계

> 작품 10 설계를 **차원 단위로 전면 상세화**한다. 차원 하나의 지형·종족·힘·사회·세력·역사·대외 관계·인물을 한 파일에 모두 담아, 설계가 끝난 차원은 다시 설정을 추가할 필요가 없게 한다.

## 진행 규칙
- 차원 하나씩, 카테고리 하나씩 진행한다. 사용자가 고른 것만 [확정].
- 각 파일 머리말의 "기존 확정 출처"에 있는 내용은 설계할 때 해당 파일로 병합한다. 기존 확정과 다르게 바꾸면 새 D-번호로 기록한다.
- 설계가 끝난 차원은 그 파일이 정본이다. 기존 `settings/01~08`의 중복 내용은 병합 후 정리한다.
- 모든 파일은 같은 12개 카테고리를 쓰고, 해당이 없으면 "없음"으로 명시한다.
- **인물 프로필 단계** [추천]: 1단계 전체 프로필(외형·성격·말투 예시 대사·능력·약점·과거·주변 관계·태현과의 관계·서사 역할) / 2단계 짧은 프로필(인물 표 + 말투 예시 한 줄) / 이름 없는 단역만 스토리 중 생성. 모든 차원 공통.

## 차원 간 공통 규칙 [확정]
### 다중우주 구조
- **연결망**: 엘리시온 + 여섯 세력 차원. 서로를 알고 대전을 함께 겪었다.
- **연결망 바깥**: 무수한 독립 세계. 연결망을 모르고 연결망도 관심이 없다. 바깥 세계에도 엘프·수인 같은 종족이 따로 있으며 연결망의 종족과는 전혀 다르다.
- **지구**: 원래 바깥 세계였으나 균열로 벽이 약해져 연결망과 바깥 세계 양쪽에 닿게 된 유일한 세계.
- **게이트의 격 제한**: 모든 게이트에서 작은 게이트는 강한 존재가 지나가지 못한다.

### 전력 구조 — 셀레스티아 vs 판데모니움
| 항목 | 셀레스티아 | 판데모니움 |
| --- | --- | --- |
| 강점 | 질 — 소수 정예, 정점(주신 1,700) | 양 — 하위·중위 마족 수백만, 마왕 7명(1,000~1,500) |
| 본거지 밖 | 본체 출력 약 60%, 화신은 약 30% | 출력 유지. 대신 게이트 격 제한·마기 회복 지연 |

| 전장 | 우세 | 이유 |
| --- | --- | --- |
| 셀레스티아 | 신 | 본체 100%와 주신 |
| 판데모니움 | 마족 | 마역과 물량, 신은 60% |
| 엘리시온 | 팽팽함 | 정예 60% 대 물량 100% — 대전이 오래 끈 이유, 태현이 판을 깸 |
| 지구 | 마족 | 신은 화신·대리인뿐, 마족은 상위 마족까지 군대째로 넘어옴 |

두 세력은 서로의 본거지를 칠 수 없으므로 중립지인 엘리시온과 지구가 차원전쟁의 무대가 된다.

### 본거지 밖 제약 — 차원별
| 차원 | 제약 | 지구에 힘을 주는 방식 |
| --- | --- | --- |
| 셀레스티아 | 본체 출력 약 60%, 화신 약 30% | 축복 (신력 분여) |
| 판데모니움 | 출력 유지, 게이트 격 제한·마기 회복 지연 | 계약 (마기 대여, 오래 쓰면 타락자) |
| 에덴 | 출력 유지, 밖에 오래 머물수록 타락 위험 증가 | 수호 맹세 (거의 쓰지 않음) |
| 엘리시온 | 출력 유지, 마력이 옅은 차원(지구 등)에서는 회복이 아주 느림 | — |
| 알프헤임 | 식물이 없는 곳에서 자연 마법 효율 저하(바람·궁술은 그대로) | — |
| 드라코니아 | 출력 유지. 용형은 일반 게이트를 못 지나 다른 차원에서는 인간형(광역 공격 크게 감소) | — |
| 페럴리아 | 출력 유지. 달이 없는 차원(셀레스티아·판데모니움)에서는 수화가 약해짐 | — |
| 지구 | 지구 각성자가 엘리시온에 가면 오히려 회복·성장이 빨라짐 | — |
