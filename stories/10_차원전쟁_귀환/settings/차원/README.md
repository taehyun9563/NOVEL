# 작품 10 — 차원별 상세 설계

> 작품 10 설계를 **차원 단위로 전면 상세화**한다. 차원 하나의 지형·종족·힘·사회·세력·역사·대외 관계·인물을 한 파일에 모두 담아, 설계가 끝난 차원은 다시 설정을 추가할 필요가 없게 한다.

## 진행 규칙
- 차원 하나씩, 카테고리 하나씩 진행한다. 사용자가 고른 것만 [확정].
- 각 파일 머리말의 "기존 확정 출처"에 있는 내용은 설계할 때 해당 파일로 병합한다. 기존 확정과 다르게 바꾸면 새 D-번호로 기록한다.
- 설계가 끝난 차원은 그 파일이 정본이다. 기존 `settings/01~08`의 중복 내용은 병합 후 정리한다.
- 모든 파일은 같은 12개 카테고리를 쓰고, 해당이 없으면 "없음"으로 명시한다.
