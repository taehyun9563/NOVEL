# 작품 10 — 떡밥 목록

> 차원별 설계 파일에서 정한 떡밥을 한곳에 모은 목록. 정본은 각 차원 파일이며, 차원 설계가 끝날 때마다 갱신한다.
> 최종 갱신: 엘리시온 설계 완료 시점 (셀레스티아·판데모니움·에덴·엘리시온 반영)

## 1. 최종 떡밥 (여러 차원을 잇는 큰 줄기)
| 떡밥 | 내용 | 차원 |
| --- | --- | --- |
| 루시페르의 부활 | 원초의 마왕이 코키토스 바닥에 잠들어 있음. 마핵 일곱 조각이 한곳에 모이거나 봉인이 흔들리면 깨어남 | 판데모니움 |
| 금단의 정원의 뱀 | 정체는 루시페르의 의지 조각. 천족을 하나씩 타락시켜 루시페르가 깨어날 때 쓸 군대를 만드는 중 (작가만 아는 진실) | 에덴·판데모니움 |
| 크로노드의 봉인 | 시간의 거신. 타르타로스에 봉인, 로키안과 꿈으로 교감 중. 풀리면 태현과 대등(2,100) | 셀레스티아 |
| 태현이 온 균열 | 대전의 충격으로 찢긴 균열이 지구의 벽을 약하게 만들어 지구에 게이트가 생김 | 엘리시온·지구 |

## 2. 지구를 둘러싼 떡밥
| 떡밥 | 내용 | 차원 |
| --- | --- | --- |
| 맹약의 빈틈 | 휴전 조건에 지구 조항이 없어 셀레스티아는 맹약을 어기지 않고 지구에 축복·화신을 보냄 | 셀레스티아·엘리시온 |
| 축복 회수 | 루키엔이 셀레스티아를 거스른 지구 각성자의 축복을 빼앗음 | 셀레스티아 |
| 에오스의 신탁 | 여명 교단을 통해 셀레스티아의 뜻이 지구 사건에 들어옴 | 셀레스티아 |
| 계약과 타락자 | 마몬·베리스가 검은 성배회를 통해 지구 안에 타락자를 만듦 | 판데모니움 |
| 게이트 확장과 마왕 강림 | 판데모니움이 지구 게이트를 넓히려 함. 성공하면 마왕 강림 | 판데모니움 |
| 그레모리의 지구 전선 | 지구 S급들과 정면으로 부딪히는 실제 전쟁 | 판데모니움 |
| 아리엘라의 수호 맹세 | 천족 하나가 허락 없이 지구 인간을 지키기로 맹세 | 에덴 |
| 카시아 파견 | 셀레스티아가 지구에 보낼 수 있는 첫 인물(반신이라 약해지지 않음) | 셀레스티아 |
| 신의 본체 강림 | 신이 본체로 오려면 엘리시온과 서울 게이트를 지나야 함 | 셀레스티아 |
| 지구 개입 결정 | 군신이 지구에 어떻게 손을 뻗을지 — 본편 첫 번째 큰 선택 | 엘리시온 |
| 엑스칼리버로 게이트 확장 | 서울 게이트를 넓힐 수 있는 유일한 수단. 군대를 보낼지는 태현의 선택 | 엘리시온 |

## 4. 태현과 얽힌 인물 떡밥
| 떡밥 | 내용 |
| --- | --- |
| 백귀야행의 망자들 | 아레온(티르온의 아버지)과 레비아탄(레비아의 스승)이 망자 군세에 있음. 알려지면 두 차원이 뒤집힘 |
| 헬리아의 흥미 | 그의 영혼을 거두지 못한 죽음의 신. 정작 그는 죽은 자를 거두고 있음 |

| 사마엘의 본명 | 원래 이름 아즈라엘, 메타트론의 기록에만 남음 |
| 타락은 되돌릴 수 있나 | 완전히 타락한 천족을 되돌리면 에덴의 상식이 뒤집힘 |
| 다시 에덴의 문 앞에 | 태현이 다시 문 앞에 서는 것이 교착을 깨는 사건 |
| 아스타로트 | 칠좌 밖의 떠돌이 마공, 우군이 될 수 있음 |
| 엘리시아의 불안 | 태현이 지구로 떠날까 봐 |
