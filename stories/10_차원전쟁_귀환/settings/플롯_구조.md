# 작품 10 — 플롯 큰 구조

> 상태: [확정]
> 이 플롯은 **"아무도 개입하지 않으면 세계가 흘러갈 방향"**이다. 세계가 일으키는 사건만 배치하고, 태현의 큰 선택은 비워 둔다.
> 설정의 정본은 `settings/차원/`이며, 이 파일은 사건의 흐름만 다룬다.

## 1. 전체 틀
| 항목 | 내용 |
| --- | --- |
| 구성 | [확정] **4부.** 귀환 → 쟁탈 → 제2차 차원대전 → 태초 |
| 결말 | 정하지 않는다. 태현의 선택이 쌓여 정해진다 |
| 부 전환 | 시간이 아니라 **사건 조건**으로 넘어간다. AI가 임의로 다음 부로 넘기지 않는다 |
| 로맨스 | 히로인 7명과의 관계 결과는 정하지 않는다. 사건은 계기만 만든다 |
| 적의 배치 원칙 | [확정] 1·2부는 주된 적이 바뀐다 / 3부는 전면전이라 모든 차원과 주요 인물이 나온다 / 4부는 태초의 위협 / **엘리시온 안의 배신은 없다** — 위기는 모두 바깥에서 온다 |
| 마키나의 단계 | [확정] 1부 숨어 있음(에밀) → 2부 공작 후 첫 침투(흑강대) → 3부 본대(하인리히, 「바벨의 심장」) |

## 2. 운영 규칙
| 구분 | 내용 | 바뀌는 방식 |
| --- | --- | --- |
| 고정 | 세계 설정 — 차원 규칙, 인물의 과거, 작가만 아는 진실(뮐러·뱀·잿빛 숲 등) | 바뀌지 않는다. 바꾸려면 설정 수정 절차를 거친다 |
| 유동 | 사건의 순서·시기·규모, 어느 부에서 터지는지 | 태현의 선택에 따라 앞당겨지거나 미뤄지거나 형태가 바뀐다 |
| 사라질 수 있음 | 개별 사건 | 태현이 미리 막으면 일어나지 않는다(예: 에밀의 정체를 미리 밝히면 2부 후반의 흑강대 침투가 형태를 바꾼다) |
| 결과 미정 | 각 선택의 결과, 로맨스, 결말 | RP에서 정해진다 |

- 태현의 선택이 플롯과 어긋나면 **선택이 우선**이다. AI는 세계가 그 결과에 어떻게 반응할지를 다시 짠다.
- 큰 사건이 사라지거나 순서가 바뀌면 장면이 끝난 뒤 `progress/진행_기록.md`에 적고 이 파일을 갱신한다.
- 최종 떡밥(루시페르, 크로노드)은 언젠가 반드시 터지는 **세계의 시계**다. 태현이 이것까지 막는다면 결말이 바뀌는 큰 선택으로 다룬다.

**차원별** [확정]
| 차원 | 누가 어떻게 움직이나 |
| --- | --- |
| 셀레스티아 | 주신 **아르케온** 아래 판테온 강경파(**오르디엘·티르온·토라크**)가 주도. 티르온의 독단 출정이 판테온 의결로 번지며 전면전. 중립 4석(자이라·헬리아·헤파론·베리타스)을 누가 가져가느냐가 판을 정하고, 독자파 세라피나·아르테아는 흔들린다 |
| 판데모니움 | **일곱 마왕 전부.** 침공파(**벨제부스·마몬·발타르**) 주력, **리제트**는 군신 본인을 노리는 설욕전, 관망파(**벨페고르·레비아**)는 판세를 보다 늦게 참전, **아스모데아**는 변덕으로 움직임, 마공 **아드라멜렉**은 그 틈에 하극상. 마왕 강림 |
| 마키나 | **하인리히**의 본대와 「바벨의 심장」 — 게이트 확장을 노린다. 마몬과 손잡는다 |
| 에덴 | 만장일치 교착이 깨진다. 순결파(**우리엘·메타트론**)는 적대, 개방파(**가브리엘·레미엘**)는 엘리시온 편, **미카엘**이 교착을 깨는 한 표 |
| 알프헤임 | 장로회 보수파(**오베론**)는 문을 닫으려 하고 **레아**의 은빛 궁기대는 동맹군으로 참전. 잿빛 숲의 진실 폭로 |
| 드라코니아 | **이그나리스**는 동맹 — 태현이 부르면 용언으로 드라코니아 전체가 응한다. 은둔파는 중립, **칼로르**의 탐욕파는 혼란을 틈타 움직임, 용왕 **마레아스**는 불만을 쌓다 4부에서 터진다 |
| 페럴리아 | 칸 **사르한**의 연맹 통합. **라쉬카**의 용병파는 마키나·판데모니움 쪽에 용병을 팔고, 고립파는 문을 닫는다 — 어느 편에 서느냐가 숨은 변수 |
| 지구 | 전장 — 신·마족·기계가 모두 지나가는 길목 |

| 사건 | 내용 |
| --- | --- |
| 첫머리: 에덴 | [확정] ① 아리엘라가 「먼 소리」로 성배회·마족이 신인 각성자(이채린)를 노린다는 것을 듣고, 가브리엘 씨족의 허락으로 불타는 검의 문을 넘어 **카멜롯에 와 지구 통행 허가를 청함**(넓어진 문 덕에 지수 300도 지나갈 수 있음) ② 순결파(우리엘·메타트론)가 "군신에게 머리를 숙인다"며 반발, 맹세의 전당이 흔들림 ③ 아리엘라가 이채린에게 수호 맹세 |

| 선택 | [확정] **3부에는 정해 둔 선택이 없다.** 선택 ④는 2부에서 씀 |

## 6. 4부 「태초」 — 최종 떡밥
| 사건 | 내용 |
| --- | --- |
| 위협 | 루시페르 부활, 뱀의 진실, 로키안이 크로노드의 봉인을 풂 |
| 증인 | 태고룡들이 깨어나 옛일을 증언 |
| 드라코니아 | 용왕 마레아스가 용언과 젊은 용제에 반발해 흔들린다 |
| **선택 ⑤** | **용언을 언제 쓸지**, 그리고 결말 |

- 선택 ⑤(용언)는 한 번 쓰면 판이 크게 바뀌는 카드라 판이 가장 커지는 순간까지 아껴 둔다. (선택 ④ 게이트 확장은 2부에서 이미 씀)
