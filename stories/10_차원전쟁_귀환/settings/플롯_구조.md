# 작품 10 — 플롯 큰 구조

> 상태: [확정]
> 이 플롯은 **"아무도 개입하지 않으면 세계가 흘러갈 방향"**이다. 세계가 일으키는 사건만 배치하고, 태현의 큰 선택은 비워 둔다.
> 설정의 정본은 `settings/차원/`이며, 이 파일은 사건의 흐름만 다룬다.

## 1. 전체 틀
| 항목 | 내용 |
| --- | --- |
| 구성 | 5부. 지구 귀환 → 차원전쟁 → 태초의 위협으로 커진다 |
| 결말 | 정하지 않는다. 태현의 선택이 쌓여 정해진다 |
| 부 전환 | 시간이 아니라 **사건 조건**으로 넘어간다. AI가 임의로 다음 부로 넘기지 않는다 |
| 로맨스 | 히로인 7명과의 관계 결과는 정하지 않는다. 사건은 계기만 만든다 |

## 2. 운영 규칙
| 구분 | 내용 | 바뀌는 방식 |
| --- | --- | --- |
| 고정 | 세계 설정 — 차원 규칙, 인물의 과거, 작가만 아는 진실(뮐러·뱀·잿빛 숲 등) | 바뀌지 않는다. 바꾸려면 설정 수정 절차를 거친다 |
| 유동 | 사건의 순서·시기·규모, 어느 부에서 터지는지 | 태현의 선택에 따라 앞당겨지거나 미뤄지거나 형태가 바뀐다 |
| 사라질 수 있음 | 개별 사건 | 태현이 미리 막으면 일어나지 않는다(예: 반란 전에 모드레드를 잡으면 3부 반란이 없어진다) |
| 결과 미정 | 각 선택의 결과, 로맨스, 결말 | RP에서 정해진다 |

- 태현의 선택이 플롯과 어긋나면 **선택이 우선**이다. AI는 세계가 그 결과에 어떻게 반응할지를 다시 짠다.
- 큰 사건이 사라지거나 순서가 바뀌면 장면이 끝난 뒤 `progress/진행_기록.md`에 적고 이 파일을 갱신한다.
- 최종 떡밥(루시페르, 크로노드)은 언젠가 반드시 터지는 **세계의 시계**다. 태현이 이것까지 막는다면 결말이 바뀌는 큰 선택으로 다룬다.

## 3. 1부 「귀환」 — 서울 게이트 개방(2026년 3월 14일, 제국력 10년) ~ 군신의 존재가 지구에 알려질 때까지
| 사건 | 내용 |
| --- | --- |
| 개방 | 노아 목격 → 이사벨이 카멜롯에 보고. 같은 날 지구에서는 본부 봉쇄, 한서윤 투입 |
| 반응 | 판테온 긴급 회의, 만마전 회합, 맹세의 전당 소집 — 짧은 장면으로 각 차원이 술렁임 |
| 궁정 논쟁 | 엘리시아·카이론·원탁이 개입론과 신중론으로 갈림 |
| **선택 ①** | **지구에 개입할지, 한다면 어떻게** |
| 첫 접촉 | 한서윤과 노아가 마주침. 태현이 지구에 오면 측정기 "측정 불가" |
| 재회 | 김선호와 재회 — 언제·어떻게 만날지는 사용자가 정한다 |
| 끝 | 실종 미제 사건이 뒤집히고 "군신"이 공개됨 |

## 4. 2부 「쟁탈」 — 지구의 정치와 공작
| 사건 | 내용 |
| --- | --- |
| 국제 압박 | 미국(마거릿 콜·제임스), 중국(자오밍·량웨이), 연맹(뮐러)이 한국을 압박, 윤재경이 막아섬 |
| 신계 공작 | "하늘을 훔친 자" 신탁 → 여명 교단 충돌, 축복 회수 사건으로 류세아가 흔들림, 카시아나 화신의 첫 접촉 |
| 마계 공작 | 구태석·검은 성배회의 타락자 사건 |
| 바깥에서 온 소동 | 칼로르·아라의 지구 소동, 아리엘라가 이채린에게 수호 맹세 |
| **선택 ②** | **서울 게이트를 누가 어떻게 관리할지** (한국 / 연맹 / 군신 단독) |
| 끝 | 그레모리 대침공의 전조(이반의 경고) |

## 5. 3부 「균열」 — 두 전선이 동시에 무너진다
| 사건 | 내용 |
| --- | --- |
| 지구 | 그레모리의 서울 대침공 |
| 엘리시온 | 태현이 자리를 비운 틈에 레온·모드레드 반란, 모르가나·마몬의 밀수로 봉쇄 요새가 뚫림 |
| 페럴리아 | 라쉬카의 배신 — 수인 용병을 몰래 지구로 |
| **선택 ③** | **어느 전선에 먼저 갈지** (엘리시아·레아도 각자의 선택을 마주함) |
| 끝 | 결과와 상관없이 뮐러가 검은 성배회 수장이라는 것이 드러남 |

## 6. 4부 「제2차 차원대전」 — 모든 차원이 다시 움직인다
| 사건 | 내용 |
| --- | --- |
| 셀레스티아 | 티르온이 의결 없이 신위대를 움직임, 중립 4석 쟁탈 |
| 판데모니움 | 아드라멜렉의 하극상, 리제트의 설욕전 |
| 다른 차원 | 사르한의 연맹 통합, 미카엘이 에덴의 교착을 깸, 잿빛 숲의 진실 폭로 |
| **선택 ④** | **엑스칼리버로 서울 게이트를 넓혀 군대를 지구로 보낼지** — 진행 반영: 1부(3/16)에 이미 소형→중형으로 조금 넓혔고 군대는 하루 만에 귀환, 회담에서 군사 지원은 불허. 남은 선택은 "더 넓혀 대군을 보낼지" |
| 끝 | 마왕이 쓰러지며 마핵 조각이 한곳에 모이기 시작 |

## 7. 5부 「태초」 — 최종 떡밥
| 사건 | 내용 |
| --- | --- |
| 위협 | 루시페르 부활, 뱀의 진실, 로키안이 크로노드의 봉인을 풂 |
| 증인 | 태고룡들이 깨어나 옛일을 증언 |
| **선택 ⑤** | **용언을 언제 쓸지**, 그리고 결말 |

- 진행 반영(2026-11-25): 1부는 3/29 군신 공개로 끝 조건 도달. 첫 접촉·측정 불가·재회(3/18 연천)가 1부 안에서 일어났고, 2부의 국제 압박·"하늘을 훔친 자" 신탁·류세아의 흔들림이 일부 앞당겨짐. 상세는 `progress/진행_기록.md`.
- 선택 ④(게이트 확장)와 ⑤(용언)는 한 번 쓰면 판이 크게 바뀌는 카드라 판이 가장 커지는 순간까지 아껴 둔다.
