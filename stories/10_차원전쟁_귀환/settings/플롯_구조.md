# 작품 10 — 플롯 큰 구조

> 상태: [확정] (2026-11-27 전면 재설계 — 지구 침공판. 이전 판은 `progress/보관/플롯_구조_v2.md`)
> 이 플롯은 **"아무도 개입하지 않으면 세계가 흘러갈 방향"**이다. 세계가 일으키는 사건만 배치하고, 태현의 큰 선택은 비워 둔다.
> 설정의 정본은 `settings/차원/`이며, 이 파일은 사건의 흐름만 다룬다.

## 1. 전체 틀
| 항목 | 내용 |
| --- | --- |
| 핵심 축 | [확정] **지구가 엘리시온을 침공한다.** 엘리시온은 명분 없이 먼저 지구를 치지 않는다 |
| 주제 | 고향과 나라. 태현이 칼을 들 때마다 상대가 지구인이다 |
| 구성 | [확정] **4부.** 귀환 → 침공 → 제2차 차원대전 → 태초 |
| 서울 게이트 | [확정] **격 제한이 없는 큰 문.** 지구 쪽은 여의도, 엘리시온 쪽은 카멜롯 고원 근처. 다른 문들은 여전히 격 제한이 있어, 이 문이 모든 차원이 노리는 유일한 큰길이 된다 |
| 맹약 | [확정] **한쪽이 어기면 깨진다.** 어긴 쪽은 베리타스의 신력 제재를 받는다. 이 판에서 먼저 어기는 자는 **티르온** |
| 결말 | 정하지 않는다. 태현의 선택이 쌓여 정해진다 |
| 부 전환 | 시간이 아니라 **사건 조건**으로 넘어간다. AI가 임의로 다음 부로 넘기지 않는다 |
| 로맨스 | 히로인 7명과의 관계 결과는 정하지 않는다. 사건은 계기만 만든다 |
| 적의 배치 원칙 | [확정] **엘리시온 안의 배신은 없다** — 위기는 모두 바깥에서 온다 |

### 부별 한눈에 보기 [확정]
| 부 | 주된 적 | 핵심 | 태현의 선택 |
| --- | --- | --- | --- |
| 1부 「귀환」 | 없음 (첫 접촉) → 배후 공작 | 큰 문 개방, 재회, 지구가 엘리시온을 탐내기 시작, 사망 사건, 통첩 | ① |
| 2부 「침공」 | 지구 연합 + 셀레스티아 강경파 + 판데모니움 | 같은 날 두 전선, 맹약 파기, 카멜롯 고원 전투 | ② ③ |
| 3부 「제2차 차원대전」 | 모든 차원 | 지구가 이용당했다는 진실, 전 차원 전선 | ④ |
| 4부 「태초」 | 태초의 위협 · 용왕 마레아스 | 루시페르, 뱀, 크로노드 | ⑤ |

### 지구 진영 [확정]
| 진영 | 구성 |
| --- | --- |
| 연합 | **한국 정부(처음부터)**, 미국 연방게이트청, 국제각성자연맹, EU 공동 대응단 |
| 독자 노선 | 중국 국가각성총국 — 미국과 경쟁, 연합에 끼지 않고 따로 움직인다 |
| 관망 | 일본, 러시아(지옥문 전선에 묶여 있음, 이반은 엘리시온과 손잡을 이유가 있다) |
| 한국 안 | 정부·본부는 연합. 협회와 길드는 징집·허가권으로 끌려가며, 해태·협회 일부 등은 흔들린다 |
| 배후 | 셀레스티아(여명 교단·백야·EU) / 판데모니움(검은 성배회) / 마키나(교역청, 병기 공급) |

## 2. 운영 규칙
| 구분 | 내용 | 바뀌는 방식 |
| --- | --- | --- |
| 고정 | 세계 설정 — 차원 규칙, 인물의 과거, 작가만 아는 진실(뮐러·뱀·잿빛 숲 등) | 바뀌지 않는다. 바꾸려면 설정 수정 절차를 거친다 |
| 유동 | 사건의 순서·시기·규모, 어느 부에서 터지는지 | 태현의 선택에 따라 앞당겨지거나 미뤄지거나 형태가 바뀐다 |
| 사라질 수 있음 | 개별 사건 | 태현이 미리 막으면 일어나지 않는다(예: 사망 사건의 조작을 미리 밝히면 통첩의 명분이 약해진다) |
| 결과 미정 | 각 선택의 결과, 로맨스, 결말 | RP에서 정해진다 |

- 태현의 선택이 플롯과 어긋나면 **선택이 우선**이다. AI는 세계가 그 결과에 어떻게 반응할지를 다시 짠다.
- 큰 사건이 사라지거나 순서가 바뀌면 장면이 끝난 뒤 `progress/진행_기록.md`에 적고 이 파일을 갱신한다.
- 최종 떡밥(루시페르, 크로노드)은 언젠가 반드시 터지는 **세계의 시계**다. 태현이 이것까지 막는다면 결말이 바뀌는 큰 선택으로 다룬다.

## 3. 1부 「귀환」 — 2026년 3월 14일 ~ 통첩까지 (약 3~5월)
| 순서 | 사건 | 내용 |
| --- | --- | --- |
| 1 | 큰 문 개방 | 3/14 여의도와 카멜롯 고원 근처를 잇는 큰 문이 열린다. 지구 쪽은 여의도 봉쇄, 엘리시온 쪽은 고원에 군이 깔린다. 양쪽이 서로를 처음 본다 |
| 2 | 조사단과 재회 | 협회 조사단(한서윤·김선호)이 문을 넘어 카멜롯에 온다. 실종됐던 태현이 엘리시온의 황제 군신이라는 것이 드러난다 |
| 3 | 엘리시온을 알게 됨 | 지구가 엘리시온의 짙은 마력, 마석, 통언, 강자들을 알게 된다. 지구 각성자는 엘리시온에 머물면 빨리 회복되고 수련 효율도 오른다 — 탐욕의 씨앗 |
| 4 | 교역과 외교 | 교역·외교가 시작된다. 미국 연방게이트청과 국제각성자연맹이 "인류 공동 관리"를 내세워 끼어든다 |
| 5 | 신탁 | 여명 교단에 "하늘을 훔친 자" 신탁. 태현이라는 해석이 퍼지며 성전 여론이 생긴다 |
| 6 | 성배회 | 검은 성배회가 계약자를 늘리고 지구 기관·길드에 파고든다 |
| 7 | 사망 사건 | 문 근처에서 지구인 사망 사건. 실제로는 로키안의 기만과 성배회의 조작이지만 지구 여론은 엘리시온이 죽였다고 믿는다 |
| 끝 조건 | 통첩 | 연합(한국 정부 포함)이 엘리시온에 통첩 — 서울 게이트 양쪽을 연합이 관리하겠다 |

| 선택 | 내용 |
| --- | --- |
| **선택 ①** | **지구와 어떤 관계로 시작할지.** 교역을 크게 열면 지구가 엘리시온을 빨리 알게 되고, 작게 열면 지구의 의심이 커진다. 2부의 속도와 지구 여론이 달라진다 |

## 4. 2부 「침공」 — 통첩 거절 ~ 침공 격퇴 (약 6월~가을)
| 순서 | 사건 | 내용 |
| --- | --- | --- |
| 1 | 거절 | 태현이 통첩을 거절하면 엘리시온은 지구를 치지 않고 문만 지킨다(거절 여부와 방식은 태현이 정한다) |
| 2 | 같은 날 두 전선 | [확정] 판데모니움이 북쪽 봉쇄 요새를 치는 날, 연합군이 서울 게이트로 넘어온다 |
| 3 | 섞여 든 힘 | [확정] 연합군에 축복자와 계약자가 섞여 있고, 그 뒤로 셀레스티아의 화신과 판데모니움의 마족이 따라 들어온다 |
| 4 | **맹약 파기** | [확정] 티르온이 판테온 의결 없이 신위대를 연합군 뒤에 붙여 엘리시온 땅에 들인다 — 맹약 ① 위반. 티르온은 베리타스의 제재를 받고 판테온은 갈라진다 |
| 5 | 카멜롯 고원 전투 | 앞줄에 한국 특수각성여단과 청룡 길드. 김선호는 징집돼 연합 쪽에 선다 |
| 6 | 지구 최강들 | 하워드(160)·량웨이(150) 등이 엘리시온 땅을 밟는다. 중국은 연합과 따로 움직인다 |
| 7 | 포로와 부상자 | 지구인 포로·부상자를 두고 엘리시온 안에서 의견이 갈린다(엘리시아·카이론) |
| 끝 조건 | 격퇴 | 침공을 막아 낸다. 맹약이 깨지면서 엘리시온에도 반격할 명분이 생긴다 |

| 선택 | 내용 |
| --- | --- |
| **선택 ②** | **어느 전선으로 먼저 갈지.** 남쪽 문(지구·신위대)과 북쪽 요새(판데모니움). 가지 않은 쪽은 원탁이 버텨야 하고 피해가 크다 |
| **선택 ③** | **지구로 넘어갈지.** 넘어가면 연합의 심장을 칠 수 있지만 태현이 지구를 침공한 군신이 된다. 안 넘어가면 지구는 다시 준비해서 온다 |

## 5. 3부 「제2차 차원대전」
### 진영
| 진영 | 구성 |
| --- | --- |
| 엘리시온 쪽 | 제국군·원탁·마탑. 알프헤임(레아)·드라코니아(이그나리스)는 태현이 청하면 참전. 에덴 개방파, 지구의 이탈자들(해태·협회 일부, 이반의 러시아 등) |
| 침공 쪽 | 연합(한국 정부·미국·연맹·EU), 셀레스티아 강경파(티르온·오르디엘·토라크), 판데모니움 칠좌, 마키나(병기를 대다가 엘리시온이 약해지면 직접 노림), 페럴리아 용병파, 드라코니아 탐욕파, 에덴 순결파, 알프헤임 보수파 |
| 흔들리는 쪽 | 중국(독자 노선), 판테온 신중파·중립 4석, 에덴의 만장일치 교착 |

### 흐름
| 단계 | 내용 |
| --- | --- |
| 전반 | 셀레스티아와 판데모니움이 서로를 이용하며 엘리시온을 노린다. 지구가 이용당하는 쪽이라는 것이 드러나기 시작한다 |
| 중반 | 검은 성배회 수장 뮐러의 정체와 사망 사건 조작이 밝혀진다. 한국 안에서 정부와 길드가 갈라지고 김선호·한서윤은 어느 편에 설지 정해야 한다 |
| 후반 | 각 차원의 전선이 터진다. 에덴의 교착이 깨지고, 마키나가 등을 돌리고, 셀레스티아 내전이 일어난다 |

| 선택 | 내용 |
| --- | --- |
| **선택 ④** | **셀레스티아로 넘어갈지.** 맹약은 이미 깨져 막을 것이 없다. 넘어가면 신들의 전쟁을 끝낼 수 있지만 그동안 엘리시온과 지구가 빈다 |

## 6. 4부 「태초」 — 최종 떡밥
| 사건 | 내용 |
| --- | --- |
| 위협 | 루시페르 부활, 뱀의 진실, 로키안이 크로노드의 봉인을 풂 |
| 증인 | 태고룡들이 깨어나 옛일을 증언 |
| 드라코니아 | 용왕 마레아스가 용언과 젊은 용제에 반발해 흔들린다 |
| **선택 ⑤** | **용언을 언제 쓸지**, 그리고 결말 |

- 선택 ⑤(용언)는 한 번 쓰면 판이 크게 바뀌는 카드라 판이 가장 커지는 순간까지 아껴 둔다.
